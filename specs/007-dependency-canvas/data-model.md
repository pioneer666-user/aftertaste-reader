# 依赖画布数据模型

## Graph

D009 图协议定义内容、身份及更新方式。路径在该图内唯一且大小写敏感。画布用图原文、已发布的移除与重加历史、当前可确认的缺席路径标识读取快照。每个文件额外提供当前讲解列表中实际匹配的镜像入口。

## Library legend

同一 `dependency-graph.json` 的可选 `legends` 数组保存当前图的库图例。每项包含稳定的 `id`、`kind`（`standard` 或 `third-party`）、`name`、`description` 及 `uses`（若干 `{path, reason}`，每个路径唯一且必须已登记）。同一图中 ID 唯一，显示名可重复。介绍和理由按原文呈现。具体校验与更新见 [图工具契约](../004-dependency-graph/contracts/cli.md#库图例)。

图例的布局键为 `legend:<id>`，与 Git 文件路径的语法互斥。节点名单由文件路径和图例键共同组成。两类对象使用同一移动、编组、保组重排、坐标、正式移除凭据和草稿对账规则。只更新介绍或用法不改变身份，使用文件被正式移除时对应关联随图发布删除。

## CanvasLayout

`docs/aftertaste/dependency-layout.json` 为 UTF-8 JSON。布局文档含 `format`（`aftertaste-canvas-layout/v1`）、`graph`（`dependency`）、`revision`（已落盘保存尝试的 UUID）、`layout`，可附 `nodeRemovals`。后者仅记录本次布局纳入的节点已接受的移除标记，使用路径到标记的自有键映射。D012 原布局没有该字段，直接读取。

- layout.positions 是以对象 ID 为自有键的坐标表。依赖图使用文件路径和 `legend:<id>`。
- layout.groups 为 `{ id, name, members }` 数组。ID 为 UUID，名字为去除首尾空白的 1—160 字符（按 UTF-16 计），允许重名。每个 ID 最多属一个组，加入另一组时转移归属，组至少有一名成员。
- layout.viewport 为 `{ x, y, zoom }`，画布坐标和视野位移为绝对值不超过十亿的有限数，缩放范围 0.25—2，保存保留原精度。
- 组框由成员坐标及实测节点尺寸加留白获得。不保存框位置或画布尺寸。拖组使用画布位移，每次从起点快照计算，重排保留组身份、名称和成员。

## 图与布局协调

图内容按 D009 的结构和引用校验读取。节点缺失时，持久清理还需匹配当前图发布的[明确移除凭据](../004-dependency-graph/data-model.md#画布移除凭据)。凭据缺失、损坏、失配或缺少路径时，页面提供当前结构合法的图预览，暂停布局保存并保全磁盘坐标和组。结构损坏、读不到图时同样停止协调。

路径正式移除后重加，若已发布的重加身份尚未被布局接受，原位置和组成员按移除处理，重加路径按新节点摆放。图中身份存续时保留坐标和归属，新节点优先从原布局最右边以外排列。当次协调有重加时，以存续节点坐标计算摆放范围。受坐标范围限制时选择有空间的一侧，四侧均已到极限时使用画布中央一列未占用的格位。空组消失，视野保留。读取只返回预览，已有布局需协调时由页面提交结果，空图也执行。

刷新并保留草稿时，页面将草稿已见的身份与服务确认的重加身份比较。两者相同就保留新位置和新组，另一个文件暂缺时等待恢复后再保存。磁盘布局中的标记只表示这份布局已接受的身份；保存时可以承接仍在图中的旧标记。直接编辑或撤销无关边的说明后，跨过正式移除的旧请求仍与当前图版本冲突。

当已保存的图例暂时从 JSON 缺席，但没有当前发布的正式移除凭据时，提供只读预览并保留整体布局。图例字段或端点损坏时按图校验错误处理。修复资料后可恢复同一实例的位置；有正式移除凭据则由页面协调保存，清理该实例和空组。正式移除后同 ID 再次出现时按新实例摆放，包含写回旧图文件的情形。

## D026 临时画布状态

| 状态 | 字段与有效条件 | 变化 |
| --- | --- | --- |
| 详情 | 当前文件路径或库 ID，目标必须存在于已加载图 | 选中时打开，可显式关闭；从文件讲解返回时恢复原节点及视野 |
| 框选 | 起止屏幕坐标、完全被框入的当前文件及库节点 ID | 拖动更新边界，松手保留选中反馈；新选择、取消或切页清除原选区 |
| 就近命名 | 选中的成员、松手锚点、名称草稿及将转移的成员 | 允许保存且选区有效时由浮钮或快捷键打开。确认时沿 CanvasLayout 的名字及成员规则校验，使用当前归属完成一次分组更新；取消丢弃临时状态 |

三者都在页面内存中。布局仍由 `CanvasLayout` 记录，既有失败草稿和冲突恢复负责保存确认后的操作。

## D027 依赖图临时状态

- 固定工具属于当前图页。按住 Ctrl 反转有效工具，拖动起点记录本次操作。松开 Ctrl、窗口失焦或离开图页清理临时反转。悬停位置、回弹、选区与小地图的显示均不写入布局。小地图读同一份节点坐标和主图实际视野，用户在小地图定位时更新原 `viewport`。
- 只有通过创建入口产生的组 ID 才会等待一次播放。保存尝试携带该修订实际提交的布局快照，只有服务确认的快照包含这个组才可消费其播放机会。失败仍保留重试机会，其他修订的成功不能提前确认。成功消费后，后续视野或改名保存均不重播。离开图页即清理播放机会，减少动态效果时显示静态保存反馈。布局持久化和冲突处理仍按原规则执行。

## D028 画布回访与浮层状态

| 状态 | 字段与有效条件 | 变化 |
| --- | --- | --- |
| 选中对象 | 文件路径或图例键。闭环使用步骤 ID 或图例键 | 在当前图内查找。已移除对象清除选择或使用可读入口，显示原因 |
| 详情 | 所选线或库用法的阅读位置 | 根据所选对象从当前图计算摘要和原因。浮层的显隐不参与画布测量 |
| 视野 | 当前平移与缩放 | 用于 [006 站内回访](../006-file-reader/data-model.md#d028-站内访问位置)。回访复位视野不提交布局写入 |
| 操作入口 | 闭环目录显隐、详情、组表单及工具状态 | 留在当前页。切换详情或编辑只更新对应浮层，成组确认按既有规则提交 |

恢复时以当前图和布局为准。已有布局编辑或保存进行中时，保留本页修改和既有冲突处理。两图的布局、选中和工具状态分别管理。

## D042 · 依赖图与闭环往返

闭环选择保存 ID 与标题。参与集合由完整路径推导，全有或全无。线的身份由两端节点标识确定。
