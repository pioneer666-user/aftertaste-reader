# Quickstart: 项目笔记

## 准备

在仓库根使用 Node.js 24、Git 与安装好的 Edge。测试创建隔离项目和临时本机监听，证据位于 `.local/D020/`。

```powershell
npm run typecheck
npm run build
node --test tests/unit/notes.test.mjs
node --test tests/integration/notes.test.mjs
node tests/browser/notes.mjs
```

## 验证场景

1. 在「笔记」独立写问题。从对照块选文当场新建，另一文件的纯讲解块选文加入该条笔记。添加两个标签，停服务、重开，用标签找回。每条链接应滚动并聚焦到文件内的正确块。删除独立笔记，重开后查另一条内容。
2. 等待一次真实保存后再输入，按 Ctrl+Z。核撤销结果重新落盘。控制一次较早响应延迟，核最新文字与状态。在 Windows 锁住原笔记文件制造替换失败，核旧文件、草稿和恢复重试。
3. 两页编辑不同笔记均可保存。同条从旧修订保存或删除时应明确冲突。保持 ID 改写讲解，另测临时缺档、畸形和当前缺块，核原链接及另一链接。恢复后再次回访。
4. 切换英文并用窄窗口查看操作、状态、列表与预览，确认用户内容保留原文。
5. 保存一条笔记，截断下一次保存的请求或响应。恢复连接后删除，分别确认原版本与成功提交的新版本均能删除，其他页面的新修订仍需要读者处理冲突。

正式版本更新的确认删除信号由后续更新联验承接。

## D035 工作台

构建后运行 `node tests/browser/record-workbench.mjs`。可用进程变量 `AFTERTASTE_D035_INPUT` 指定订单试读项目，脚本在新副本中添加长笔记，验证两处原句、非零侧栏位置、Tab 续读和窄窗读写。用 `AFTERTASTE_TEST_TASK=D035` 串行运行 notes、reader-history、bookmarks 和 understanding-marks 的浏览器用例，分别核真实写失败、保存中的历史、同块多书签及改标留原话。

## D036 · 带引用与空白新建

在试读副本先开笔记列表，搜索已有篇或新建；编辑标题、正文、标签后重开核结果。讲解选文加入直接落在原页浮层，连续加入两处，复制其中一处粘入另一篇，删除、撤销后比对落盘的原始链接。模拟一次真实保存失败，经列表找回重试。

## D041 · 三页详情对齐

按 [006 D041](../006-file-reader/quickstart.md#d041-三页详情对齐) 核长笔记起线、双栏与窄窗，回访《数量无效时，订单去哪了？》第一处引用，返回后用 Tab 到第二处。
