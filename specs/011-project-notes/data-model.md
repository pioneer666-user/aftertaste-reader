# Data Model: 项目笔记

## Note

`docs/aftertaste/notes.json` 为 UTF-8 JSON，根对象为 `{ "version": 1, "notes": [...] }`。没有文件时返回空列表。未知格式或无效资料拒绝写入。

| 字段 | 约束 |
| --- | --- |
| `id` | 小写 UUID v4，项目内唯一 |
| `revision` | 小写 UUID v4，每次提交生成，重试保持同一请求内容 |
| `title` | 可选的 Unicode 字符串；旧篇缺省时用正文首个非空行作列表名。 |
| `body` | 合法 Unicode 字符串，允许空正文，保留原样 |
| `tags` | 互不重复的非空白 Unicode 字符串数组，允许空数组，保留各项原样和顺序 |

## 块链接

正文可含零个或多个 Markdown 块链接。`[选文](<#aftertaste-block/文档路径编码/块ID>)` 中路径使用 `encodeURIComponent`，块 ID 沿用文档语法。文档路径属于当前资料镜像。选文用 Markdown 实体保留字面字符。点击时重新读取目标，不在写笔记时要求其他链接当前可用。普通网址沿用原 Markdown 策略。

## 从讲解加入

显式加入选文使用上述块链接写入浮层当前编辑篇；同一篇切至眼睛预览仍接收引文；关闭或停在列表时以引文新建。列表选择与工作台选择独立，共享按 ID 的草稿和修订。复制保留原始链接字节序列。

## 保存状态

客户端草稿可编辑、待保存、已保存或失败。输入与请求快照分开，较早确认只推进已存修订。发生冲突时保留草稿，待读者处理。删除优先检查本页最后确认的修订。前次保存结果未知时，版本冲突后只再检查那次提交的修订。服务端临时文件写入、同步并关句柄后，核原件与归属，替换成功才确认。
