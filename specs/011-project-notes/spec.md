# Feature Specification: 项目内全局笔记与跨文件回访

**Feature Branch**: `codex/feat-project-notes`

**Created**: 2026-11-19

**Status**: Ready for Planning

**Input**: [D020 派单](../../docs/work/2026/11/D020-project-notes/task.md)及[现行规则 R13、A13、A14、G4](../001-first-release/08-current-spec-and-acceptance.md)

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 随手记下问题并按标签找回 (Priority: P1)

读者在本项目的新笔记中写问题，添加几个自由标签，下次打开时按标签找回并继续编辑。

**Why this priority**: 记录问题随时都能开始，包括还没打开讲解时。

**Independent Test**: 独立创建无来源的两条记录，重启后按标签找到一条，删除另一条。

**Acceptance Scenarios**

1. 项目没有打开的讲解时，读者可新建无来源、无标签的笔记，填写正文后重开仍能看到。
2. 给一条笔记加两个标签，重开后用任一标签找到它。删除另一条后，这条的正文和标签仍完整。

### User Story 2 - 将两段讲解串联到一条笔记 (Priority: P2)

读者从对照块选文新建笔记，再从另一个文件的纯讲解块选文加入同一篇。

**Why this priority**: 阅读时可快速积累与同一问题有关的证据。

**Independent Test**: 选取不同文件的两个同 ID 块，从同一笔记逐一回访。

**Acceptance Scenarios**

1. 选中单个讲解块内的文字时可打开「加入笔记」。可新建或选现有记录，正文中追加有别于网址的链接，保留既有文字、标签和链接。
2. 重开后点击两段选文，各自滚动并聚焦到正确文件的正确块，目标块无需书签。
3. 同 ID 修改后沿原链接打开当前讲解，选文保持原样。文档暂缺、解析失败或当前没有目标块时显示对应原因。后续可以继续点另一链接，恢复后原链接可再次使用。

### User Story 3 - 异常时保住已存内容与输入 (Priority: P3)

读者等待保存完成后仍可以撤销输入。磁盘失败或另一页面先保存时，当前输入仍可继续编辑或重试。

**Why this priority**: 连续写作、临时故障与两个页面操作都涉及个人资料。

**Independent Test**: 连续输入并撤销，实际阻止一次替换，随后恢复并检查两页的竞争写入。

**Acceptance Scenarios**

1. 两次可区分的输入之间经历一次自动保存，Ctrl+Z 仍可撤销，结果自动保存并在刷新后出现。较早响应迟到时，新输入和保存状态保持正确。
2. 磁盘临时写入或替换失败时明确显示失败，旧文件完整，现有草稿可继续编辑。恢复后重试只有一条目标记录。
3. 两页修改不同笔记各自成功。同一笔记已被另一页面改动或删除时，陈旧操作收到明确的冲突信息，草稿保留。

**D035 验收场景 · 查标签、读原句和编辑**　搜「回」选「回访」，从长笔记中段回访并用键盘接读下一链接。两种窗口写完并读回正文与标签，在隔离项目验证撤销、写失败重试与选文新建／追加。

### Edge Cases

- 没有文档、笔记、标签或匹配结果时提供对应的空态和可用操作。
- 跨块、跨区域和纯源码选文不触发加入笔记。引号、括号、换行和 Unicode 原样保留。
- 畸形讲解、非法目标路径或失效链接均说明实际问题。读者可以继续使用同一笔记内的其他有效链接。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001** 项目内提供无来源、可选标签的笔记增删改查（05 FR-055、FR-056、FR-059）。
- **FR-002** 支持多个自由文字标签和按所选标签过滤（05 FR-057）。
- **FR-003** 从单个正常块的讲解选文，新建或追加可点击的正文链接，保留原选文、正文、其他链接和标签（05 FR-059、FR-060）。
- **FR-004** 内部链接与普通网址可辨，依据路径和块 ID 在当前文档滚动并聚焦。不可定位时说明原因并保留原链接（05 FR-060、U102）。
- **FR-005** 正文、标签、插入链接自动保存，反馈保存中、成功和失败，保存后可 Ctrl+Z（05 FR-061）。
- **FR-006** 写失败保留完整已存资料和当前草稿，恢复可重试。较早请求不覆盖最新输入，同服务内陈旧操作报告冲突（05 FR-058、08 A14）。
- **FR-007** 讲解 AI 按需只读本项目笔记，读者决定内容与去留（05 FR-063）。
- **FR-008** 操作、状态及失败反馈提供中英文，读者正文、选文和标签保留原文（D020）。

- **FR-009** 输入部分文字匹配已有标签，再按所选完整标签筛笔记。优先保留可见的选择，否则展示首条或可清除的空态。已有笔记直接阅读 Markdown 和标签，引用返回后原句可见且可用 Tab 续读。新建或点编辑后桌面左写右预览，窄窗切换编辑／预览保留输入。完成后回阅读，保存中和失败草稿可找回、重试；从讲解追加须明确选择。

### Key Entities

- **项目笔记**：读者拥有的独立正文及可选标签。
- **块链接**：正文的一部分，包含选文及当前项目文档路径和块 ID。
- **编辑草稿**：尚待保存的正文及标签，保留到保存成功或由读者放弃。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-005** 从视口中段打开长笔记的第一处引用，后退仍看见原句，Tab 接到第二处引用。两种窗口都可完成编辑并读回正文和原标签。

- **SC-001** 两条独立笔记中删除一条并重开，另一条可由两个标签分别找到。
- **SC-002** 同一笔记中的两条跨文件链接均落在对应讲解。在失效、改写和恢复场景中保留两条原选文，回访有效链接成功。
- **SC-003** 经过一次真实保存后仍可撤销，刷新后与撤销结果一致。一次实际写失败后原件完整，恢复时一次重试只保存一份。
- **SC-004** 两页改不同笔记均保留，陈旧编辑或删除有明确反馈且不会覆盖已保存内容。

## Assumptions

- 标签按单个所选文字精确筛选。笔记仍可用无标签筛选条件浏览。
- 首版使用阅读器的轻量入口。正式管理页面和理解标记按其他任务推进。
- 正式版本更新确认删除的信号由更新任务联验。本批用隔离的当前资料验证实际不可定位和恢复。
