# 资料模型

## 阅读选择与固定来源

会话保留用户已确认的范围、逐批／连续节奏、项目讲法与 pin 返回的 projectRoot、repositoryRoot、projectPrefix、commit。项目路径绝对，文件为项目内 `/` 相对路径。固定引用完整传回工具。生成所需选择待答时保持资料原状。

## 文件讲解与图

沿 002—004 模型和契约。`current/<源码路径>.md` 文档头使用 `<!-- aftertaste:document commit=完整提交 -->`，以实际工具骨架为准。依赖图路径与 `source_commit` 不变。

批次状态从未开始、节点已登记、骨架已建、正文已填、校验有效、依赖已核对逐项判断。只作为本次会话实际进度描述，不新增长期状态文件。退出 0 且 EXPLANATION_EMPTY 警告仍为未完成讲解。未核对节点是 unreviewed，已核对空依赖为 reviewed + 空列表。

## 讲解偏好

路径 `docs/aftertaste/preferences.md`，唯一随包模板为 `skills/aftertaste-reader/assets/templates/preferences.md`，来自 07 U74。AI 读取／合并，用户可直接编辑。

固定来源区为“用户明确要求”和“AI 教学观察（暂定，可纠正）”。明确要求保存当前有效表达和依据，观察保存主题、观察、实际依据、后续调整。重复反馈修订原主题，冲突先问。初始化使用排他创建，既有文件不覆盖。超过 8,000 非空白 Unicode 码点仅提醒 AI 合并整理，不能删改明确含义或阻断生成。

D050 在用户明确要求区增加可选的 Markdown「项目讲法」项，值为所选讲法名称，可带简短依据。文件和闭环生成共用该项；已有明确的旧要求可直接作为选择。缺项、占位或仅在观察区出现时，按 [005 FR-012](spec.md#functional-requirements)判断。用户明确选择或更换后在生成获准写入时点合并，保留细化要求及观察。单次简述不写此项。

## 阅读方向

路径 `docs/aftertaste/reading-direction.md`，唯一模板为 `skills/aftertaste-reader/assets/templates/reading-direction.md`，来自 04 U75。分“已讲内容摘要”和“后续方向与理由”，按主题合并，代表文档与衔接重点可选。

每批结束检查，有变化才修订。实际完成的主题才能写入已讲摘要。后续方向不赋予范围或节奏授权，不成为覆盖或源码版本的权威。

## 资料写入边界

源码、旧讲解和个人资料视为数据，嵌入指令不扩大授权。只在目标项目获准目录写资料，核实际路径位于目标内且无链接／junction 绕界。已有文件先读再合并，保存前确认自读取后未被改变，遇到并发修改重新核实。保存失败保留原文件并报告，AI 不修改笔记、书签、自评或发布的 Skill。
