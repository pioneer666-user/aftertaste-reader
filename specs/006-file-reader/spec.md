## User Scenarios & Testing *(mandatory)*

### User Story 1 - 打开指定项目并逐块阅读 (Priority: P1)

用户启动指定项目的本地阅读器，选择实际存在的讲解，逐块对照它所引用提交中的源码。

**Why this priority** 这是当前讲解进入日常阅读的完整入口。

**Independent Test** 从其他工作目录启动 D010 可重建样例，选择两篇讲解，检查真实行号、正文与提交，再停止和重启。

**Acceptance Scenarios**

1. **Given** 项目有两篇讲解，**When** 启动并选择文件，**Then** 镜像完整路径区分目录及扩展名，显示文档路径与完整提交。
2. **Given** 合法文档含两类块，**When** 阅读，**Then** 对照块左源码右讲解，纯讲解块只有正文，Markdown 示例与源码可区分，所有源码行含空行、注释及长行均可查看。
3. **Given** 文档引用提交 A，**When** 修改工作区或 HEAD，**Then** 阅读仍使用 A。修改讲解并刷新后，正文、范围与检查全部来自同次磁盘读取。
4. **Given** 没有讲解，**When** 打开页面，**Then** 显示空状态。端口被占用或项目不可读时给启动诊断，正常关闭后可重新启动。

### User Story 2 - 资料有问题时继续读并定位修复 (Priority: P1)

用户直接打开未校验或有错误的文档，仍能阅读已有讲解并取得可交给 AI 的修复信息。

**Why this priority** 手改资料及 Git 读取失败是正常使用必须处理的状态。

**Independent Test** 分别制造结构错误、范围遗漏、Git 对象不可用和文档不可读，检查可见状态与复制内容。

**Acceptance Scenarios**

1. **Given** 块或范围有误，**When** 直接打开，**Then** 显示稳定问题标识及定位，安全地按普通 Markdown 展示原文，提供可复制修复信息。
2. **Given** Git 仓库或引用不可读，**When** 打开讲解，**Then** 列表及讲解可读，源码明确不可用，修复信息含实际可确定的提交与路径，检查状态如实呈现。
3. **Given** 文档本身不可读取，**When** 打开，**Then** 显示读取错误。超大块仅警告，空正文显示未完成。

### User Story 3 - 切换界面语言并保持阅读 (Priority: P2)

用户可以选择简体中文或英文，继续阅读当前文件，浏览器记住有效的选择。

**Why this priority** B003 要求首份正式页面就具备双语界面。

**Independent Test** 在阅读中切换语言并刷新，禁用浏览器存储后再切换，检查位置和正文。

**Acceptance Scenarios**

1. **Given** 没有有效保存值，**When** 打开，**Then** 默认简体中文。已有有效保存值时恢复选择，缺翻译回退中文。
2. **Given** 正在阅读，**When** 切换语言，**Then** 当前文档和阅读位置保留，所有界面及无障碍文案切换，用户内容保持原文。
3. **Given** 浏览器无法保存，**When** 切换语言，**Then** 本页切换可用并明确提示保存结果，仅界面语言会被持久保存。

### User Story 4 - 从项目文件树打开讲解 (Priority: P1)

读者按目录找到已有讲解，读到需要更宽的正文时收起侧栏，再展开可接着浏览文件。

**Why this priority** 目录分清同名文件，释放宽度能改善源码与讲解的并排阅读。

**Independent Test** 用键盘从文件树的两个同名叶项进入各自的讲解，收起再展开，核当前文件、目录和阅读位置。

**Acceptance Scenarios**

1. **Given** 项目有不同目录下的同名文件，**When** 展开目录或由已有记录回访，**Then** 可辨认当前文件及其目录，并可查项目及文件的完整路径。
2. **Given** 已打开目录并滚到块中部，**When** 用阅读页左上图标收栏再固定展开，**Then** 目录展开状态和当前阅读块仍在。
3. **Given** 窄屏，**When** 用键盘打开导航、选文件或直接关闭面板，**Then** 选中后可接着读正文，关闭后可从展开入口继续操作。
4. **Given** 桌面侧栏已收起，**When** 鼠标指向阅读区左缘再移入侧栏，**Then** 侧栏临时展开，保持正文宽度、焦点与阅读位置。离开临时侧栏且焦点在外时收合，也可用左上图标将其固定。
5. **Given** 正在读一篇讲解，**When** 用鼠标或键盘从文件树打开另一篇，**Then** 可立即辨认所选文件。读取稍久时，读者在眼前看到目标和阅读占位，随后从新篇篇首接读。
6. **Given** 另一篇在等待中，**When** 改点文件、离开阅读页或收到读取失败，**Then** 可继续在最后选择的位置操作。读取失败时可回到原读点及草稿，并再次打开同一文件。

### User Story 5 - 从本篇目录跳到讲解块 (Priority: P1)

读者按讲解顺序查看本篇各块，跳到想读的位置，也能从高亮项看出当前读到哪里。

**Why this priority** 文件较多或讲解较长时也能直接找到所需的段落。

**Independent Test** 在同一篇讲解中分别选取标题相同的两项，再切至含对照块、纯讲解块与无标题块的不同讲解，核跳转与当前项。

**Acceptance Scenarios**

1. **Given** 讲解有标题、无标题、只有代码或空正文的块，**When** 打开本篇目录，**Then** 每块按原顺序有一项，依次取可读标题、首句短摘或位置。对照块位置用实际源码行范围，纯讲解块位置用在文档中的序号。
2. **Given** 存在重名标题或不同文档复用同一块 ID，**When** 选择条目、手动滚动或快速切换文档，**Then** 每项跳到所选文档的对应块，当前项随正文更新，手动滚动期间焦点留在原控件。
3. **Given** 文件树很长或窄屏导航已打开，**When** 查找本篇目录并用键盘跳块，**Then** 本篇目录容易找到，选中后焦点到目标块，窄屏回到正文。
4. **Given** 文档降级为普通 Markdown，**When** 打开此文档，**Then** 继续呈现诊断和降级讲解，只在可靠块结构可用时提供块目录。切换语言时，新控件与位置回退随界面翻译，讲解中的标题和摘句保留原文。
5. **Given** 文件树与有效的本篇目录同时显示，**When** 上下拖动中间分隔线，或聚焦分隔线后用方向键调节，**Then** 两部分可用空间随之调整，均保留滚动与选择能力，收栏重开后保留调节结果。

### User Story 6 - 阅读正文并回访个人记录 (Priority: P1)

读者先阅读讲解，按需展开保存的书签和批注。从项目列表返回时直接看到点选的个人记录。

**Why this priority** 日常正文在先，回看时可直接确认自己的收藏理由或疑问。

**Independent Test** 从同块的两条书签分别用键盘回访，再从「不理解」与项目笔记中的跨文件链接返回讲解，核落点、原话和编辑。

**Acceptance Scenarios**

1. **Given** 块已有书签或批注，**When** 日常打开讲解，**Then** 标题和讲解在先，下方可见理解状态及展开记录的入口，展开后可查看原话与操作。
2. **Given** 同块有多条书签，**When** 从项目书签点选某条，**Then** 阅读区显示、定位并聚焦该条记录。由项目标注回访时，可直接看到该块理解状态与已有批注。
3. **Given** 读者改状态、编辑或清空记录，**When** 成功提交、保存失败或离开再回原块，**Then** 既有独立编辑、草稿保留和错误反馈继续可用。选文加入笔记和从笔记跨文件回访继续有效。

### User Story 7 - 留在当前讲解查项目资料 (Priority: P1)

读者可以从项目名查阅完整项目路径与当前讲解引用的源码版本，再从刚读的位置接着读。

**Why this priority** 常用的阅读空间留给讲解，查版本时仍能拿到完整资料和正常校验结果。

**Independent Test** 滚到当前篇中段，从左缘唤出侧栏，打开项目资料，选取路径并关闭。切换文件确认资料随正文变化。

**Acceptance Scenarios**

1. **Given** 在正文中段，**When** 从固定或临时侧栏点击项目名，或用键盘开启，**Then** 资料浮窗显示可选取的完整项目路径、当前讲解引用的完整源码提交和正常校验结果，临时侧栏可在移入及选文时继续操作。
2. **Given** 资料窗已打开，**When** 按 Esc 或点击窗外，**Then** 浮窗关闭并保留正文位置。首次 Esc 后临时侧栏仍在，焦点回项目名。
3. **Given** 切换、加载或读取失败，**When** 查询资料，**Then** 文档专属字段随实际显示结果更新，影响阅读的问题仍可从正文前发现并取得修复信息。

### User Story 8 - 逐段对照同一块源码 (Priority: P1)

读者从文件题头进入原讲解，滚动几段时仍能看到当前块较短的固定源码。

**Why this priority** 源码与讲解是主要阅读内容，两者在恰当位置交接能减少来回滚动。

**Independent Test** 读服务文件的两条 import 和中间空行，滚过块尾，检查长源码、长行与纯讲解的呈现。

**Acceptance Scenarios**

1. **Given** 当前讲解有可用块，**When** 打开文档，**Then** 一行主标题区分浅色目录与较突出的完整源码文件名，当前讲解的项目相对路径在主标题下以小号字呈现。经分隔后从各块的原 Markdown 标题或首段阅读。纯讲解块只呈现原文，正文代码示例可与固定源码区分。
2. **Given** 宽屏及能完整放进可视区的短源码，**When** 滚动长讲解并越过块尾，**Then** 左侧源码先随本块停留，再让位给下一块。空间不足时整块随阅读区滚动，最后一行可读。
3. **Given** 有长行、空行或缩进，**When** 横向滚动固定源码，**Then** 行号留在源码左缘，源码文本到行末仍可读。窄屏按源码后讲解的顺序阅读。

### User Story 9 - 复制块定位去 AI 会话提问 (Priority: P1)

读者能从选中的疑问句或整个块取得定位，留在原处继续读，再自行粘贴到同项目的 AI 会话。

**Why this priority** 提问需要文档、块和固定版本，选文用于说明具体疑问。

**Independent Test** 选中讲解片段后从浮条复制并粘贴，从其他块直接复制，解析比较路径、块 ID、提交和选文。验证写入被拒绝时手动复制同一文本。

**Acceptance Scenarios**

1. **Given** 在同块讲解内选择非空原文，**When** 松开指针或用键盘完成选择，**Then** 可到达复制定位操作。鼠标划选时入口邻近松手端并避开窗口边缘，反向选择同样有效。
2. **Given** 读者想问整块，**When** 从原标题旁或无标题块首执行复制，**Then** 得到当前块的定位，选文字段省略。缺少可靠块身份或提交时沿现有诊断。
3. **Given** 执行复制，**When** 成功或浏览器拒绝写入剪贴板，**Then** 就近反馈成功，或提供可手动复制的同一完整文本。普通 Ctrl+C 保持原生选文复制，同一浮条可把原选文加入笔记。
4. **Given** 跨块、跨到固定源码、只选择源码、取消选区或切文件，**When** 原操作目标失效，**Then** 浮条收起，旧目标不可复制。语言切换后文案随界面更新，目标与当前正文对应。

### User Story 10 - 从左上切换页面 (Priority: P1)

读者可从左上识别当前页，切到其他页面阅读或查看记录。

**Why this priority** 文件讲解与依赖图需要随手往返，其他页面也应使用同一导航顺序。

**Independent Test** 从讲解切到依赖图，依次访问其他页面并核当前状态。切换英文和窄窗后以键盘重复。

**Acceptance Scenarios**

1. **Given** 桌面视口，**When** 从任意一页切到另一页，**Then** 两个箭头、侧栏开关和页签位置、顺序与名称一致，当前页、悬停和键盘焦点可区分。
2. **Given** 当前页有独立辅助区，**When** 使用顶栏开关，**Then** 可显隐对应区域并辨识展开状态。没有适合区域时，开关仍在原位，显示禁用态及原因。
3. **Given** 英文标签或较窄视口，**When** 页面入口需要收纳，**Then** 读者仍可辨识当前页、打开任一页面，并抵达该页可用的导航工具。

### User Story 11 - 前进或后退到刚才的阅读位置 (Priority: P1)

读者在图、讲解和个人记录之间往返，沿刚才走过的路径接着读。

**Why this priority** 从关系进入长篇讲解后，重新找图上节点或文中段落会中断阅读。

**Independent Test** 从图中选中的文件打开讲解，读到中段后切到书签。后退两步再前进，核图与讲解的落点。

**Acceptance Scenarios**

1. **Given** 已走过多个页面或讲解目标，**When** 后退再前进，**Then** 按实际访问顺序恢复位置，边界处箭头禁用。回退后去新的目标，前进分支随之清除。
2. **Given** 从筛选后的记录打开讲解块，**When** 返回列表或再次前进，**Then** 可继续从原条目或原块读，当前记录和草稿仍可使用。
3. **Given** 目标在访问后已改变或失效，或早先读取晚于后续操作结束，**When** 继续导航，**Then** 读者到达最后一次有效请求指向的可用位置。失效原因可查，旧结果不能改写当前阅读位置或历史。

### User Story 12 - 沿同一套轮廓阅读与操作 (Priority: P1)

读者打开文件，从共用顶栏、侧栏和源码一路读到段落末尾，并能辨认选中、悬停、键盘焦点和展开状态。

**Why this priority** 打开讲解时，小按钮、目录选中行和大源码板同时出现在同一视野。

**Independent Test** 在桌面和窄窗打开同一篇服务讲解，按 SC-016 对照阅读位置、控件状态与外轮廓。

**Acceptance Scenarios**

1. **Given** 当前文件与块已选中，**When** 阅读源码并展开项目资料或块后记录，**Then** 小控件、选中行和面板采用随尺寸变化的同族转角，焦点可辨认。
2. **Given** 用键盘操作、打开窄窗菜单或剪贴板写入失败，**When** 在控件与浮层间切换，**Then** 焦点完整，选文、编辑和滚动仍可操作。

**D035 验收场景 · 个人记录的侧栏与返回**　在三页依次收起和打开侧栏，用窄窗键盘选择第二条，再从原文后退，核两处滚动、焦点及资料字节。

### Edge Cases

- 同名异目录、同主名异扩展名、Unicode 和空格路径，空源码，空讲解，60/61 行及 1200/1201 码点边界，超长源码行。
- 快速切文件或刷新时旧请求晚返回，当前选择和正文仍一致。
- 资料目录不可读、非法镜像、链接/junction、硬链接、Windows 设备名/尾点/尾空格/ADS、编码穿越及任意文件请求。
- 外部网页访问、恶意 Host/来源、不可信 Markdown/HTML/URL，浏览器断网读取。
- 块首标记需按 Markdown 语义辨认。标题内的行内样式呈现为可读文字，代码围栏内的「#」不生成标题。仅代码或空白用位置回退。
- 窄屏关闭导航时可恢复正文操作。通过记录切入异目录文档时能找到当前条目。同块多书签回访按所选记录区分。
- 资料浮窗避开窄视口边缘，完整项目路径可辨认、选择。题头的长讲解路径在窄屏可断行。加载中的新篇不借用上篇的讲解路径、提交或校验。
- 向左或向上选择、窗口边缘选择、引号与换行、仅空白、跨块及跨入源码分别检验。降级正文缺少可靠身份时使用原诊断。
- 重复打开同一目的地、回访失败、后退后另择目标、挨次快速点击和刷新重启历史分别核对。返回时资料若有修订，按实际仍可用的目标恢复。
- 连续圆角按实际控件尺寸成形。窄窗内的菜单或浮层嵌套、多行选中项、兼容浏览器与系统强制色均需核焦点完整。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001** 对应 W01。提供显式绝对项目路径的启动与关闭方式，从任意 cwd 提供同一预构建页面，仅回环监听，启动失败可诊断且保护既有进程。
- **FR-002** 对应 W02。发现 current 实际讲解并按完整镜像路径选择，区分空态和错误，显示文档路径、实际提交，刷新读取磁盘内容。
- **FR-003** 对应 W03。复用已定块规则及固定源码，按原序完整展示两类块、行号、Markdown 和代码，保留长行、空行及注释，同一次读取支撑正文与校验。
- **FR-004** 对应 W04。直接打开执行必要校验，错误时提供安全普通 Markdown 与无源码正文的可复制定位、问题、下一步。Git 失败保留讲解阅读，文档失败真实报错，大块仅警告、空正文未完成。
- **FR-005** 对应 W05。中英文覆盖本批全部界面状态和无障碍文案，默认中文、有效持久选择优先、缺键回退中文，存储失败本次可切换且保留文件和位置，用户正文保持原文。
- **FR-006** 对应 W06。文件讲解与固定源码以只读方式访问，范围限于启动项目允许的资料，路径及来源边界可核验，安全呈现不可信内容，离线资源随构建提供，动态正文与源码只在运行内存使用。个人记录编辑沿其已批准的入口和资产保护规则。
- **FR-007** 阅读区侧栏顶部优先显示项目名，完整项目路径可查。上半部仅列已有讲解对应的源码，以文件夹展开／收起和文件名叶项导航，完整路径可区分同名项。打开文件或从记录回访时可辨认当前叶项及其目录。
- **FR-008** 阅读页左上角以常驻小图标切换侧栏，收起让出阅读宽度。桌面收起时从阅读区左缘悬停可临时查看侧栏，保持正文布局和阅读位置，可用图标固定。重开保留目录展开状态和当前阅读块。窄屏通过图标开启，选文件或跳块后回正文，支持键盘选择和关闭。
- **FR-009** 下半部按原序提供本篇块目录，文件树很长时也能找到目录。文件树与块目录之间的分隔线可拖动，也可用键盘调整。每块取块首标题的可读文字，或无标题时首句可读正文的短摘。对照块和纯讲解块的最终回退分别用真实源码行范围和文档内块序号。每项按文档路径与块 ID 定位，快速切换时目录与当前正文对应，手动滚动更新当前项且不改变焦点。降级页保留诊断，仅在有可靠块结构时提供块导航。界面文案按 FR-005 切换。
- **FR-010** 标题、讲解排在编辑控件之前，普通阅读可见理解状态及已有书签、批注的展开入口。项目书签回访显示并聚焦所选记录，项目标注回访呈现该块状态与已有批注。保留三态、编辑与清空、失败与草稿反馈、选文加入笔记和键盘回访，沿 [R13—R15](../001-first-release/08-current-spec-and-acceptance.md)保护记录。
- **FR-011** 共用顶栏依次放置后退、前进、侧栏开关及「文件讲解、文件依赖图、闭环阅读、书签、标注、笔记」。六页位置一致，页名固定。箭头不可达时原位禁用。侧栏开关以当前页的区域命名并反映展开状态，讲解页控制文件树与块目录，依赖图控制浮条，闭环页始终控制左侧闭环目录，其他页可接入可独立收起的既有辅助区，例如笔记列表。无适合区域时原位显示可说明原因的禁用状态。悬停、键盘焦点和当前页可区分，语言左侧的全局新建笔记在桌面显示纸笔图标和文字、窄窗显示有名称的图标，按 [011 FR-010](../011-project-notes/spec.md) 在右上角打开随手记，后台页面的尺寸、位置与访问历史保持稳定。保留刷新资料、语言、键盘跳过导航与窄窗切页入口。
- **FR-012** 阅读侧栏的项目名带展开提示，点击或用键盘开启资料浮窗。完整项目路径、文档所引完整源码提交与正常校验结果可查阅和选取。正常切篇时元数据随已显示的文档更新，影响阅读的诊断仍在正文前并保留修复入口。临时侧栏支持移入及选择浮窗文字，首次 Esc 关闭浮窗并回焦项目名，窗外点击也可关闭，正文位置保持。
- **FR-013** 文件题头以一行显示源码路径并突出文件名及扩展名，可辨认长路径。主标题下方以小号字显示可选取的当前讲解项目相对路径，切篇后同步更新，窄屏可断行。题头与首块有分隔。原 Markdown 标题或首段先行，纯讲解块用正文宽度。正文代码示例与固定源码有明确视觉区别。桌面左源码右讲解。浅绿源码底板贴合内容，符合 SC-011 的短源码在本块停留并于块尾让位，其余随主阅读区滚动。横向滚动保留左缘行号和完整原文，窄屏上下排列。
- **FR-014** 有效讲解块支持直接复制及选文浮条。浏览器根据同块内的非空讲解选区定位松手端，临近边缘避让，键盘可达。整块入口贴近原文开头。复制文本按 [U73](../001-first-release/05-reading-feedback.md#u73--复制文档块定位-v1作者授权-ai-定稿)生成，剪贴板写入失败时提供同一可选文本，成功就近反馈。选区失效收起、切篇清除目标，文案双语。细指针下常态浮条外框高 32 CSS px，两个命中区各 28 × 28 px，粗指针各至少 44 × 44 px。白灰半透明表面带约 4 px 模糊、上沿高光与轻阴影。浮条只显示复制块定位和加入笔记两个图标，两者悬停、键盘聚焦时可见名称，读屏与窄窗点按可区分。出现、提示与收起时正文和块尾记录保持原位。普通点击或拖选正文保持安静；目录与笔记引用显式跳转时在讲解标题或开头旁短暂显示细线，键盘焦点持续可辨，减少动态及强制色下仍能定位。保持原生选文复制，定位操作仅发生在当前文件阅读页。
- **FR-015** 当前打开的标签页记录成功切页、显式打开不同文件及由记录跳转到讲解块的访问顺序。重复打开同一目的地或失败回访不增加步骤。滚动、选图节点、筛选、显隐详情、平移、缩放、打开随手记、预览、关闭和编辑保存留在当前步骤。后退后另开目的地清除前进分支。浏览器重新加载页面时从实际进入的页重新起步。多次操作以最后一次有效导航为准，过期读取不能抢回焦点或改写历史。
- **FR-016** 站内往返使用当前资料。讲解按文档、所读块和块内位置恢复，由书签或标注初次回访沿 FR-010。依赖图按 [007 FR-002](../007-dependency-canvas/spec.md#functional-requirements) 恢复对象和视野。书签、标注及笔记恢复条目、筛选和列表位置，闭环按 [009 FR-008](../009-loop-reader/spec.md#functional-requirements) 恢复。保留笔记草稿、已改文字、节点坐标及组成员。目标失效时给出可用位置与原因。

- **FR-017** 六页的共用顶栏和窄窗页签菜单，以及 FR-007—014 涉及的文件讲解选中行、有底色或边界的表面、随读操作与反馈，使用同族圆角。小控件的转角收紧，整行选中底、浮窗与大面板按实际尺寸舒展，保留直边。焦点、填充与边线沿同一轮廓。行内代码只保留微小转角。正文原有分隔、图标、树连接线、滚动条与贴窗直边沿用现有形态。图、闭环正文和管理页内部沿各自的页面规则。

- **FR-018** 从文件树显式打开与当前讲解不同的文件时，目标行及阅读区在下一次可绘制更新中标明正在打开的目标。读屏获得简短的双语状态，窄窗或临时侧栏收起后仍可见反馈。当前项保留到成功才更新。快速返回直接呈现新篇。等待稍久时，在当前阅读视口显示已知源码路径和浅色阅读占位，题头及两栏沿 FR-013 的起点，随同一断点上下排并沿 FR-017 使用连续角。源码板和讲解段落长短交错。并排时源码及讲解骨架均铺到当前视口底部，上下排时源码放在开头，讲解铺满其下的视口。占位保持顶栏、文件树和阅读外框稳定。此时隐藏原篇目录、文档元信息及正文，暂时停用原篇读写动作。成功时题头、路径、源码、讲解和目录同步对齐并从篇首可读，普通 Markdown 降级和纯讲解块沿原有呈现。系统减少动态效果时静态交接。
- **FR-019** 等待期间文件树、切页与站内导航仍可用。改点只提交最后有效目标，离开阅读页结束反馈，迟到结果不能恢复反馈或抢焦点。读取失败指出可区分同名文件的路径和原因，保留原篇、块内位置、该块的记录草稿和访问历史，允许再次选择同一文件。显式切篇仍重读磁盘。首次打开、资料刷新、图或个人记录回访、前进后退沿用既有语义。

- **FR-020** 笔记、书签、标注三页初次进入选择首条。桌面能收起列表，窄窗分别显示列表或整宽详情，选择一条后回到详情。站内历史保留当时仍存在的条目、筛选及两个区域各自的滚动位置。查看、筛选及返回不触发个人资料写入。

### Key Entities

- **阅读项目** 启动时指定的唯一项目，包含讲解镜像与可能可用的 Git 映射。
- **文档条目** 实际文档路径与推导的源码路径。
- **阅读结果** 单次读取原文、解析块、固定提交、源码行、校验状态和结构化诊断。
- **界面语言** 中文或英文，独立于讲解、源码和个人内容。
- **块目录条目** 标题、首句短摘或位置回退，关联当前讲解的文档路径及块 ID。
- **个人记录落点** 文档路径与块 ID 标记原块，书签另用记录身份区分同块的多条收藏。
- **站内访问位置** 一次访问对应的页面、内容身份和阅读位置，供本标签页前进和后退。
- **项目资料** 项目目录和当前已显示讲解的源码提交及校验结果，供查阅和选取。
- **文档块定位** [U73](../001-first-release/05-reading-feedback.md#u73--复制文档块定位-v1作者授权-ai-定稿)定义的当前实际文档、块、固定源码提交与可选原文引用。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-018** 在窄窗从三个列表各选一条，详情使用整宽。站内返回能恢复双区位置；只浏览三页期间个人记录写请求为零。

- **SC-010** 服务讲解中段从左缘展开临时侧栏，打开项目资料、移入窗内、实际选取完整项目路径。首次 Esc 保有侧栏、恢复项目名焦点及原阅读位置。重新开启后窗外点击可关闭。换篇后浮窗显示项目路径、当前文档所引提交与正常校验结果。讲解文档路径在题头下可查。有问题的讲解仍从正文前获得诊断。
- **SC-011** 以 1440×900 CSS px 验桌面题头、中文内容与两栏交接，宽 1051 CSS px 保持并排，宽 1050 CSS px 与 390×844 CSS px 改上下排列。讲解路径在主标题下以 11 CSS px 字体呈现，换篇随正文更新，窄屏可断行且路径完整可选。在并排模式，当源码底板高度加上下各 16 CSS px 可容于主阅读可视区时，停留处距阅读区顶边 16 CSS px，越过块尾后本块源码随之退出。服务文件第一块的 1—3 行含一个空行且仅出现一次，滚到下一块再看长讲解对应的 7—10 行。使用隔离长源码及 1440×320 CSS px 矮窗检查普通滚动可读末行，横移长行时左缘行号不移动。`support/audit.mjs` 的纯讲解句「从已有名字构建路径。」只呈现一次且无空源码栏。
