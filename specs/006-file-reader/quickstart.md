# Quickstart · 逐文件源码对照阅读

需要 Node 24、Git 2.45+。首用时按 [README](../../README.md#首次安装)安装预构建包，用 [日常启动命令](../../README.md#日常打开与关闭)打开指定项目。页面、脚本和字体均由同一回环服务提供。按 [D045 实验](../../experiments/D045-alpha-first-run/README.md)从独立安装目录启动、打开真实讲解并关停重开。

以下开发回归使用产品根的锁定依赖，执行 `npm run typecheck`、`npm run build`，再执行 `node dist/cli/main.js serve --project <目标项目绝对路径>`。从启动输出读取地址。端口占用可指定 `--port`。终端 Ctrl+C 关闭，看到 `stopped` 后可重启。

D010 合成样例使用 tests/fixtures/reader-project.mjs 重建到全新隔离目录，复制 D010 两篇原件并核固定提交。实际作者入口、可复制命令与资源归属见 [D011 handoff](../../docs/work/2026/11/D011-file-reader/handoff.md)。

## 可复核场景

1. 从产品根以外 cwd 启动，选择 rules 和 service，核文档路径、提交、行号和 Markdown 示例。
2. 修改样例工作区及 HEAD，刷新仍取头部提交。改讲解再刷新，显示新正文和对应检查。
3. 切换英文并刷新，保留已保存语言。屏蔽 localStorage 后仍可切换，明确保存失败。
4. 结构错误及范围遗漏按普通 Markdown 展示并可复制无源码诊断。移走样例 Git 后仍能列出并阅读讲解。不可读文件显示读取错误。
5. 测试路径、Host/Origin、恶意 Markdown，核接口 no-store、CSP 和目标目录前后字节。
6. 停服务再启动，重开仍可读。自动化依次使用 npm test 与 npm run test:browser，浏览器串行。

样例是合成教学资料，真实项目教学与作者体验状态由 handoff 单独记录。

## D022 导航与记录

在仓库根以 Node 24 执行 npm run typecheck 和 npm run build。按[试读重建说明](../../tests/README.md#页面改版共用试读)在 .local/D022/ 内另建一份样例，使用与作者入口不同的空闲端口。保存失败、编辑和草稿检查在隔离副本完成。

1. 展开 src 并打开 service.mjs，依次跳本篇第二、第三块。滚动后核当前项，收起并恢复侧栏，核文件、展开状态和正在读的块。窄屏仅用键盘打开导航、选文件、跳块并关闭面板。
2. 从 support/audit.mjs 的两项分别找到对照块和纯讲解块。用补充的同名文件、重名标题、仅代码或空正文及降级页核对应落点和回退。切换语言并快切文件，核当前正文、目录、原文与当前项。
3. 从数量规则的项目书签回访，核同一块的两条记录能分别聚焦。由「不理解」打开原疑问，再从笔记链接跨文件回访。编辑、清空或触发保存失败后，核既有反馈与草稿。核 FR-011 的六个共用页签。

试读调整复核 SC-009。在常规桌面以及 851 CSS px 宽的桌面边界检查中英文顶栏单行 48 CSS px，左上角为侧栏图标。将正文滚到一处，点图标收起，移鼠标到工作区左缘，移入浮现的侧栏再离开。核浮层展开和收合、正文宽度及位置保持，并试用图标固定。拖动分隔线并用方向键调节，收起再开时比例保留。在 1440×320 的矮窗口通过拖动及 Home、End 检查较小的一侧仍有完整的可选项。换窄视口点左上图标并选一项，核面板关闭并可接着读正文。

补充回归使用 tests/browser/reader-navigation.mjs 和受影响的既有浏览器检查，按验证约定串行。作者体验沿[共用试读入口](http://127.0.0.1:4341/)。

## D023 项目资料、阅读中区与复制定位

沿[试读重建说明](../../tests/README.md#页面改版共用试读)在 .local/D023/ 建隔离项目，使用独立空闲端口。以同一组选篇分别从改前和候选截图，用候选实走连续滚动、浮窗选择及粘贴。先以 Node 24 执行 npm run typecheck、npm run build，再运行 `node tests/browser/reader-center.mjs`。按 [SC-010—012](spec.md#measurable-outcomes)核实际结果与视口。写入式操作都在隔离项目中完成。

1. 打开 `src/service.mjs` 并滚至块中部，收栏后从左缘进入临时侧栏。用鼠标和键盘分别打开项目资料。移入窗内并选择完整项目路径，按 Esc 观察焦点、侧栏和阅读位置，重开后点击窗外。切换讲解并核浮窗显示项目路径、当前源码提交和正常校验结果，另用有问题的讲解查看正文前诊断。
2. 按 SC-011 的桌面、实际分栏临界值、窄屏和矮窗检查题头与正文。用服务与审计讲解核标题下完整的小号讲解路径、其选取与切篇更新，窄屏用长路径检查断行。滚过服务首块和长讲解的块尾，核源码停留与交接。用隔离长行、长源码核行号和末行。打开 `support/audit.mjs` 核纯讲解块。记录改前与候选的题头和候选滚动、浮条实图。
3. 按 SC-012 从服务首块选文，实际粘贴后以 [U73](../001-first-release/05-reading-feedback.md#u73--复制文档块定位-v1作者授权-ai-定稿) 还原。另复制第二块及无标题纯讲解块。隔离副本改 HEAD 并继续核原文档引用，用包含引号与换行的选文比较粘贴结果。
4. 分别反向选文、在边缘选文、用键盘完成复制、跨块、跨源码及取消选区，再切篇和语言。检查原生 Ctrl+C 与浮条加入笔记，模拟剪贴板拒绝写入后手动选取文本、复制、粘贴并比对。受影响的导航、书签、批注及笔记按 D022 入口串行复验。

## D026 共用顶栏

沿 [007 的共用副本与命令](../007-dependency-canvas/quickstart.md#d026-依赖图首屏与框选分组)验证 [SC-013](spec.md#measurable-outcomes)。从讲解依次切六页，用鼠标与键盘核当前状态，切英语后收窄至导航开始收纳，检查临界点两侧，再用窄窗走键盘路径。讲解侧栏开关、右侧工具和图到讲解的返回入口实际可用。依次运行 `node tests/browser/reader-navigation.mjs` 及受影响的个人记录回访脚本，证据归 D026。

## D028 站内往返与顶栏

从 [共用试读](../../tests/README.md#页面改版共用试读) 固定输入，沿 [007 同窗对照](../007-dependency-canvas/quickstart.md#d028-浮层与闭环联验) 在 `.local/D028/` 留 D027 和候选证据。依次执行 `npm run typecheck`、`npm run build`，在 PowerShell 设置 `$env:AFTERTASTE_D028_INPUT` 指向固定输入，再运行 `node tests/browser/reader-history.mjs`。其余直接受影响的脚本串行运行。

- 按 [SC-013](spec.md#measurable-outcomes) 量测坐标并用键盘验证中英文入口。
- 按 SC-014 走依赖图、讲解中段、书签的往返，并验证分支、重复入口及浏览器重新加载。
- 按 SC-015 走标注和笔记跨文件回访，在副本模拟失效、读取延迟及保存失败，观察原位草稿和最后有效落点。闭环右栏跟 007 同轮核验。

## D029 连续圆角

按 [共用试读重建说明](../../tests/README.md#页面改版共用试读)固定一份订单项目。分别使用 D028 固定构建与本批构建启动副本，从 `src/service.mjs` 的「更新集合、调用辅助函数、返回同一对象」块对照 [SC-016](spec.md#measurable-outcomes)。用同一视口、100% 页面缩放、相同的选中及焦点状态拍整窗与原尺寸局部。项目浮窗退回项目名，源码区可聚焦，例码可选，窄窗菜单焦点完整，打开块后批注和书签时对照外壳、输入框和动作。

用 Node 24 依次运行 `npm run typecheck` 和 `npm run build`。设置 `AFTERTASTE_TEST_TASK=D029` 与 `AFTERTASTE_READER_INPUT`（上述固定副本路径），按 Edge、Chrome、Firefox 依次运行 `node tests/browser/reader-center.mjs`。脚本在各自副本验证原生选文复制、剪贴板拒绝、长行横滚及小窗末行。设置 `AFTERTASTE_BROWSER=edge` 后串行运行 `tests/browser/reader-history.mjs` 及受影响的记录回访。强制色时看键盘焦点。图内节点、框选浮条和管理页内部用同一输入短访核对。实图、日志和副本归 `.local/D029/`。

## D030 文件树切篇

先执行 `npm run typecheck` 与 `npm run build`。从仓库根运行 `node tests/browser/reader-file-switch.mjs`，用 [共用试读固定输入](../../tests/README.md#页面改版共用试读) 建立隔离副本，按 [SC-017](spec.md#measurable-outcomes) 保存逐帧时序、操作数据及实图到 `.local/D030/`。默认 Edge，也可逐个指定 Chrome 或 Firefox。随后串行复用 `tests/browser/reader-navigation.mjs` 和 `tests/browser/reader-history.mjs`。

独审使用同一固定构建与副本。共用 4341 试读使用原项目和自然响应，只在隔离副本阻断、延迟或修改资料。

脚本分别记录自然读取和快返测试。快返使用相同服务实际成功响应，在隔离测试浏览器内直接放行。若自然固定源码读取超过阈值，按实际时序核慢读，快返另核一遍。可设 `AFTERTASTE_READER_INPUT` 指向固定试读项目，`AFTERTASTE_BUILD` 指向固定构建。

## D037 · 浮条与原页

用同一服务首块选句比较桌面、窄窗细指针及触控命中，检视白灰玻璃、键盘提示与底部记录位置。开关随手记并操作背景，核阅读区、图视野和站内历史。

## D036 · 选文与块落点

以 SC-012 的句子在桌面和窄窗实际划选，比较前后正文和记录区的坐标，悬停和 Tab 查看两个图标的名称。目录与笔记引用跳到有标题和无标题块后观察细线、焦点、减少动态及强制色。书签与标注仍应落到具体记录。

## D039 页边记录

在共用试读副本测服务首块原句各行、阅读区滚动量及下一块坐标，再走同块两条书签和不理解批注回访。按 [D039](../../docs/work/2026/11/D039-reader-margin-records/task.md) 覆盖窄窗、键盘、仅批注、真实失败及重试。

## D040 原位编辑

从 4342 作者项目复制独立输入。在 1440 × 900 Edge 对照服务首块已有书签的铅笔和已理解状态的批注编辑，记录整窗、浮层和各按钮尺寸。按 [D040 验证与停点](../../docs/work/2026/11/D040-margin-record-editors/task.md#验证与停点) 串行检查三份书签草稿、字段独立落盘、双页冲突、实际写失败、精确回访、更多开关前后各行和浮层坐标、尺寸及层内滚动量，390 px 触屏、强制色、Firefox 轮廓及正文零位移。

## D041 · 三页详情对齐

以 [D041 验证与停点](../../docs/work/2026/11/D041-record-management-details/task.md#验证与停点) 的订单项目副本串行运行 `tests/browser/record-details.mjs` 和 `tests/browser/record-workbench.mjs`。测两种桌面宽度、窄窗、连续角、两区域恢复及只读回访。D038 固定构建只在隔离页套用同一 CSS 布局规则，核正文和引用。

D044 使用 D043 订单独立副本，展开第 03 步并打开《订单步骤核对》，从顶栏切换深黑和浅绿。核同一篇正文、笔记引文、图上 ◆ 与选中边线，再重开站点。六页五主题验收按 SC-019。
