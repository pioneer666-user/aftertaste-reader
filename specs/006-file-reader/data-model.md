# 读取模型

## 项目与发现

启动项目使用规范化的绝对目录，无链接祖先。资料发现读取 docs/aftertaste/current，缺失目录返回空集，存在但非法/不可读返回结构化问题。条目包含 documentPath 与 sourcePath，保留目录与扩展名。非法条目单独报告，合法条目仍可选择。

## 单次阅读

DocumentService.read 返回 DocumentResult 及可选 sourceLines。raw、blocks、commit、diagnostics 均派生自同一次 UTF-8 读取。取源沿 FixedSourceService，项目到仓库映射由适配器解析，各文档独立使用头部完整提交。sourceLines 保留全部物理行，终止换行不凭空增加一行。

comparison 模式只在机械校验有效时使用，源码缺失或结构/覆盖错误为 markdown 模式。源码不可用带 sourceError，文档不可读是请求错误。空正文和超阈值沿既有 warning 语义。

修复内容由 documentPath、sourcePath、实际 commit、diagnostics、sourceError 组成，包含块/行/params、问题与下一步，排除 raw、body 和 sourceLines。

## 页面状态

列表 loading/ready/empty/error。阅读 idle/loading/ready/error。切换和刷新使用单调请求序号及 AbortController，过期结果不提交。语言独立于阅读模型，切换仅更新文案并恢复滚动位置。

界面语言枚举 zh-CN/en。读取有效本地存储值，否则中文。存储异常保留当前选择并显示本页有效提示。翻译按稳定 code/params，缺键回退中文。用户内容保持原文。

## D022 导航与回访状态

| 状态／条目 | 字段与有效条件 | 状态变化 |
| --- | --- | --- |
| 文件树 | 目录键为完整源码相对目录，叶由已有文档路径、源码路径和文件名组成 | 清单更新时由合法条目重建。选择或回访时展示当前叶与祖先，收栏时保留展开状态 |
| 块目录 | 当前有效对照结果的文档路径、块 ID、原序及显示标签 | 仅与当前正文共用结果。切换或加载错误清除旧条目，接收有效结果后重建，滚动或显式跳转更新当前块 |
| 标签 | 教学原文纯文本，或行范围／序号 | 块首标题取可读文本，无标题取首句短摘。无合适文字时对照块采用已有真实行范围，纯讲解块采用文档内从 1 开始的块序号 |
| 记录回访 | 文档路径与块 ID，书签另含记录 ID | 目标仍有效时展开并定位。普通导航使用同一阅读结果，列表回访失败走已有错误反馈 |
| 导航可见状态 | 桌面固定、桌面收起、桌面临时展开、窄屏开启或关闭 | 图标切换固定或开启状态。桌面收起由左缘鼠标进入临时展开，离开且焦点在外后恢复收起 |
| 分隔位置 | 文件树份额 20%—80%，仅在本篇目录可用时参与布局 | 拖动或键盘调整两区比例，保持在本次页面内。暂时收栏或切至降级文档后可复用最近的值 |

上述状态只在本页使用。记录继续沿 [书签](../010-block-bookmarks/spec.md)、[批注](../012-understanding-marks/spec.md)与[项目笔记](../011-project-notes/spec.md)管理各自的持久资料。

## D023 项目资料与复制状态

| 状态／条目 | 字段与有效条件 | 状态变化 |
| --- | --- | --- |
| 项目资料 | `projectRoot` 来自清单，`commit` 与校验状态来自当前已显示的读取结果 | 项目名触发显隐，Esc 或窗外点击关闭。文档加载或读取失败时清空旧文档字段，按实际显示结果更新 |
| 文件题头 | 源码路径和讲解 `documentPath` 来自当前已显示的读取结果。前者为主标题，后者为可选取的项目相对路径 | 随正文切换更新，文档加载或读取失败时清空旧路径 |
| 源码板 | 源码行范围沿块，吸附条件取当前底板与阅读区可见高度并遵循 [SC-011](spec.md#measurable-outcomes) | 重排和视口变化时重算，块尾自然离开阅读区 |
| 块定位 | 文档路径、块 ID 和提交使用 [U73](../001-first-release/05-reading-feedback.md#u73--复制文档块定位-v1作者授权-ai-定稿)的必填约束。选文可缺省，存在时为同一讲解块内的非空渲染原文，保留原片段的引号与换行 | 整块入口不带选文。只有选区两端同属有效讲解块才产生选文操作，跨界、取消及切篇清除旧目标 |
| 复制结果 | 本次定位的完整纯文本与剪贴板结果 | 成功就近反馈，失败保留同一文本供手动选择。切篇后清除该次界面反馈。状态不持久化 |

## D026 共用顶栏状态

导航从 App 的当前页态派生当前项，收纳入口复用该名称和页序。讲解页侧栏固定、临时展开及焦点沿 D022 独立管理。通过图的讲解入口保留图往返状态，返回时继续使用已加载的图实例；临时框选的生命周期见 [007](../007-dependency-canvas/data-model.md#d026-临时画布状态)。顶栏状态留在本页内存。

## D028 站内访问位置

标签页内的访问项有页类型及对应的位置字段。进入时创建唯一初始项，离开时更新当前项。在当前位置成功打开新目的地时清除游标后的步骤并追加新项。重复或失败的记录回访保留前进分支。前进和后退选择已有项。读取与恢复基于递增的导航序号，过期结果退出而不落位。

| 页面 | 位置 | 恢复依据 |
| --- | --- | --- |
| 讲解 | 文档路径、当前块、相对块的阅读偏移、普通滚动位置、回访的书签或标注定位 | 重新读取当前讲解并按稳定身份定位。块消失时提示并回到文档可读处，读失败使用诊断 |
| 文件依赖图 | 对象键、视野、可用详情位置 | 按 [007 画布位置](../007-dependency-canvas/data-model.md#d028-画布回访与浮层状态) |
| 闭环 | 闭环 ID、步骤或库图例身份、画布视野、右栏位置 | 清单与闭环按当前结果解析。原闭环已失效时可继续读清单中的现有闭环 |
| 书签、标注、笔记 | 适用的记录身份、筛选及滚动位置 | 当前记录仍存在时定位，失效时提示并保留可用列表。笔记草稿由编辑器继续管理 |

访问项只存可恢复位置。关闭标签页或通过浏览器重新加载页面会结束这段历史。顶栏「刷新资料」继续按各自页面的读取逻辑更新内容。

## D030 文件切篇等待

等待仅存于阅读页面内存。请求使用现有的完整讲解路径与导航序号，文件树同时提供已知源码路径供提示。占位显示标志随本次有效请求切换。当前讲解、目录来源与记录仍归已提交的文档路径。等待不写入访问项或个人资料。成功提交才交接到目标文档，失败、覆盖和切页释放等待状态。
