# Research · 跨文件闭环讲解

## 选线与讲解

**Decision** 由 Skill 查询已有文件图、块和固定源码，获得明确选择后提交块级路线。程序只验证可观察的结构及引用。

**Rationale** 业务终点、因果、示例和用户关注点需要查阅源码后由 AI 决定。一个文件可在路线中多次出现，块级连线含义和推荐顺序可以各自表达。

**Alternatives considered** 从文件依赖边自动寻路无法认出数据传递和教学联系。等待用户选择由 Skill 管理，额外的令牌或项目状态文件无法证明用户真实选择。

## 固定引用与资料快照

**Decision** 预先固定完整提交及 Git 项目前缀。创建复用文档机械校验与版本匹配，读取每篇一次，拷贝选中块的讲解及已有范围。一次图例查询复制选中的实例及用法。读回用持久资料与固定 Git。

**Rationale** 同提交也可能发生讲解修订，所以只保存块 ID 无法稳定重读。只保存引用且从 Git 取源码可满足 U101。前缀保留子项目在固定树中的归属。

**Alternatives considered** 当前文档回查会读到重写后的说明。源码快照违反 U101。保存完整文件讲解和依赖图会把未采用的材料随成果复制。

## 发布与重试

**Decision** 在目标 loops 的私有同级暂存目录中完成并同步单文件，再以目录重命名发布整个闭环。沿用资料目录边界检查，正式入口拒绝已占用 ID。进程异常终止时，暂存路径不符合公开 ID。

**Rationale** 正常并发写入下，先发布的目录已有内容，后续重命名不能替换。写前失败可重试，读者只看到已发布数据。失败清理只处理本次创建的已知路径。

**Alternatives considered** 直接写目标文件可能暴露半成品。先占用 ID 再写会在中断后遗留阻塞重试的半成品。单文件硬链接发布会在链接到清理之间额外暴露一个链接并与现有读保护冲突。此方案保留资料目录的路径边界检查，未承诺防御恶意外部进程同步替换祖先目录或突然断电后的磁盘持久性。
## D050 · 项目讲法增量

- **Decision** 路线选择和项目讲法沿同一对话确认，讲法写入 005 已有项目偏好。闭环成品保留实际串讲正文。
- **Rationale** 两个入口共享读者选择，已存闭环按原正文重读。
- **Alternatives considered** 将讲法写入闭环协议会使新生成偏好与既有成果绑定，无法为普通文件生成提供项目级选择。
