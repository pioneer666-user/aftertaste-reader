# Data Model: 块级注解书签

项目根下 `docs/aftertaste/bookmarks.json` 为 UTF-8 JSON。根对象包含 `version: 1` 和 `bookmarks` 数组。尚无文件时为空列表。格式无效或路径不安全时报告原因并保护原件。

| 字段 | 规则 |
| --- | --- |
| `id` | 小写 UUID v4，在项目内唯一，创建后固定 |
| `documentPath` | 现有 current 镜像验证器认可的项目相对文档路径 |
| `blockId` | 讲解文档的八位小写字母或数字 ID |
| `note` | 备注字符串，可空。作为用户原文存储和显示 |

数组按添加顺序排列。编辑只改变目标备注，移除只删目标记录。相同内容的两条新增仍有不同身份。回访中的可用性只来自当前读页，磁盘始终保存原定位。U45 的已确认删除及降级状态由版本更新任务设计并接入。
