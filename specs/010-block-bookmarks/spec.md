## User Scenarios & Testing

### User Story 1 — 在讲解旁收藏（P1）

读者给源码对照块或纯讲解块加书签，备注选填。在原块旁查看、修改备注、移除指定书签。

**Why this priority**：有值得回看的内容时，可以当场留下自己的理由。

**Independent Test**：在一个非首块分别保存有备注和无备注两条书签，改一条、移除另一条，查看原块与项目列表。

**Acceptance Scenarios**

1. 给同一块加两条书签，显示两条独立记录，原样保留备注。
2. 修改或移除其中一条后，只改变该条记录。
3. 纯讲解块提供相同操作，控件支持简体中文、英文及键盘操作。

### User Story 2 — 从同一项目回访（P2）

读者关掉阅读器后再打开同一项目，在顶栏书签列表点击该条的「回原文」，回到当前讲解中的原块，直接辨认所选书签。

**Why this priority**：回看时无需记住文件名或块所在位置。

**Independent Test**：在两篇讲解里收藏 ID 相同的块，重启服务，从列表分别回访。让其中一个目标临时消失，再恢复。

**Acceptance Scenarios**

1. 列表显示文件、块和备注。空备注仍可通过文件和块辨认。点击「回原文」后滚到正确的块并把焦点移到所选记录。
2. 在相同路径保留原块 ID 改写或移动块后，书签仍打开同一身份的块。
3. 文件暂缺、讲解解析失败或当前无该块时，查看所选条目的路径、块 ID、备注与暂不可定位提示。恢复后可重试。

### User Story 3 — 保存失败后重试（P3）

读者在资料暂时写不了时仍看到原记录与本次输入，修复后可以再次保存。

**Why this priority**：个人备注需要在失败和多页同时操作时得到保护。

**Independent Test**：隔离项目上阻断一次资料写入再恢复。两个页面从旧列表各自操作，重开核结果。

**Acceptance Scenarios**

1. 写入成功后才显示成功。保存失败时原资料与正在编辑的备注均保留。
2. 同一服务中的两个页面修改不同记录或各自添加时，已确认成功的操作都出现在下次打开的列表中。

**D035 验收场景 · 从收藏理由回访**　在同一个块保存两个理由，各自在详情读原话，从列表直接回到指定书签，再后退检查原条目。

### Edge Cases

- 同块多条可有相同备注，每条有独立身份。不同文档可能使用相同块 ID。
- 普通打开或刷新期间的任何暂时缺失只影响本次定位。成功校验并完成版本更新后的删块降级、删文档保留未绑定等行为由正式更新入口接入。
- 个人资料无法读取时提示故障，恢复后可重试。可读的讲解仍可阅读。

## Requirements

### Functional Requirements

- **FR-001** 逐文件阅读页的两种块均提供新增书签，备注可空，一块可多条。主动收藏单位为块。
- **FR-002** 原块显示各条记录，读者可逐条编辑备注或移除。保留用户输入原文。
- **FR-003** 顶栏提供项目书签列表和详情，按 FR-009 查看理由、文件和块。
- **FR-004** 回访按文档路径和块 ID 打开当前讲解。渲染后滚动并聚焦于原块中所选书签，支持同篇及跨文件。
- **FR-005** 目标暂不可定位时保留路径、块 ID、备注与绑定，告知读者并可重试。
- **FR-006** 书签持久保存在所选项目的个人资料中，与可重新生成的讲解分开。读者管理内容，讲解 AI 按需只读。
- **FR-007** 成功保存须有确认。失败保留原资料与编辑草稿。读者在当前页面刷新资料或切换讲解后，回原块可继续编辑。两页操作不得用旧列表覆盖其他已保存操作。
- **FR-008** 书签操作沿用现有中英文、键盘操作与焦点反馈。

- **FR-009** 左栏显示条数、至多两行理由、短文件名和实有行范围或块定位，重名文件可区分。条目详情先展示完整收藏理由，空备注以块标题或正文首句提示并注明无备注。下方显示当前讲解的标题、两三句可读摘录、来源及回访入口；默认收起的完整定位包含文档路径和块 ID。列表箭头和详情各可一步按书签 ID 回访。临时读取失败保留原话、定位与具体提示，可重试，不写资料或进入阅读历史。

### Key Entities

- **书签**拥有独立身份，引用一个项目内的当前讲解文档和稳定块 ID，带可为空的个人备注。
- **项目书签列表**包含该项目持久保存的书签，每条可发起一次回访。

## Success Criteria

### Measurable Outcomes

- **SC-005** 在同块两条书签中选择一条后能读全理由和当前讲解，分别从列表和详情定位到那条书签。无备注时用标题带出记录；同 ID 分布于不同文件、改写、快切和暂不可读后恢复时，摘录与来源始终对应当前所选记录。

- **SC-001** 两种块共保存至少三条书签。修改一条和移除一条后，其余书签的备注与归属完全保留。
- **SC-002** 服务和页面重开后，自顶栏列表点击该条的「回原文」即回到准确的文件、块和记录，即使两篇文档使用相同块 ID。
- **SC-003** 临时失效前后所有原定位与备注相同，恢复后同一条书签可再次定位。
- **SC-004** 一次真实写入失败后输入与既有记录均可恢复使用。重试和两页面交错写入后，只出现预期记录。

## Assumptions

- 使用逐文件阅读器、当前项目和当前讲解。正式管理页面、全局笔记、理解标记及版本更新完成入口由各自任务承担。
- 讲解保留块 ID 时仍视为同一目标。版本完成确认前保留原绑定。
