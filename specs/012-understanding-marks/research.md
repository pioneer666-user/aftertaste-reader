# Phase 0 Research: 块级理解标注与批注

## 并发与原件

- **Decision**：项目单 JSON 文件，按块定位，每次比较并更新一个字段。复用同目录临时文件及替换前原件校验。
- **Rationale**：状态与批注互不覆盖，同一字段的陈旧编辑得到冲突。对相同目标值的重试保持幂等。
- **Alternatives considered**：整表替换会覆盖其他块。整条记录比较会把独立的状态和批注改动也判为冲突。数据库和跨实例锁超出单服务范围。

## 块内交互与回访

- **Decision**：原生状态选择即时保存，可展开批注单独提交。列表共用文件读取、校验与块聚焦过程。
- **Rationale**：常用的改标只需一次选择，写批注时可以先读后写。原路径和 ID 足以定位。
- **Alternatives considered**：把批注并入书签会混淆两种用途。按行号或正文重新匹配会错误迁移旧记录。

依据现有个人资料、文件回访和隔离样例。技术栈与产品边界明确，无待研究的外部依赖或未知方案。
