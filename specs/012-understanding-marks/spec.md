# Feature Specification: 块级理解标注与批注

**Feature Branch**: `codex/feat-understanding-marks`

**Created**: 2026-11-19

**Status**: 已批准实施

**Input**: [D021 派单](../../docs/work/2026/11/D021-understanding-marks/task.md)，细化 [R15、A06、A16](../001-first-release/08-current-spec-and-acceptance.md) 的当前讲解行为。

## User Scenarios & Testing

### User Story 1 - 在原块标注和批注 (Priority: P1)

读者标出理解程度，写下疑问或自己的解释，并可随时继续读。

**Why this priority**：读者在上下文仍清楚时就能记下自评和原话。

**Independent Test**：在两类正常讲解块上改标、写批注、清空批注并重开。

**Acceptance Scenarios**：

1. **Given** 正常的对照块或纯讲解块，**When** 首次打开，**Then** 默认未标记，可选已理解或不理解，批注可空，任何状态均可继续阅读。
2. **Given** 一块已有疑问，**When** 从不理解改成已理解或未标记，**Then** 重开仍看到原问句。单独改写或清空批注保留当前自评，同块书签和项目笔记各自保留。
3. **Given** 原资料可读但保存失败，**When** 修改自评或批注，**Then** 页面显示失败、保留输入供重试，已存记录完整。另一页已修改同字段时，陈旧保存需明确提示冲突。

### User Story 2 - 从项目标注回到原块 (Priority: P2)

读者重开项目，筛选仍不理解的块，回到原处继续阅读。

**Why this priority**：读者可跨文件找到尚未读懂的具体位置。

**Independent Test**：两份讲解使用相同块 ID，分别标注并从列表回访。

**Acceptance Scenarios**：

1. **Given** 已理解、不理解和仅留批注的未标记记录，**When** 打开标注或按不理解筛选，**Then** 显示文件、块、当前状态和原话，筛选仅含当前不理解的记录。
2. **Given** 两个文件的块 ID 相同，**When** 分别回访，**Then** 每条滚动并聚焦到其原文件的对应块。
3. **Given** 讲解同 ID 改写或重排，**When** 回访，**Then** 同一记录继续定位。拆分、合并的新 ID 默认未标记，原位置不可读时提示并保留记录。普通改写和批注编辑均不新增版本提醒。

### User Story 3 - 讲解时按需参考自评和原话 (Priority: P3)

讲解 AI 从项目个人资料找到相关块的当前自评和读者原话。

**Why this priority**：可沿读者的理解继续讲解，也能识别已经解决的旧问题。

**Independent Test**：按指南读回已理解的旧问句和未标记但有批注的记录。

**Acceptance Scenarios**：

1. **Given** 自评已改成已理解且批注仍是问句，**When** 讲解 AI 参考资料，**Then** 尊重当前自评，按原文理解批注，不擅自改写个人记录。

**D035 验收场景 · 在标注详情读原话**　筛不理解后选一条，从列表回原文，再返回读完整批注。改标后仍能在全部记录找到原话。

### Edge Cases

- 未标记且批注为空时没有列表项，批注仅含空格或换行时保留原文。
- 讲解不可读、损坏或缺块时不能从标注跳入错误位置，已有记录可在列表读回。
- 无个人资料时可正常阅读。个人资料读写失败时可以继续阅读，并可从标注入口重试读取。

## Requirements

### Functional Requirements

- **FR-001**：两类正常讲解块都提供三态且默认未标记，阅读不受自评限制。
- **FR-002**：读者可以独立改标和编辑、清空可选批注。改标保留原话，批注和书签备注、项目笔记独立。
- **FR-003**：项目内提供标注入口，显示两个明确状态和留批注的未标记记录，可按当前不理解筛选并读原话。
- **FR-004**：按文档路径与块 ID 定位并聚焦。同身份改写保留，新 ID 默认未标记，暂无法定位时提示并保留原记录。
- **FR-005**：保存失败须保留输入和已存资料。同一服务多页编辑不得静默覆盖另一页已改的批注或自评。
- **FR-006**：讲解 AI 可在项目内按需只读相关记录，分别解释当前自评和批注原话。
- **FR-007**：普通改写和批注编辑均不触发版本变化提醒。R15 的正式源码更新触发、确认和提醒留存随更新任务联验。
- **FR-008**：入口、筛选和块内操作可用键盘，反馈提供中英文，个人批注保持原文。

- **FR-009** 左栏平铺「全部／不理解」，显示当前筛选、条数和空态；每行显示带符号和颜色的状态、至多两行批注及短来源。详情先展示完整批注，空批注用块标题或首句带出并注明无批注。下方显示当前讲解的标题、两三句可读摘录、来源及回访入口，完整文档路径和块 ID 默认折叠。列表行尾及详情都可一步打开原块的批注，临时失效保留原话及定位，显示原因并可重试。

### Key Entities

- **块级理解记录**：所选项目内的文档路径、块 ID、当前自评和批注原文。

## Success Criteria

### Measurable Outcomes

- **SC-005** 从不理解列表读完整疑问和当前摘录，从列表或详情回访并展开原状态和批注。返回保留筛选、所选与双区位置；在全部列表可读无批注和仅有批注的未标记块，临时失效可重试，浏览步骤零资料写入。

- **SC-001**：两类块均可独立改标批注，重开保持三态转换后的原话、书签和项目笔记。
- **SC-002**：同 ID 的两个文件各准确回访一次，按不理解筛选只保留当前不理解的记录，换 ID 或暂时不可读时原记录仍可读。
- **SC-003**：一次实际保存失败及一次双页陈旧编辑均保护原件，输入保留可重试。
- **SC-004**：按指南从项目资料读回两种有原话的状态并区分当前自评和原文。

## Assumptions

- 本地单项目阅读器与现有块路径和身份规则继续适用。并发保护范围为同一服务实例。
- D041 落实列表扫读与详情回读，其余管理需求继续按项目待办安排。
