# Data Model: 块级理解标注与批注

资料位于目标项目的 `docs/aftertaste/understanding-marks.json`。顶层为 `{ "version": 1, "marks": [...] }`。没有文件时视为空列表。已有文件若格式、编码或路径不合法，报告错误并保护原件。

| 字段 | 规则 |
| --- | --- |
| `documentPath` | 项目相对的 current 镜像文档路径，复用文件阅读校验 |
| `blockId` | 文档中的 8 位小写字母数字 ID |
| `status` | `unmarked`、`understood`、`not-understood` |
| `annotation` | 完整 Unicode 字符串，空字符串表示无批注。保持原文和空白 |

路径与 ID 的组合在文件内唯一。缺记录等同 `unmarked` 加空批注，该状态和空批注组合不持久化为条目。两字段分别允许更新，保持另一字段已存值。仅当前可读块可提交新变化。原块失效时已有记录继续可读，存档不迁移。

服务实例串行提交。每次提交比较该字段的已知原值，目标值已存时可直接重试。修改后整文件安全替换；版本更新任务负责正式变化信号和提醒确认。
