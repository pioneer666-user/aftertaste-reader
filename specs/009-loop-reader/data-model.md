# Data Model

- **闭环成品**：沿 [008 数据模型](../008-loop-authoring/data-model.md)。清单含 ID、标题、目标、推荐顺序的步骤 ID、有向边端点和节点路径去重数。完整读取带每步源码状态（可用、不可用、纯讲解），源码只在运行时返回。
- **画布成员**：步骤键使用 D015 已校验的节点 ID，图例键沿用 `legend:<id>`。默认从入口按 `edges` 分层，推荐顺序决定同层顺序。业务连线来自 `edges`，库辅助线只来自节点的 `library_uses`。旧文件用法在概览查阅，完整个人布局保存全部存续身份。
- **个人布局**：`docs/aftertaste/loops/<id>/layout.json`，位于教学成品的 `current/` 外。信封使用现有布局格式，`graph` 为 `loop:<id>`，包含 UUID v4 修订和位置、组、视野。布局须含当前图精确坐标名单，分组和坐标边界沿 [007 契约](../007-dependency-canvas/contracts/graph-layout.md)。闭环内容更新与节点移除的布局协调留待更新任务。
- **页面保存状态**：每图从默认或已保存状态进入草稿、保存中、已保存或失败。失败保留原图草稿，冲突可显式放弃草稿并读取磁盘版本。未打开过的图不发出布局请求。
- **临时源码对照状态**：入口悬停／焦点预览与点击固定均为当前步骤的页面临时状态。固定随主动换步更新；同一步的同引用保持代码滚动位置，新范围更新起始行。它不属于个人布局、闭环成品或站内历史，不写项目资料。
- **临时画布反馈状态**：悬停轻抬和空白关闭只改变当前实例的卡面视觉与选择，不改变节点坐标、分组或视野。闭环工具常驻。目录开合及目录滚动只属本页临时状态。

- **阅读栏显隐、当前关系与组菜单**：各图的临时界面状态。推荐前后按 reading_order，来自／通向按 edges。显式解散提交原布局及去除目标组后的 groups。

## D042 · 依赖图与闭环往返

底条开合无独立状态，当前步、视口、固定源码继续归各图。

画布按步骤读 annotation 与 lines；阅读态只在当前图记录手动开合。节点和组位置、视野及依赖图布局沿原协议。
