# Phase 0 Research

## 图和步骤身份

**Decision**：闭环画布采用 D015 保存的节点 ID 和连线，图例仍使用既有图例身份。图例的文件关系显示在阅读区。

**Rationale**：同一块可被多个节点引用，文件级图例关系没有精确到教学步骤。

**Alternatives considered**：使用路径或原块 ID 折叠步骤会使独立布局丢失；把库连到每个同文件步骤会宣称成品未保存的关系。

## 布局归属与版本

**Decision**：闭环布局放在 `loops/<id>/layout.json`，图标识为 `loop:<id>`。闭环图版本包含项目、图身份及成品版本。共用依赖图的修订与原子发布流程。

**Rationale**：每图独立保存，既有依赖图文件及未布局成品均可继续读取。

**Alternatives considered**：统一大文件会扩大写入面；放入 `current/` 会混合个人记录和闭环教学内容。

## 切图与阅读呈现

**Decision**：每个已打开的图保有以图身份绑定的画布实例、接口目标和草稿。入口步骤先显示，串讲、顺序列表与长正文可展开，下一步理由位于步骤区。

**Rationale**：请求完成时间不会改变归属，退回原图可看到它的实际状态。

**Alternatives considered**：共用单一可变选择和保存变量的实例时，需要额外手写切换状态管理。

## 依赖及集成核对

复用仓内 D015 的解析和 Git 诊断、D012/D014 的Vue Flow 及布局契约、Fastify 已有本机请求约束。无外部新依赖或待澄清项。
