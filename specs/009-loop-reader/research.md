# Phase 0 Research

## 图和步骤身份

**Decision**：闭环画布采用 D015 保存的节点 ID 和连线，图例仍使用既有图例身份。图例的文件关系显示在阅读区。

**Rationale**：同一块可被多个节点引用，文件级图例关系没有精确到教学步骤。

**Alternatives considered**：使用路径或原块 ID 折叠步骤会使独立布局丢失；把库连到每个同文件步骤会宣称成品未保存的关系。

## 布局归属与版本

**Decision**：闭环布局放在 `loops/<id>/layout.json`，图标识为 `loop:<id>`。闭环图版本包含项目、图身份及成品版本。共用依赖图的修订与原子发布流程。

**Rationale**：每图独立保存，既有依赖图文件及未布局成品均可继续读取。

**Alternatives considered**：统一大文件会扩大写入面；放入 `current/` 会混合个人记录和闭环教学内容。

## 切图与阅读呈现

**Decision**：每个已打开的图保有以图身份绑定的画布实例、接口目标和草稿。D032 起先显示概览及入口，串讲、顺序列表与长正文可展开，下一步理由位于步骤区。

**Rationale**：请求完成时间不会改变归属，退回原图可看到它的实际状态。

**Alternatives considered**：共用单一可变选择和保存变量的实例时，需要额外手写切换状态管理。

## 依赖及集成核对

复用仓内 D015 的解析和 Git 诊断、D012/D014 的Vue Flow 及布局契约、Fastify 已有本机请求约束。无外部新依赖或待澄清项。

## D031 主阅读与画布交接

**Decision**：沿用 `DependencyCanvas.vue` 的画布实例、布局保存和浮动工具，在 `LoopReading.vue` 管理本步讲解和临时源码对照。步骤选择不写入站内历史；源码预览或固定状态不写入磁盘，也不进入回访位置。点击入口或 Enter 固定后，主动换步取新步骤的已有源码；同引用保留代码区域，纯讲解或图例关闭浮层。空间足够时浮层右缘对齐阅读栏左缘，空间不足时只在步骤内展开。

**Rationale**：读讲解与核对源码可并排完成，且已有响应已经按步骤提供固定源码和诊断，不需要新增服务接口、存储、第三方依赖或选择历史。把视觉位移放在内部卡面可保持 Vue Flow 的热区、端口、拖动与个人布局坐标稳定。

**Alternatives considered**：新增源码 API 或把预览写入布局会扩大读取和持久化范围；推动画布为源码让位会改变读者已经布置的视野；以路径合并步骤会混淆同块不同讲解。均不采用。

## D032 目录开合

采用覆盖定位以免图容器重排引起节点及小地图移动；沿用 D031 独立图实例以保留阅读和布局。列表利用已有解析结果，避免预读布局或按步骤取源码。

## D033 收栏追图

D032 的目录实测验证了稳定原点与独立浮层可保留画布几何。沿用 D031 的单步源码实例，在面板收起时隐藏固定对照。完整闭环已有边理由，updateGroup 可提交空成员移除组，无需修改读写契约。

沿用 D034 的覆盖式阅读栏和 LoopReading 出口。补上来路即可保全原面板的可达关系。
