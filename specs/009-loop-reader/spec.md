## User Scenarios & Testing

### User Story 1 - 找到闭环并读完两条路线 (Priority: P1)

读者从项目里按标题打开已保存闭环，从入口读到订单的两个结果。

**Why this priority**：让独立保存的成果能在阅读器直接阅读。

**Independent Test**：从项目列表打开订单闭环，在数量校验处分别追到追加订单和提前结束。

**Acceptance Scenarios**：

1. 项目有两条已保存闭环，打开列表后可按标题切换，并回到文件阅读或依赖图。空列表提供明确提示。
2. 打开订单闭环后可点图名或展开阅读栏查看主题、目标与入口。读者可展开串讲和推荐顺序，也可按当前步骤的输出连线查看下一步及其理由。
3. 阅读栏展开时，点选步骤后首先读到标题、本步讲解和就近提示，原块讲解默认折叠。每条出口把目标标题和理由放进同一可激活行；上／下一步显示对应名称。共享原块的不同步骤仍显示各自讲解和相同源码位置。
4. 有行范围时显示「对照源码 · 文件 · 起止行」。桌面稍停或键盘聚焦可预览，点击或 Enter 固定；固定后主动换步更新源码，同引用不闪空，关闭可归还焦点。窄窗或空间不足时入口在当前步内展开。纯讲解无源码入口；缺源诊断保留讲解和分支。
5. 点击空白清除当前详情和关系条。开栏时显示概览，收栏时维持收起。点选、预览、固定、选文与滚动源码不新增站内历史，不改图布局；站内返回仍能恢复原闭环原步骤和视野。
6. 两类图均有共用浮动工具、低对比点阵和小地图；选图后闭环工具常驻，顶栏控制覆盖在左边的闭环目录。鼠标悬停只令卡面轻抬约 2 CSS px，拖动跟手，减少动态效果下静止反馈；固定提示为「点击节点查看详情，点击空白关闭」，英文随界面切换。

7. 首次进入即见满幅点阵、展开的目录和右侧「回味」字标及选图提示。每行可按真实路线缩影、完整标题、目标、步数和文件数挑选。首次选图同时收起目录和右栏；回访恢复原图的步骤、视野与显隐选择。再次展开时当前项可辨，收回后接着原处读。

8. 收栏后从校验步沿「通向」选失败步，展开直接读集合未改变的原因。「来自」回校验步，栏内顶部推荐上一步回成功路线末步。收栏点空白清空选择，主动点画布左上图名打开概览。

### User Story 2 - 查看参与文件怎样使用库 (Priority: P2)

读者打开闭环的库图例，对照参与文件及各文件的用法。

**Why this priority**：读者可在同一成果中查阅完成路线所需的库背景。

**Independent Test**：打开带库图例的闭环并选择该图例，核对保存的介绍与文件用法。

**Acceptance Scenarios**：

1. 图例显示保存的库名、类型、介绍、使用该库的参与文件及各自用法。文件用法按路径展示，步骤用法可跟到对应教学步骤。
2. 中英文切换后，导航、状态和诊断随界面语言更新，讲解、图例、用户组名和源码保留原文。

### User Story 3 - 重开后接着自己的排布读 (Priority: P3)

读者给每张图布置自己的阅读视野。

**Why this priority**：同一原块的教学步骤及同一库在不同图中可以各有位置。

**Independent Test**：在两条闭环及依赖图内布置不同布局，关闭页面并重启服务后核对三张图。

**Acceptance Scenarios**：

1. 拖放步骤与图例，调整组名和成员，拖组时只有成员一起移动，重排保留组。个人布局也记录平移和缩放后的视野。
2. 同一原块的两个步骤分别恢复坐标。同一库图例在不同图分别恢复位置、组和视野，布局操作期间教学资料字节一致。
3. A 读取或保存未完成时切换到 B，迟到响应仍各归原图。另一标签先保存当前图后，旧版本保存提示冲突并保留草稿。写入失败也可留在页面重试。

4. 拖组名移动整组，点旁边的「⋯」改名、调整成员或解散。取消菜单保留当前阅读和布局。解散后保存、重开，节点和连线仍在拖动后的位置。

**D051 阅读场景。** 读者在步骤卡下收起「节点说明」，再点已选步骤或使用键盘展开；手摆图上可以就地读，查看源码后仍能返回该步。

### User Story 4 · 留在原视野展开两步（P1，D053）

一步可见、一步在右侧时仅提示右侧一步。键盘定位后返回，视野和缩放相同，当前讲解和固定源码仍可读。

### Edge Cases

- 缺少个人布局时，从入口沿教学边向右分层，同层按推荐顺序排列。
- 个别成果不可读时，提示问题并保留其他可读成果。
- 磁盘布局损坏或写入失败时，提示实际状态并保护已保存资料。
- 长步骤名、长理由及长源码行在桌面和窄窗可读；源码浮层不挤压画布，失焦、Esc、换到纯讲解或图例时不错误保留旧源码。

## Requirements

### Functional Requirements

- **FR-001**：本地阅读器必须列出已保存闭环，目录显示数量并可刷新。整行可用键盘或点按选择，长标题换行；加载、失败可重试、真实无成品、单条诊断分别呈现。未选时收起目录后的提示指向顶栏入口，支持返回文件或依赖图。对应 V01。
- **FR-002**：显示主题、目标、串讲及入口，支持按保存的推荐顺序及实际连线阅读；目标标题和保存理由在同一可激活行，栏内顶部图标悬停或聚焦显示用途和目标全名，入口按 entry，推荐上／下一步按 reading_order，首尾禁用，滚动后可用。选教学步时，底部毛玻璃条按有向边列「来自／通向」，支持键盘、鼠标与点按查阅每条边的完整目标和理由并选步，终点有明确提示。对应 V02。
- **FR-003**：展开时选中步骤直接显示自己的讲解和就近提示，提示后以一行对照源码衔接真实出口；单出口给出承接缘由和去向，分岔逐条展示理由与完整目标，终点明确收束。最后才放默认折叠的原块全文。有行范围时按需显示对照源码、路径、行号和提交；桌面悬停／聚焦预览及点击／Enter 固定，固定随主动换步更新，窄窗在本步内展开。源码不可读时就地诊断，纯讲解无入口，讲解与画布可用。对应 V02、D031。
- **FR-004**：用闭环步骤自身的身份选择、布局和恢复步骤。同一原块可用于多个步骤。图例展示保存的库介绍、参与文件及各自用法。对应 V03。
- **FR-005**：共用画布支持拖动、命名分组、加入和移出成员、拖组、平移、缩放与保组重排。两类图复用浮动工具、点阵和小地图；悬停卡面轻抬约 2 CSS px 而不改变节点几何，支持键盘焦点及减少动态效果。闭环的分组编辑位于画布内，组名拖动与「⋯」操作分开命中。菜单末项「解散分组」提示「节点保留在原位」，直接保存，仅移除该组。对应 V04、D031、D033。步骤卡、库卡及整组沿用 [007 FR-025](../007-dependency-canvas/spec.md) 的吸附和保存规则。教学实线指向下一步，库虚线指向使用步骤；分支、汇合、回边、自环按来向绘制，经过第三张卡时默认被遮，点选端点可沿原路径浮起，仍能操作线下的步骤或库卡。
- **FR-006**：坐标、组及视野按项目和图保存与恢复，写入保护成果、其他图和已有依赖图布局。迟到结果和冲突按原图处理，写失败可重试且状态如实。对应 V04。
- **FR-007**：界面、导航和反馈随现有中英文选择变化，读者和作者的内容保留原文。对应 V01。
- **FR-008**：画布左上图名可打开本图概览。选步后的底条有「展开讲解／收起讲解」，与右侧把手同步控制当前步骤的阅读栏。完整来路、出口及其理由在栏内可读、可换步。右栏覆盖满幅画布；边缘淡把手在靠近或聚焦时显示箭头，点击、Enter 或空格收展，触屏可点按。收起时选步只更新选择，展开读当前步；原步滚动与固定源码可接续，临时预览退出。同次收展保留视野、节点和小地图位置。概览、空白与库图例清除关系条。桌面保留闭环右侧阅读，当前步骤先显示标题、讲解和可选提示；空白关闭详情，顶栏控制浮在画布上的目录，Esc 关闭回焦触发按钮。开合及刷新仍存在的条目时，保留视野、小地图、阅读位置与固定源码；目录动作不写布局或新增历史。按 [006 FR-016](../006-file-reader/spec.md#functional-requirements) 返回当前可用的原闭环与步骤。选步及源码对照不新增历史或写布局；闭环和依赖图各自管理选择、工具及保存布局。对应 D031。
- **FR-009**：单一步骤讲解或提示的非空选区可复制定位和加入随手记。整步也可复制。换步、收栏或跨区选择时清除浮条，保留原生复制与画布位置。笔记回访按闭环和步骤身份展开右栏；目标暂缺时显示原因并保留摘录。

- **FR-010** 无坐标时从入口沿教学边向右分层。分支错行、汇合在来路之后，同层依推荐顺序。步骤用到的库全部居左，各逻辑层共同居中，密集层内可分列。确认流程沿用 [007 FR-003](../007-dependency-canvas/spec.md)，主动重排保组，重开优先恢复完整快照。仅有步骤用法的库上图，辅助线与流程箭头可分辨；仅文件用法可在概览查阅。

- **FR-011** 闭环的教学箭头与库用法虚线采用[双图共用的淡线和节点指向反馈](../007-dependency-canvas/spec.md#functional-requirements)。在分支节点悬停可看到全部直接来路和两个出口。

- **FR-012（D051）** 按批准示例在卡底左缘挂纸色短注，支持鼠标、键盘、触屏选步与收展。空间不足先收起，卡片重复激活可展开。随节点、组及视野移动，保留关系反馈与右栏选择；长文和真实固定源码可进入阅读栏。

- **FR-013（D052）** 读者可用鼠标、触屏或键盘直接选教学边及库到步骤的用法线。关系条展示两端、短文本与理由。点线和关闭关系条时保留当前步骤、阅读栏开合及固定的源码。连线反馈沿用 007 FR-026。

- **FR-014（D053）** 可拖动无边框问句，计数按实际变化；展开只强调新出现的内容，按方向提示屏外目标。阅读栏占据的区域排除在可读画布之外。原有步骤入口可打开所需开关并读固定源码。

### Key Entities

- **已保存闭环**：主题、目标、串讲、入口、推荐顺序、教学步骤、连线及使用的库。
- **教学步骤**：闭环内身份、讲解、提示、原块及固定提交下的源码定位。
- **个人布局**：一张图的节点和图例位置、组、视野及当前保存版本。

## Success Criteria

### Measurable Outcomes

- **SC-013（D052）** 固定判断步的源码，选中「返回 4」和「非整数，抛错」再关闭详情，原步骤、源码、阅读栏与磁盘布局均保持。

- **SC-001**：读者从数量校验走到两种结果，能逐步复述连线原因并区分两处共享原块的讲解。
- **SC-002**：两条闭环及一张依赖图重开后各自恢复位置、组和视野。同库图例可保留不同排布。
- **SC-003**：迟到响应、旧标签保存和失败重试三个场景中，磁盘和页面状态均归正确的图，内容文件字节一致。
- **SC-004**：更改当前讲解或让一处固定源码不可用后，已有闭环仍呈现保存的讲解、可读步骤及相应诊断。
- **SC-005**：以 [006 SC-013 与 SC-011 的桌面和窄窗](../006-file-reader/spec.md#measurable-outcomes) 打开订单闭环，收栏选步、展开读完整讲解，再读同行分支理由；通过分支到建立订单时集合尚未改变，到追加订单步才首次改变；失败分支在创建与追加前结束。在校验步固定 `src/rules.mjs` 第 1–7 行，选择失败分支后代码保持相同引用而讲解换成集合未改变的原因。预览、固定、选文、横滚和关闭前后节点坐标、视口与小地图位置不变且无新增历史；390 CSS px 下在本步读完整源码。节点悬停轻抬约 2 CSS px，离开／拖动／减少动态时符合反馈规则，空白回到概览。切依赖图并后退恢复闭环步骤和视野，各图布局独立。

- **SC-006**：1440 × 900 下，开栏、收栏的真实绘图区四边与满幅工作区一致。目录中可区分五步分岔和两步单线。在校验步固定源码并滚动后，于打开前、滑动中和关闭后量同一节点屏幕位置与小地图，三次相同。390 CSS px 下可选图并读步骤。

- **SC-007**：完成 US1 场景 8 和 US3 场景 4。1440 × 900 的校验步在收展动画每帧中绘图区、视野、节点、小地图与底部关系条均保持收栏态的位置；关系条水平居中、距底 12 px，阅读路径无布局写入；解散前后及重开保存的坐标、视野、其他组与连线逐项相同。

- **SC-008** 从依赖图直接进订单图，底部展开规则转换步骤的讲解，沿成功和失败出口换步，把手与底条显隐同步。超过两条的来路或出口也能用键盘与触屏读取全名、理由并选步。

- **SC-009** 在订单闭环第 01、03 步各取一句，与文件块同存一篇，从两处笔记预览分别点回。第 03 步讲解改写后仍能从旧摘录返回该步骤。

- **SC-010** 同一收藏路线从入口看到下一步，分支两路通向同一应答；重开、增点、重排后旧组与视野按操作恢复。旧图隐藏的库坐标与组成员可再次保存。

- **SC-011** 从分支点沿两个出口分别找到下一步，再从两路找到同一汇合步骤。拖步骤、库或组名对齐并重开，核对本图布局与文件图布局各自恢复。取消重排保留手摆位置，确认后检查最左库、入口、密集分支列及汇合点的顺序与共同中线。

- **SC-012（D051）** 在稀疏和手摆密图单独收展、复点、选文、看固定源码和全文；位置、组和视野相同且无布局保存。确认重排、拖组和缩放后注释仍跟随。文件依赖图可点选文件、查依赖理由，排布一致。

- **SC-014（D053）** 一步可见、一步在右侧时仅提示右侧一步。键盘定位后返回，视野和缩放相同，当前讲解和固定源码仍可读。

## Assumptions

- 读者已有 D015 创建的闭环。源码显示依赖原提交中的文件仍可读取。
- 本批限本地阅读和个人排布。依赖图参与文件高亮见 007 FR-021—022。同提交的讲解修订见 005 FR-010；跨提交更新、历史及整页视觉重设沿后续任务。

共用主题沿 [006 FR-021](../006-file-reader/spec.md#functional-requirements)。切换时保留当前步骤、展开的讲解与源码。
