## User Scenarios & Testing

### User Story 1 - 找到闭环并读完两条路线 (Priority: P1)

读者从项目里按标题打开已保存闭环，从入口读到订单的两个结果。

**Why this priority**：让独立保存的成果能在阅读器直接阅读。

**Independent Test**：从项目列表打开订单闭环，在数量校验处分别追到追加订单和提前结束。

**Acceptance Scenarios**：

1. 项目有两条已保存闭环，打开列表后可按标题切换，并回到文件阅读或依赖图。空列表提供明确提示。
2. 打开订单闭环后显示主题、目标与入口。读者可展开串讲和推荐顺序，也可按当前步骤的输出连线查看下一步及其理由。
3. 点选步骤后首先读到标题、本步讲解和就近提示，原块讲解默认折叠。每条出口把目标标题和理由放进同一可激活行；上／下一步显示对应名称。共享原块的不同步骤仍显示各自讲解和相同源码位置。
4. 有行范围时显示「对照源码 · 文件 · 起止行」。桌面稍停或键盘聚焦可预览，点击或 Enter 固定；固定后主动换步更新源码，同引用不闪空，关闭可归还焦点。窄窗或空间不足时入口在当前步内展开。纯讲解无源码入口；缺源诊断保留讲解和分支。
5. 点击空白关闭当前详情并回到闭环概览。点选、预览、固定、选文与滚动源码不新增站内历史，不改图布局；站内返回仍能恢复原闭环原步骤和视野。
6. 两类图均有共用浮动工具、低对比点阵和小地图；选图后闭环工具常驻，顶栏控制覆盖在左边的闭环目录。鼠标悬停只令卡面轻抬约 2 CSS px，拖动跟手，减少动态效果下静止反馈；固定提示为「点击节点查看详情，点击空白关闭」，英文随界面切换。

7. 首次进入即见满幅点阵、展开的目录和右侧「回味」字标及选图提示。每行可按真实路线缩影、完整标题、目标、步数和文件数挑选。选图收起目录，显示概览。再次展开时当前项可辨，收回后接着原处读。

### User Story 2 - 查看参与文件怎样使用库 (Priority: P2)

读者打开闭环的库图例，对照参与文件及各文件的用法。

**Why this priority**：读者可在同一成果中查阅完成路线所需的库背景。

**Independent Test**：打开带库图例的闭环并选择该图例，核对保存的介绍与文件用法。

**Acceptance Scenarios**：

1. 图例显示保存的库名、类型、介绍、使用该库的参与文件及各自用法。关联按文件展示。
2. 中英文切换后，导航、状态和诊断随界面语言更新，讲解、图例、用户组名和源码保留原文。

### User Story 3 - 重开后接着自己的排布读 (Priority: P3)

读者给每张图布置自己的阅读视野。

**Why this priority**：同一原块的教学步骤及同一库在不同图中可以各有位置。

**Independent Test**：在两条闭环及依赖图内布置不同布局，关闭页面并重启服务后核对三张图。

**Acceptance Scenarios**：

1. 拖放步骤与图例，调整组名和成员，拖组时只有成员一起移动，重排保留组。个人布局也记录平移和缩放后的视野。
2. 同一原块的两个步骤分别恢复坐标。同一库图例在不同图分别恢复位置、组和视野，布局操作期间教学资料字节一致。
3. A 读取或保存未完成时切换到 B，迟到响应仍各归原图。另一标签先保存当前图后，旧版本保存提示冲突并保留草稿。写入失败也可留在页面重试。

### Edge Cases

- 缺少个人布局时，显示按推荐顺序排列的默认画布。
- 个别成果不可读时，提示问题并保留其他可读成果。
- 磁盘布局损坏或写入失败时，提示实际状态并保护已保存资料。
- 长步骤名、长理由及长源码行在桌面和窄窗可读；源码浮层不挤压画布，失焦、Esc、换到纯讲解或图例时不错误保留旧源码。

## Requirements

### Functional Requirements

- **FR-001**：本地阅读器必须列出已保存闭环，目录显示数量并可刷新。整行可用键盘或点按选择，长标题换行；加载、失败可重试、真实无成品、单条诊断分别呈现。未选时收起目录后的提示指向顶栏入口，支持返回文件或依赖图。对应 V01。
- **FR-002**：显示主题、目标、串讲及入口，支持按保存的推荐顺序及实际连线阅读；目标标题和保存理由在同一可激活行，上／下一步带目标名称。对应 V02。
- **FR-003**：选中步骤直接显示自己的讲解和就近提示，原块讲解默认折叠。有行范围时按需显示对照源码、路径、行号和提交；桌面悬停／聚焦预览及点击／Enter 固定，固定随主动换步更新，窄窗在本步内展开。源码不可读时就地诊断，纯讲解无入口，讲解与画布可用。对应 V02、D031。
- **FR-004**：用闭环步骤自身的身份选择、布局和恢复步骤。同一原块可用于多个步骤。图例展示保存的库介绍、参与文件及各自用法。对应 V03。
- **FR-005**：共用画布支持拖动、命名分组、加入和移出成员、拖组、平移、缩放与保组重排。两类图复用浮动工具、点阵和小地图；悬停卡面轻抬约 2 CSS px 而不改变节点几何，支持键盘焦点及减少动态效果。对应 V04、D031。
- **FR-006**：坐标、组及视野按项目和图保存与恢复，写入保护成果、其他图和已有依赖图布局。迟到结果和冲突按原图处理，写失败可重试且状态如实。对应 V04。
- **FR-007**：界面、导航和反馈随现有中英文选择变化，读者和作者的内容保留原文。对应 V01。
- **FR-008**：桌面保留闭环右侧阅读，当前步骤先显示标题、源码入口、讲解和提示；空白关闭详情，顶栏控制浮在画布上的目录，Esc 关闭回焦触发按钮。开合及刷新仍存在的条目时，保留视野、小地图、阅读位置与固定源码；目录动作不写布局或新增历史。按 [006 FR-016](../006-file-reader/spec.md#functional-requirements) 返回当前可用的原闭环与步骤。选步及源码对照不新增历史或写布局；闭环和依赖图各自管理选择、工具及保存布局。对应 D031。

### Key Entities

- **已保存闭环**：主题、目标、串讲、入口、推荐顺序、教学步骤、连线及使用的库。
- **教学步骤**：闭环内身份、讲解、提示、原块及固定提交下的源码定位。
- **个人布局**：一张图的节点和图例位置、组、视野及当前保存版本。

## Success Criteria

### Measurable Outcomes

- **SC-001**：读者从数量校验走到两种结果，能逐步复述连线原因并区分两处共享原块的讲解。
- **SC-002**：两条闭环及一张依赖图重开后各自恢复位置、组和视野。同库图例可保留不同排布。
- **SC-003**：迟到响应、旧标签保存和失败重试三个场景中，磁盘和页面状态均归正确的图，内容文件字节一致。
- **SC-004**：更改当前讲解或让一处固定源码不可用后，已有闭环仍呈现保存的讲解、可读步骤及相应诊断。
- **SC-005**：以 [006 SC-013 与 SC-011 的桌面和窄窗](../006-file-reader/spec.md#measurable-outcomes) 打开订单闭环，选中步骤直接读讲解和同行分支理由。在校验步固定 `src/rules.mjs` 第 1–7 行，选择失败分支后代码保持相同引用而讲解换成集合未改变的原因。预览、固定、选文、横滚和关闭前后节点坐标、视口与小地图位置不变且无新增历史；390 CSS px 下在本步读完整源码。节点悬停轻抬约 2 CSS px，离开／拖动／减少动态时符合反馈规则，空白回到概览。切依赖图并后退恢复闭环步骤和视野，各图布局独立。

- **SC-006**：1440 × 900 下，两态工作区四边与依赖图一致。目录中可区分五步分岔和两步单线。在校验步固定源码并滚动后，于打开前、滑动中和关闭后量同一节点屏幕位置与小地图，三次相同。390 CSS px 下可选图并读步骤。

## Assumptions

- 读者已有 D015 创建的闭环。源码显示依赖原提交中的文件仍可读取。
- 本批限本地阅读和个人排布。路线高亮、闭环内容更新与历史、编辑及整页视觉重设沿后续任务。
