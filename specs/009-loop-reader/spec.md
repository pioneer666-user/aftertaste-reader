## User Scenarios & Testing

### User Story 1 - 找到闭环并读完两条路线 (Priority: P1)

读者从项目里按标题打开已保存闭环，从入口读到订单的两个结果。

**Why this priority**：让独立保存的成果能在阅读器直接阅读。

**Independent Test**：从项目列表打开订单闭环，在数量校验处分别追到追加订单和提前结束。

**Acceptance Scenarios**：

1. 项目有两条已保存闭环，打开列表后可按标题切换，并回到文件阅读或依赖图。空列表提供明确提示。
2. 打开订单闭环后显示主题、目标与入口。读者可展开串讲和推荐顺序，也可按当前步骤的输出连线查看下一步及其理由。
3. 选中交出数量和接回结果两步时，分别显示各自的讲解。展开原块讲解及固定源码后，两步显示同一位置。
4. 改写当前文件讲解后，旧闭环仍显示自己的讲解和固定源码引用。纯讲解步骤显示正文，一处源码不可读时，诊断在该步显示，其余讲解和画布可用。
5. 桌面从右侧读步骤、源码和分支理由，窄窗仍可读。按站内历史返回时可接着读原闭环的原步骤。

### User Story 2 - 查看参与文件怎样使用库 (Priority: P2)

读者打开闭环的库图例，对照参与文件及各文件的用法。

**Why this priority**：读者可在同一成果中查阅完成路线所需的库背景。

**Independent Test**：打开带库图例的闭环并选择该图例，核对保存的介绍与文件用法。

**Acceptance Scenarios**：

1. 图例显示保存的库名、类型、介绍、使用该库的参与文件及各自用法。关联按文件展示。
2. 中英文切换后，导航、状态和诊断随界面语言更新，讲解、图例、用户组名和源码保留原文。

### User Story 3 - 重开后接着自己的排布读 (Priority: P3)

读者给每张图布置自己的阅读视野。

**Why this priority**：同一原块的教学步骤及同一库在不同图中可以各有位置。

**Independent Test**：在两条闭环及依赖图内布置不同布局，关闭页面并重启服务后核对三张图。

**Acceptance Scenarios**：

1. 拖放步骤与图例，调整组名和成员，拖组时只有成员一起移动，重排保留组。个人布局也记录平移和缩放后的视野。
2. 同一原块的两个步骤分别恢复坐标。同一库图例在不同图分别恢复位置、组和视野，布局操作期间教学资料字节一致。
3. A 读取或保存未完成时切换到 B，迟到响应仍各归原图。另一标签先保存当前图后，旧版本保存提示冲突并保留草稿。写入失败也可留在页面重试。

### Edge Cases

- 缺少个人布局时，显示按推荐顺序排列的默认画布。
- 个别成果不可读时，提示问题并保留其他可读成果。
- 磁盘布局损坏或写入失败时，提示实际状态并保护已保存资料。

## Requirements

### Functional Requirements

- **FR-001**：本地阅读器必须列出已保存闭环，支持按标题切换、空状态提示及返回文件或依赖图。对应 V01。
- **FR-002**：显示主题、目标、串讲及入口，支持按保存的推荐顺序及实际连线阅读，连线附保存的原因。对应 V02。
- **FR-003**：每步按需显示自己的讲解、提示、保存的原块讲解及固定源码和行号。源码不可读时就地诊断，讲解与画布可用。对应 V02。
- **FR-004**：用闭环步骤自身的身份选择、布局和恢复步骤。同一原块可用于多个步骤。图例展示保存的库介绍、参与文件及各自用法。对应 V03。
- **FR-005**：共用画布支持拖动、命名分组、加入和移出成员、拖组、平移、缩放与保组重排。对应 V04。
- **FR-006**：坐标、组及视野按项目和图保存与恢复，写入保护成果、其他图和已有依赖图布局。迟到结果和冲突按原图处理，写失败可重试且状态如实。对应 V04。
- **FR-007**：界面、导航和反馈随现有中英文选择变化，读者和作者的内容保留原文。对应 V01。
- **FR-008**：桌面保留闭环右侧阅读，可在此读当前步骤解释、源码和分支理由，窄窗保有相同阅读能力。按 [006 FR-016](../006-file-reader/spec.md#functional-requirements) 返回当前可用的原闭环与步骤。闭环和依赖图各自管理选择、工具及保存布局。

### Key Entities

- **已保存闭环**：主题、目标、串讲、入口、推荐顺序、教学步骤、连线及使用的库。
- **教学步骤**：闭环内身份、讲解、提示、原块及固定提交下的源码定位。
- **个人布局**：一张图的节点和图例位置、组、视野及当前保存版本。

## Success Criteria

### Measurable Outcomes

- **SC-001**：读者从数量校验走到两种结果，能逐步复述连线原因并区分两处共享原块的讲解。
- **SC-002**：两条闭环及一张依赖图重开后各自恢复位置、组和视野。同库图例可保留不同排布。
- **SC-003**：迟到响应、旧标签保存和失败重试三个场景中，磁盘和页面状态均归正确的图，内容文件字节一致。
- **SC-004**：更改当前讲解或让一处固定源码不可用后，已有闭环仍呈现保存的讲解、可读步骤及相应诊断。
- **SC-005**：以 [006 SC-013 与 SC-011 的桌面和窄窗](../006-file-reader/spec.md#measurable-outcomes) 打开订单闭环，读右侧步骤解释、源码及两条分支的理由，沿一个分支前进一步，再切依赖图并后退。闭环恢复该步骤和视野，依赖图的视野与布局独立。窄窗仍可读上述内容。

## Assumptions

- 读者已有 D015 创建的闭环。源码显示依赖原提交中的文件仍可读取。
- 本批限本地阅读和个人排布。路线高亮、闭环内容更新与历史、编辑及整页视觉重设沿后续任务。
