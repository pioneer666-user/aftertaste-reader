完成范围如下。

| 项目 | 完成情况 |
| --- | --- |
| 自由布局与组移动 | 鼠标拖节点、命名组、拖组，全部成员同位移，处于背景范围内的非成员不跟随。替换成员后背景与实际 DOM 范围一致。 |
| 持久保存与恢复 | 拖动结束、组信息应用和视图移动结束后保存。服务完成临时文件写入、sync、关闭与替换后确认，页面才显示已保存。Edge 三次关闭页面／浏览器／服务并重新启动，恢复前后磁盘 JSON、修订号、实际节点与视图矩阵一致。 |
| 图更新保持布局 | 更新文案／边保留存续节点位置，新增 e 在已有排布外侧；确定删除节点不移动其他节点，空组消失；最后重开仍保持。读取失败或不完整图保留当前状态与磁盘文件。 |
| 保存失败 | 同一保存实现于替换前注入失败，页面显示失败并保留新坐标，旧文件逐字不变。恢复写入后重试，再完整关闭重开恢复新布局。 |
| 重排保组 | 简单算法以组为单位排列节点，组名和成员保持，模型检查覆盖重复重排幂等。成本处于本单允许的小量应用代码范围。 |

Vue Flow 提供拖动、连线、平移缩放与事件。应用代码负责显式成员、背景边界、组成员同位移、增量协调、默认重排及保存状态；Fastify／Node 实现本机文件读写。正式协议、产品代码和其余实验均留在各自任务范围。
