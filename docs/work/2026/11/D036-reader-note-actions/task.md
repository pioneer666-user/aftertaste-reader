# D036 · 文件讲解选文与新建笔记

## 目标与批准依据

类型为实现。读者遇到一句值得记的原文，划选后能就近带着引用记笔记；另有独立想法时，可以在当前项目的任意页面直接开写。回到讲解时看得出落点，普通点读和划词时正文保持安静。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。需要实际改写或删除作者资料时，按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

- **选文就近操作。** 在同一正常讲解块内选中非空文字，于松手端附近显示一条浮条，只放「复制块定位」「加入笔记」两个图标按钮。指针悬停或键盘聚焦可见对应名称，读屏可区分两项；窄窗内可直接点按。移除块尾临时按钮与相关避让，浮条出现、提示名称或收起均保持正文及下方批注、书签的位置。操作图标时保住原选文，边缘或反向划词也能操作。取消、Escape、换篇或无效选区遵守既有规则。保留原生选文复制、块首整块定位入口及剪贴板写入失败时的手动复制。
- **带引用记笔记。** 点击浮条「加入笔记」沿用 D035 笔记工作台：看到刚划选的原话，明确选择用该引文新建，或选择现有笔记后追加。新建和追加的链接保留选文、当前讲解路径和块 ID，取消只结束此次待加入操作。工作台默认显示的第一条不能成为隐式写入目标。
- **随时记独立想法。** 六个页面的共用顶栏在语言选择器左侧提供同一个「新建笔记」动作，桌面用纸笔图标加文字，窄窗只保留有名称的图标。它接替笔记页原来的普通新建按钮，点一次即进入 D035 的空白笔记编辑器并聚焦正文。在划着文字或工作台有待加入引文时，全局新建仍是空白笔记；「用这段选文新建」作为针对引文的明确动作保留。笔记尚在读取时避免重复创建；已有编辑、未保存输入和失败后可重试的草稿沿用同一个编辑器的保护。站内后退沿原历史回到起点，从讲解页发起时能接着原文件、原块和原阅读位置读。
- **文档块落点。** 普通鼠标点击正文或拖选文字去掉围绕整块的深色描边。由笔记引用或本篇目录显式跳到块时，在讲解标题旁短暂显示可辨的细线；无标题时靠讲解开头。提示不移动文字。键盘导航让焦点在操作期间持续可辨，系统减少动态效果和强制色时仍能识别位置。书签、标注回访继续分别聚焦到那条记录或批注。阅读快捷键、主题及其余工作台改版留在本单之外。

**实施入口。** 在 006 的顶栏、选文、定位与访问历史，以及 011 的新建与追加场景内增量维护。按[Spec Kit 阶段与模板](../../../../development/spec-kit.md#incremental-input)使用 specify、plan、tasks；编码前以 analyze 核对，再按 implement 执行。程序从 `src/web/ReaderDocument.vue`、`BlockLocationControl.vue`、`App.vue`、`ProjectNotes.vue`、阅读器样式和双语文案接入。复用选文捕获、复制反馈和笔记编辑器，按[技能适配](../../../../development/skills.md)用 Ponytail full、Impeccable 对应局部交互；更新[阅读器说明](../../../../usage/file-reader.md)。正式回归放 `tests/browser/`，运行记录归 `.local/D036/<run-id>/`。本批沿用个人资料格式与存储接口。

## 验证与停点

1. **选一句，正文留在原位。** 主脑在 4341、Edge、1440 × 900，从 `src/service.mjs` 首块 `zhidif44` 实际拖选「服务随后忽略这个返回值」。原版浮条只有「复制块定位」，块尾另现「加入笔记」，下方记录区下移 52 CSS px，块获得 2 px 深绿色整圈焦点线。候选用同句、同窗和鼠标动作，观察浮条出现前后相同正文与记录区的位置，悬停及 Tab 均能辨明两个动作。实点复制并粘贴核 U73 和原选文，核普通 Ctrl+C、剪贴板被拒后的手动复制。向上反选、窄窗边缘、跨块／跨源码、取消或切篇后核浮条及目标。复用[阅读中区回归](../../../../../tests/browser/reader-center.mjs)。
2. **分别走带引用与空白两条路。** 在隔离副本从浮条用选文新建，再从另一块选择已有笔记并追加，读回两段引用及各自目标。另走一次取消，核记录无写入。六页均可发现全局入口，从讲解中段实点新建、写字并读回，然后后退接着原段读；在笔记页待处理引文时点全局新建，验证正文为空、此前记录完整。核窄窗、英语和键盘操作，以及已有草稿在切换中的可找回性。复用[笔记](../../../../../tests/browser/notes.mjs)、[工作台](../../../../../tests/browser/record-workbench.mjs)与[站内历史](../../../../../tests/browser/reader-history.mjs)回归。
3. **分清点读与跳回。** 鼠标点正文及划词，查看整块轮廓；从目录和笔记链接跳入同一块，另从书签、标注返回具体记录，核可见提示、实际焦点及下一步键盘操作。包含无标题讲解、强制色和减少动态效果。桌面与窄窗实际核顶栏、浮条、提示和右侧工具可达，保留一组同块同窗的前后对照。[导航回归](../../../../../tests/browser/reader-navigation.mjs)

按[试读资料与副本约定](../../../../../tests/README.md#页面改版共用试读)，新建、追加、写失败等写入验证只在隔离副本操作；保留共用项目的实际笔记、批注、书签、闭环和布局。执行自测串行，冻结候选、构建和输入后由独立审查子代理用另一份副本实走选文、空白新建与返回、鼠标和键盘落点，复验修复的原失败路径。若必须改写作者资料或改变原记录语义，先交回具体影响。
