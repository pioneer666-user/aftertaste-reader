# D022 · 阅读页文件树、块目录与块内记录

## 目标与批准依据

实现任务。读者能像用文件管理器一样展开目录、打开已有讲解，再从同一侧栏跳到本篇某一块。收栏后把宽度让给源码和正文。平时先读讲解，从书签或批注回来时能直接认出自己的那条记录。

2026-11-19，作者在页面优化主脑会话提供当前阅读页及文件树示意，指出“这个栏应该是能展开能收回的”“侧边栏下面我觉得可以放当前的这个文档里面的标题”“我觉得这应该先修”。认可书签、批注沿书页样张处理。经核实当前四篇七块中有三块无标题，作者选定“首句短摘，必要时显示位置”。作者同意把现有浅绿色作为首版第五套配色。[五色范围与后续批次](../../../../product/backlog.md#b006--个人阅读记录做完后查漏再集中优化页面)

## 范围与材料

- 仓库 `D:/project/SpecDev Harness/aftertaste-reader`。产品基线 `dev@c0d8ec8`；派单分支 `codex/feat-reader-navigation` 继承试读资料提交 `636ca7d`。派单提交随转交消息提供。执行在此分支接续，作者试读资料和 [4341 入口](http://127.0.0.1:4341/)按[共用试读说明](../../../../../tests/README.md#页面改版共用试读)沿用。
- **文件树与收栏。** 上半部由已有讲解的源码路径组成。文件夹可展开、收起，文件叶显示文件名，按目录及完整路径区分同名项。打开文件、从记录跳入文件时能找出当前项及其目录。收栏后仍有可见的打开按钮；再展开保留文件夹状态和阅读到的块。窄屏按需打开导航，选中后回正文；键盘可选文件、跳块、关闭面板。顶部以项目名为主，完整路径可查。
- **本篇目录。** 下半部按讲解原序列出每个有效块，文件多时仍能找到本篇目录。有块首 Markdown 标题用标题，无标题用第一句可读正文的短摘；只有代码、空正文等无合适文字时，对照块显示真实源码行范围，纯讲解块显示其在文档中的序号。标题内行内样式取可读文字，围栏内的 `#` 按内容处理。每块一项，重名项仍以文档路径＋块 ID 跳对位置。手动滚动可更新当前项，键盘焦点随读者操作；快速切文件时，目录与所示正文始终一致。普通 Markdown 降级时展示既有诊断，仅在有可靠块结构时提供块导航。
- **块内书签和批注。** 正文标题、讲解排在记录编辑操作之前。日常能看见理解状态及已有书签／批注的入口，按需展开原话与编辑操作。由书签进来直接呈现并聚焦所点的那一条收藏理由（同块可有多条）；由标注进来呈现该块的状态及已有批注。保留三态、编辑清空、失败和草稿反馈、选文加入笔记及现有键盘回访。沿用浅绿色做本批试读。全站主题切换、管理页整页改版与列表返回位置、图页和长讲解的源码吸附分别留待后续。
- 正式设计在[既有 006 阅读能力](../../../../../specs/006-file-reader/spec.md)内增量维护。按 [Spec Kit 接入](../../../../development/spec-kit.md#incremental-input)用 specify／plan／tasks 的生效模板维护本批增量，再用 analyze／implement 核对并执行。复用[现行块格式](../../../../../specs/001-first-release/06-document-blocks.md)、[书签](../D019-block-bookmarks/handoff.md)和[批注](../D021-understanding-marks/handoff.md)的资料与验收。沿[Impeccable 的阅读与操作适配](../../../../development/skills.md#impeccable)细化。改动落在 `src/web/` 与受影响的阅读说明、测试和 006 设计材料；使用现有数据，目录标题在阅读时提取。

## 验证与停点

1. 在隔离副本打开 `src/service.mjs`，展开 `src`，从三项目录跳第二、第三块。收起侧栏、重开，核当前文件、阅读块和展开分支。窄屏用键盘完成一次选文件、跳块、关面板并继续阅读。
2. 切到 `support/audit.mjs`，从“辅助文件拼接日志路径”和“从已有名字构建路径”分别跳到对照块与纯讲解块。补查同名文件、重名标题、仅代码或空块、降级页；确认切换语言后界面文字随语言变化，标题及摘句保留原文。
3. 从数量规则的书签回到那条收藏理由，从「不理解」回到该块疑问，普通阅读时正文在先。复验同块多个书签、从跨文件笔记回原块和受排布调整影响的编辑状态。实际操作先于补充回归，按影响串行运行。作者的 4341 项目供体验，写入式技术检查在 `.local/D022/` 隔离副本进行。
