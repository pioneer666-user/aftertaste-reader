| W04 失败仍可阅读与修复定位 | 直接打开时执行必要检查，不以 AI 事先跑过校验为前提。结构或范围不适配时说明问题，安全地按普通 Markdown 展示可读原文，并提供可复制的修复信息（文档、实际可确定的提交、源码路径、块／行／字段、问题及下一步）。Git 仓库／提交／对象不可用时，已有讲解仍能打开，源码明确不可用；启动和资料列表不能因取源失败一并挡住讲解。文件本身不可读则显示读取错误，不假称已降级展示。沿 U101 不换工作区／HEAD、不修 Git、不生成源码副本；诊断和修复信息不带源码正文 |
| W05 首批双语界面 | 按 B003 分离按钮、导航、空态、警告、错误、保存语言选择结果及无障碍文案；同一套组件可切换简体中文／英文。默认简体中文，优先恢复当前阅读器站点在本浏览器已保存的有效选择，缺失翻译回退到中文；仅持久保存界面语言，不保存源码或讲解正文。浏览器无法保存选择时仍可在本次页面切换。切换保留当前文档和阅读位置，刷新能恢复已成功保存的语言；用户内容不翻译。诊断按稳定 code／参数映射，不解析中文句子来识别错误，英文长文案下界面可读 |
| W06 只读边界与安全呈现 | 本批没有生成、编辑或删除项目资料的 HTTP 能力；正常读取、刷新、降级和失败均不改目标项目、源码或个人资料。请求只能访问启动时选定项目内本批允许的资料及其固定源码，核查路径穿越、编码形式、Windows 别名、链接／junction 及任意磁盘资源请求。服务核 Host／来源访问边界；源码和讲解中的 HTML／脚本按不可信内容处理，代码示例按文本显示。页面资源随构建提供，阅读无需在线 CDN；动态源码不进入文件、日志、浏览器持久数据或应用缓存，不返回无限制文件读取接口 |

## 验证与停点

- 自测覆盖 W01—W06，并把主要场景串成真实用户路径：从非目标 cwd 启动服务 → 浏览器选择 D010 两篇讲解 → 查看源码与正文 → 切换语言 → 修改工作区但仍显示固定提交 → 更新讲解并刷新 → 停止／重启服务。用实际接口和 DOM／截图核可见结果，不用组件静态快照代替浏览器操作；此为正式功能验证，不是另开实验。
- 针对性检查：同名／不同扩展名文件、纯讲解块、空源码／空正文、阈值边界与长内容；坏标记／覆盖错误、Git 不可读、文档不可读、无资料；快速切换文档或刷新后旧请求不能覆盖当前选择。动态内容和结构化诊断与 CLI 共用语义；只读请求前后核目标资料字节未变。
- 入口和渲染检查覆盖 W06 的实际攻击输入及普通合法路径，尤其 Windows 别名、编码穿越、链接目录、不可信 Markdown／URL；不为本地只读服务建设账号权限平台。语言检查覆盖全部本批可见状态、缺失键回退、浏览器存储不可用和英文长文本；界面切换不重新生成内容。
- 按实际改动执行类型检查、构建、共用逻辑／接口及浏览器检查；D007—D010 未变部分复用同版有效证据。Windows／Edge 主验，Chrome、Firefox 按[验证约定](../../../../development/verification.md)做受影响兼容检查，缺环境如实说明。不要并行开浏览器／服务或机械重复已通过检查。
- 完成后固定候选，调用未参与实现的独审子代理，按 Ponytail Review 追读取、HTTP、渲染和双语完整调用链；结合 Sharp Edges 检查参数／路径／来源／失败状态，以及 Impeccable 适用的页面检查。核验没有源码持久副本、跨项目读取、脚本执行、诊断误翻译或错误被吞。冻结相关构建、输入与服务候选，明确采集结束并交还写入，原文归 `review.md`；修复另提交并复核影响项。
- 作者体验前，提供确定的启动入口、合成样例及停止方式，最多三个关注点：源码与讲解是否容易对应、长内容与切换文件是否顺手、中英文及错误提示是否清楚。技术测试先由 AI 完成，作者验收不替代独审。待验资源说明候选、归属、数据位置及重启方式；只清理本次自建且不再需要的资源。
- 若必须改变固定源、源码只引用、资料保护、用户操作范围或依赖全局安装，带证据交回主脑，只暂停依赖部分；常规控件、端口、字段、局部组件与依赖选择由执行在本批内落实。两轮修复停点沿共同规则，不以缩减已批准阅读结果绕过失败。
