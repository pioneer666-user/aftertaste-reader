### 已确认发现

1. **[P2，需修复] 源码行号对比度不足**

   - **位置与场景：** [style.css:58](</D:/project/SpecDev Harness/aftertaste-reader/src/web/style.css:58>) 的 `.line-number`；背景来自同文件第 51 行 `.source-pane`。正常打开任意合法对照块即可触发。
   - **预期与实际：** 项目 craft-floor 要求普通文字对比度至少 4.5:1。实际 Edge 计算样式为行号 `rgb(100, 123, 109)`、面板背景 `rgb(242, 246, 242)`，字号 13px；按相对亮度公式计算为 **4.186:1**。对应 CSS 为 `#647b6d`／`#f2f6f2`。
   - **后果：** 低视力或低对比度显示条件下，读者较难辨认实际源码行号，影响按行核对讲解。
   - **最小修复：** 加深行号文字颜色，使其在现有面板背景上达到至少 4.5:1；保留现有布局，再核实际计算样式及源码阅读页面。
