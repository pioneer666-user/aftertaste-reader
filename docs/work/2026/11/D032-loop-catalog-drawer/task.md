# D032 · 闭环目录抽屉与满幅点阵画布

## 目标与批准依据

类型为实现。读者第一次进入闭环阅读就能在点阵上选择一条感兴趣的路线。读到一半拉出目录看另一条，再收起，眼前的节点仍停在原处。

2026-11-21，作者认可用真实路线缩影、标题、阅读目标和步数呈现目录，要求把目录放进闭环页左侧，「左侧边栏是拉出来，不会挤中间的画布」。主脑说明顶栏开合目录、已选图的画布工具常驻、选图自动收起、再次打开高亮当前图，以及未选时的品牌提示。作者答复「可以」，进一步确认「画布也是覆盖全，不留边边角角」「就算是左边没选图，页面也是画布状态，就是点阵这些」，要求本单只解决这些问题。截图圈出旧标题下方、左边及底边的空隙。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。需要实际改写或删除作者资料时，按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

**进入闭环页。** 共用顶栏下缘到窗口左、右、底边都是闭环工作区。未选与已选使用同一满幅底面，沿用依赖图点阵的密度、指针响应和减少动态效果的表现。收掉旧的选图横条、为大标题及常态保存提示预留的整行、外层内边距和圆角边框。已选后仍可辨认当前图名、打开概览、看到必要的状态与保存故障恢复操作。桌面右侧继续原位阅读概览、步骤与源码对照。本单打磨目录、空态和外框，沿用 D031 的阅读内容、节点和手势。

**有图但尚未选。** 第一次进入时目录展开，点阵直接可见。在抽屉右边可见的画布上居中放小号「回味」字标和「从左侧选择一个闭环，开始阅读。」若抽屉已收起，提示仍指向可操作的顶栏目录入口。仓内现有品牌依据是「回味」文字标识，本单复用字标。未选时不展示空白讲解栏、虚构节点或依赖图数据。真实空项目显示「当前项目还没有已保存的闭环」；列表读取中和读取失败分别显示相应反馈，失败可重试；单条坏资料给出原诊断，其余好图仍能选择。窄窗优先保证目录和长标题可读，选图后能继续读讲解。

**左侧目录。** 顶栏原位置的侧栏按钮在闭环页始终可用，含未选状态，名称、展开态与它控制的目录对应。目录从左边覆盖画布，桌面可继续看见原图，动效只作用于抽屉。头部为「闭环目录」、数量和轻量的列表刷新；每条整行可点，左侧小幅点阵图从真实步骤和有向连线概括形状，右列是完整标题、简短阅读目标、步数及去重文件数。长标题自然换行；操作靠键盘或点按也能完成。选中条目明确高亮，点选后收起抽屉。再次展开时保留目录位置，当前项可找回。顶栏按钮与 Esc 都能关闭，键盘关闭回到触发按钮；在目录内按键或滚动只作用于目录。

**画布稳定。** 选图后的左侧画布工具常驻，目录开关只操作目录；注意浮条和抽屉的层级与落点，选图、关闭以及返回画布工具都顺手。左下小地图、缩放控件及右侧阅读区以画布为定位依据。只开合目录或刷新仍存在的条目时，当前节点的屏幕坐标、平移缩放、小地图锚点、选中步骤、阅读位置和已固定源码应保持。目录动作本身不写个人布局，也不新增站内前进后退项。主动换图沿用各图独立状态和原有回访语义，快速切换以最后一次选择为准。

**实施入口。** 产品依据为 [08 现行规格](../../../../../specs/001-first-release/08-current-spec-and-acceptance.md)、[009 闭环阅读](../../../../../specs/009-loop-reader/spec.md)和 [006 共用顶栏与回访](../../../../../specs/006-file-reader/spec.md#functional-requirements)。沿 [Spec Kit 增量流程](../../../../development/spec-kit.md#incremental-input)用 specify、plan、tasks 对应技能与生效模板更新 009 US1、FR-001／008 及相关验收、方案与清单。顶栏在闭环页改控目录，替代 D031 的旧工具显隐规则；核对 006 中相应表述。同步 [列表契约](../../../../../specs/009-loop-reader/contracts/reader-api.md)，编码前以 analyze 核新增覆盖，再沿 implement 执行。

## 验证与停点

1. **首屏与四边。** 必要构建后，在[共用试读项目的隔离副本](../../../../../tests/README.md#页面改版共用试读)首次从文件讲解进入闭环阅读。1440 × 900 CSS px 下目录默认打开，字标和提示在右侧点阵上清晰可见。点开订单闭环，目录自动收起，右侧可读概览。两态分别用全窗截图和工作区四边坐标与同窗依赖图对照，留意顶栏下方、底边、横向溢出以及从空态到成图时的白闪。另实走 390 CSS px 窄窗的选图、收起及读步骤。
2. **读到一半查目录。** 在订单图平移、缩放，选「规则转换并检查边界」，固定源码、滚动讲解，再打开目录。确认订单行高亮，以鼠标浏览、以 Esc 收回，再用顶栏按钮开合一次。对比开前、滑动中、关后三个时点的同一节点屏幕坐标、画布视野、小地图位置及右栏内容与滚动；同时核焦点与写请求。只看开合终点会漏掉中途挤动画布。
3. **切图与状态。** 目录能一眼区分订单的 5 步分岔和「路径工具怎样处理文件名」的 2 步单线，数量取自真实资料。切到路径图再切回订单，核独立视野，试一次站内离开再后退。用隔离资料验证空列表及列表读取失败后的刷新；按影响补键盘、英语、减少动态、连续选择及依赖图顶栏原有操作。交付前在 4341 用原共用项目只读烟测。

冻结候选、构建与输入，交独立审查子代理实操前两条，给出每个场景对应的图、连续帧或位置量测、对应的测试入口。修复后用原失败输入复验，补受影响路径。如实现必须改变站内历史规则、资料保存语义或改写作者资料，交回影响和候选方向。
