# D037 · 浅色选区浮条与右上角随手记

## 目标与批准依据

类型为实现。读者划选一句讲解时，紧凑浮条少挡一行字；想到另一件事时，在右上角当场记下，仍能看到和操作刚才在读的内容。

2026-11-22，作者试读 D036 后提出缩小选区浮条，沿用图底部依赖摘要的毛玻璃材质；顶栏纸笔应在右上角覆盖当前页，并以小眼睛切换编辑和预览。主脑用 4341 实测尺寸和交互示意说明了 32 px 总高、约 380 px 面板、原地阅读、首次输入才建笔记、自动保存和失败重试。作者确认「改成32 px可以，复用毛玻璃材质，但是改成浅色，不要绿色的颜色了。然后右上角也按你说的做」，并指示「你出任务吧」。本单在 [D036](../D036-reader-note-actions/handoff.md) 之上替代全局新建后切到工作台的步骤。下文包含执行所需的全部设计决定。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。需要实际改写或删除作者资料时，按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

## 范围与材料

仓库 `D:/project/SpecDev Harness/aftertaste-reader`，基线 `dev@73a1fbc0e3a2594293ed25ef05b4f43c2ee9b1ea`，任务分支 `codex/feat-quick-note-overlay`。批准提交随派单消息提供。4341 的行为基线为受审候选 `667b47e`。

- **选区浮条。** 桌面鼠标下，两枚图标可操作时整条外框高 **32 CSS px**（包含边框与内边距），图标约 16 px，每个按钮的实际命中区为 28 × 28 px。触屏／粗指针给每项至少 44 × 44 px 互不重叠的命中区；窄桌面窗仍应按实际输入方式工作。复用依赖图底部摘要的半透明表面、约 4 px 背景模糊和上沿高光，缩轻投影。浮条的底、渐变、边线与阴影取中性浅白／浅灰，避免绿色染色。图底部摘要和正文选区沿用原配色。图标和提示在普通正文、选区上及强制色模式均可辨认。两个动作、键盘提示、原生复制与剪贴板失败后的手动复制沿用 D036；32 px 指通常的双按钮状态。
- **右上角随手记。** 六页共用顶栏的纸笔在按钮下方靠右打开一个非模态面板，桌面约 380 px 宽，窄窗贴合可用宽度。初始为空白编辑态，直接聚焦正文。面板覆盖页面，底下的正文、文件导航或画布保持原尺寸、换行与位置；点面板外能继续读、滚动和操作，面板留在原处。面板已开时再点顶栏纸笔，回到同一篇。点小眼睛在同一位置读 Markdown 预览，预览时显示铅笔；切回后保留文字、光标或选区及编辑位置。显式关闭即可回到原页继续，面板内可用 Esc 关闭并回焦顶栏纸笔。开合、切预览及自动保存均不新增站内前进／后退步骤。
- **什么时候形成一篇笔记。** 只打开、看预览或关闭空白面板均零记录写入。第一次实际输入正文（含粘贴或中文输入法提交）才形成一篇项目笔记，后续沿用现有自动保存、撤销、冲突提示和重试。输入后立刻关面板也要完成已发起的保存；失败时保留原稿，读者可在本次会话找回同一篇并重试。区分从未输入的面板与用户有意清空的既有笔记。浮层和工作台复用同一份草稿与保存队列，各自的当前选择独立。背景若正在编辑另一篇，或还在等用户决定把一段选文加到哪里，打开、写入和关闭面板后都能接续原任务。选区浮条的「加入笔记」仍按原句新建或明确选择已有篇追加。已有笔记的标签管理、桌面左右对照编辑沿用工作台。

**实施入口。** 以 [08 现行规格](../../../../../specs/001-first-release/08-current-spec-and-acceptance.md)、[006 文件讲解 FR-011、014—016](../../../../../specs/006-file-reader/spec.md)和 [011 项目笔记 FR-005、009、010 及 SC-006](../../../../../specs/011-project-notes/spec.md)为依据。按[Spec Kit 增量流程](../../../../development/spec-kit.md#incremental-input)在 006、011 使用 specify、plan、tasks 和对应生效模板校准本轮行为，编码前用 analyze 对齐，再按 implement 执行。前端落点在 `src/web/`。浮条见 `BlockLocationControl.vue`、`style.css`、`reader-corners.ts`，材质参照 `canvas.css` 的 `.canvas-panel-compact`。顶栏与工作台从 `App.vue`、`ProjectNotes.vue` 接入，复用 `notes-editor.ts` 的写入保护和 `markdown.ts` 的渲染。现版创建草稿便安排保存，并会切换当前笔记；改造时分别检查首次输入、背景选择及未完成保存。沿用[笔记契约](../../../../../specs/011-project-notes/contracts/notes.md)，更新[阅读器使用说明](../../../../usage/file-reader.md#记录项目笔记)。按[项目技能适配](../../../../development/skills.md)用 Ponytail full、Impeccable 检查实际视口与关键状态。运行输出归 `.local/D037/<run-id>/`。

## 验证与停点

1. **看浮条，也点浮条。** 4341 的 D036 在 1440 × 900 Edge 里划选 `src/service.mjs` 首块「服务随后忽略这个返回值」，实测外框 80 × 44、每项 36 × 36 CSS px。候选用同句、同窗核外框和两个真实按钮尺寸，留前后实图比较白灰玻璃在字面、绿选区上方的效果。悬停、Tab、复制、加入笔记都要实际命中，正文与下方记录区不跳。窄窗粗指针实点两项；窄窗细指针核紧凑态。复用[阅读中区回归](../../../../../tests/browser/reader-center.mjs)及 D036 的复制降级证据，受影响路径另验。
2. **一边读，一边记。** 从讲解中段打开面板，用一条带 Markdown 的短笔记走完输入、预览、切回原光标、继续写和关闭。期间在面板外滚动并点击正文，核其可操作和关闭后的实际阅读位置、历史及已存内容。任选一张已有图，核面板开合前后画布边界、视野和节点位置不变。六页入口均在本页起笔；另核窄窗、中英文和键盘，特别是 D036 修过的窄窗顶栏命中。复用[站内历史](../../../../../tests/browser/reader-history.mjs)和[工作台回归](../../../../../tests/browser/record-workbench.mjs)。
3. **空白、真写入、失败分别验证。** 在隔离副本统计空开空关前后的请求、笔记数和原件；测试快速重复点开、首次输入后立即关闭，重开项目读回恰好一篇。构造一次真实保存失败，关闭后找回原文、解除故障并重试；再验后台编辑另一篇或正在处理引文时随手记不会串写、抢选或吃掉原句。沿[笔记回归](../../../../../tests/browser/notes.mjs)把原先期望跳页、立刻建空记录和清除待处理选文的断言改为本批预期，保留既有草稿、冲突与选文写入覆盖。

用[共用试读资料的隔离副本](../../../../../tests/README.md#页面改版共用试读)做新建、改写、失败注入与重试，保护 4341 原项目的个人记录、讲解和布局。自测串行，冻结候选、构建和输入后，由独立审查子代理用另一份副本实走尺寸与材质、原页预览与回焦、空白及失败恢复。修复后复走原失败路径。若必须改写原项目资料，或保存机制无法保住已输入的原文，先交回证据与影响。
