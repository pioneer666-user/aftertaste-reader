# D052 · 双图连线短文本、配色与沿线选中

## 目标与批准依据

实现任务。读者查看一条关系时，可以沿着曲线找到两端、看到讲解 AI 为关键连线选写的一小段文字，并按需读完整理由。闭环图用它讲清条件、值及其他关键关系；文件依赖图只在极少数确有帮助的线上标字。

2026-11-25，作者根据两张真实试读截图指出「哪些线高亮就展示哪些线上的数据」「不必每个线都有数据」「点这个线出现的边框我觉得可以去掉」。随后明确「先做好这个通用的能力，不一定现在就定好以后它只用来做什么」「红色和绿色和主题色，然后让讲解AI自己选择是否用颜色，默认是主题色」，并批准「可以，你出任务吧，就这样做」。[讨论示意](edge-selection-reference.html)供对照曲线、箭头和短标签；示意中的示例切换用于讨论未来路线，本单验收通过现有的节点高亮和直接选线完成。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。遇到已不支持的旧文档格式，识别脚本只负责报错或警告，让使用产品 Skill 的 AI 知道哪个文件受影响、原因是什么。AI 按当前 Skill 的正常生成、校验流程改好或重做相应讲解、闭环，无需维护逐版迁移脚本或另写兼容指南。实际改写或删除作者资料仍按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

## 范围与材料

基线为 `D:/project/SpecDev Harness/aftertaste-reader` 的本地 `dev@42ce69e`，任务分支 `codex/feat-graph-edge-labels`。派单提交由转交消息提供。

- **AI 写什么。** 连线可单独选填短文本和配色。允许只写字、只选色、两者都填或都省略。未指定颜色时使用当前主题的默认线色。另两种选择为红、绿，随主题调整明暗。AI 依据讲解目的选用，读者凭文字、方向和完整理由也能读懂。保留原有完整关系理由；有理由的边可以完全没有短标签。短文本按普通文字呈现，可写「返回 4」「取自登录上下文」「命中缓存」等。不要按真假自动配红绿，不要求每线补值，也不把示例写成实测数据。
- **哪些线能用。** 两图共用一套呈现规则，适用于已有的文件依赖、教学步骤连线，以及图上已有的库到文件／库到步骤用法线。箭头保持各图原义，实线与库用法虚线仍可区分。依赖图优先靠点线后的完整理由解释关系，AI 仅给对理解该依赖特别关键的边写短文本。闭环的节点 Markdown 说明继续就地收展。
- **什么时候显字。** 全图浏览时连线淡显。沿用悬停、键盘聚焦或点选节点产生的关联线高亮；两图也能直接点线或用键盘选线。只在已高亮且写有短文本的边旁显示紧凑单行标签，底色清淡，避开箭头和节点。直接选中的线优先。遇到短线、交叉、密图或缩小后放不下时，就近省去放不下的标签；点选该线后仍可在图的现有关系详情区域读全短文本、两端与理由。
- **怎样看出选中了哪条。** 鼠标或触屏选中后，曲线稍加粗、起点有小圆点、终点箭头用同一强调色；键盘焦点沿曲线再给可见描边。取消包住整条曲线的矩形框，同时保留易命中的线与可分辨的键盘焦点。点选的反馈跟随原路径，前景线经过其他节点时仍能操作下面的节点。闭环点线和关闭连线详情后，保留正在读的步骤、右栏开合和已固定的源码。查看关系不写布局，也不挪动手摆的节点或组。
- **交付链。** 依赖资料走 `apply-graph`、`validate-graph`、`query-graph`／`query-legends`，闭环走 `create-loop`、`read-loop`（JSON 和 Markdown）。在正常制作、机械校验、保存、后续读取和阅读页贯通选填信息。复用 `skills/aftertaste-reader/references/` 的制图与闭环指导、`src/core/` 两种图的关系模型、`src/application/` 与现有 CLI／读取接口、`src/web/` 共用画布和主题。旧资料省略这两项即走默认呈现。这一单只需读取图上写好的关系。制作深度选择、按示例高亮整条路线属于 [B011 的后续工作](../../../../product/backlog.md#loop-depth)。
- **规格。** 从[现行规格 R08、R16–R18](../../../../../specs/001-first-release/08-current-spec-and-acceptance.md)进入，增量维护[依赖图资料](../../../../../specs/004-dependency-graph/spec.md)、[共用画布](../../../../../specs/007-dependency-canvas/spec.md)、[闭环制作](../../../../../specs/008-loop-authoring/spec.md)、[闭环阅读](../../../../../specs/009-loop-reader/spec.md)中受影响的要求、模型与契约。沿 [Spec Kit v1.4.0](../../../../development/spec-kit.md) 读取对应的 `speckit-specify`／`spec-template`、`speckit-plan`／`plan-template`；维护正式实施清单时沿 `speckit-tasks`／`tasks-template`，保留已有结构与有效证据。

## 验证与停点

1. **读一张数量闭环。** 复用 [D051 数量订单样例](../D051-loop-node-annotations/trial-input.json)，在同一步的两个出口分别展示绿色「返回 4」、红色「非整数，抛错」，建单到追加这条边用主题色、留空文字。高亮判断节点时能区分两路，换到无标签的边只见线。鼠标点一条线再关详情，键盘沿线聚焦和激活，触屏点按，确认容易看清选中了哪条线，焦点和选中都没有矩形黑框，返回原步骤能接着读固定源码和节点说明。
2. **读一张文件依赖图。** 用同项目带多条依赖及库虚线的图，保留多数边无标签；给一条关键关系写有源码依据的非判断类短文本，并省略配色。沿被依赖方到使用方点线，从底部读到完整两端、短文本和原理由；选一条无标签的边也能读理由。核短文本与颜色的四种组合、无标注旧图及库用法的归属。密图、窄窗和缩放下验标签避让及详情兜底，拖动节点或组后标签仍跟对线。取浅、深主题看文字、红绿、箭头和焦点，核各现有主题默认配色。
3. **从 AI 制作走到真实页面。** 在隔离样例中显式加载安装包 Skill，按两种图各自的正常入口制作、校验并读回。用同一固定提交对照标签、完整理由、语义色和实际关系，确认选填项缺省、错误字段／颜色有对应诊断、后续读取不会丢标注或串到另一条边。按影响在 `tests/unit/`、`tests/integration/`、`tests/browser/` 和 `tests/fixtures/` 复用或补测，核个人布局与只读操作。回执提供可直接打开的闭环与依赖图，并附选中曲线与键盘焦点的实图。
4. 检查串行，使用本地样例副本及独立空闲回环端口，运行输出存 `.local/D052/<run-id>/`。保留作者真实服务 4317、D051 试读 4352 及其他在用服务和资料。若确需改变既有箭头含义、用户布局或引入按示例制作整条路线的流程，先交回具体取舍；其余沿共同修复停点。
