# D033 · 闭环阅读栏收展、步骤关系与画布内解散分组

## 目标与批准依据

类型为实现。读者可以收起右栏沿画布上的真实连线追到某一步，再展开读这一步的讲解。整理分组也在画布上完成，阅读栏专用于阅读。

2026-11-21，作者在 D032 试读后提出将图名移到画布左上，右侧阅读栏可收展，入口与上／下一步靠栏边，选中节点后在画布底部用依赖图同款毛玻璃显示前后关系；分组移出右栏，「把这个组删掉，组内节点就是待在原地」。主脑以订单失败分支说明推荐阅读顺序与实际连线的区别，以及主动收栏后沿线选步、再次展开直读当前步的操作。作者答复「行，我们先做这些，你出任务吧」，并把解散分组的具体入口交主脑建议。本单采用组名条右侧「⋯」打开具名操作。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。需要实际改写或删除作者资料时，按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

## 范围与材料

仓库 `D:/project/SpecDev Harness/aftertaste-reader`，基线 `dev@78e9b3f4418534a70468773696d190b12aee2503`，任务分支 `codex/feat-loop-reading-panel`，派单提交由交接消息提供。[D032 回执](../D032-loop-catalog-drawer/handoff.md)记录 4341 固定构建 `19652cc`、原共用项目和布局。主脑在此构建实点过订单校验步及失败出口，确认右栏显示分组表单，失败步的「推荐上一步」指向成功路线的末步。

**图名与右栏。** 打开一张新图先看到现有概览。将可点击图名从右栏移到画布左上；激活它回到本图概览，收栏时主动点图名也可打开概览。长名在窄窗仍可辨识，避让左目录及操作提示。右栏和画布交界处保留可见、可用键盘或点按的收展把手，收起后把手贴工作区右边。展开时点节点仍直读；主动收起后，点节点或从关系条换步只更新当前选择，手动展开才展示当前步。只开合保住视野、节点和小地图的屏幕位置。原步收起再展开能接着原位置读，已固定的源码跟随右栏收起；再展开沿 D031 的同引用、换引用及无源码规则恢复相应对照。临时预览和被覆盖控件妥善退出焦点，收起后可操作露出的画布。

**栏边导航。** 把「入口」「推荐上一步」「推荐下一步」放在右栏靠画布的一侧，长文滚到底仍可用。入口始终按 `entry`，上／下一步只按 `reading_order`，首尾给出可辨的不可用态；概览与库图例没有当前教学步时保有适用的入口。控件紧凑，悬停、键盘聚焦可知动作和目标全名，点按也能辨认用途。收栏后留下展开入口。图名、目录入口及读步骤的入口各有明确名称。

**画布底部关系。** 选中教学节点时，在可见画布底部中央出现低矮的毛玻璃条，材质、连续圆角及小地图避让参考[依赖图摘要 FR-020](../../../../../specs/007-dependency-canvas/spec.md#functional-requirements)。以本闭环保存的有向边列「来自」与「通向」。点名称选中相应步，沿用当前右栏显隐；所有目标的全名与该边保存的理由均可查阅。长名可省略、多项可用「另 N 项」展开，鼠标、键盘和触屏均能看全、选到每条分支。无出口时能辨认路线终点。概览、空白或选库图例时收起上一步的关系条，图例沿原入口读介绍和用法。右栏保留讲解与分支理由，关系条在收栏时也可独立追图。抽屉、源码面板和底部工具按当前层操作；选步、查关系、收展都不写个人布局或新增站内历史。

**分组回到画布。** 沿用框选浮钮、Ctrl+G 命名、组名拖动与左浮条分组入口；改名、成员调整和解散用画布内的菜单或短面板完成。组名条右侧常有轻量「⋯」按钮，名称包含组名；组名与菜单按钮分开命中，点菜单不触发拖组、框选或改变正在读的步骤。操作项末尾写「解散分组」，附「节点保留在原位」。点明此项即应用，展开菜单或按 Esc 退出均不改布局。解散只移除本组和其成员归属，组内节点、连线、其他分组、位置及视野保留。保存反馈沿现有状态和重试；触发组消失后焦点回到可用画布。阅读区移除分组表单。本单的页面改版范围是闭环，共用逻辑沿现有依赖图入口做回归。

**实施入口。** 依据 [08 现行规格](../../../../../specs/001-first-release/08-current-spec-and-acceptance.md)、[009 闭环阅读](../../../../../specs/009-loop-reader/spec.md)及 [D031 步骤直读和源码对照](../D031-loop-reading-canvas/task.md)。沿 [Spec Kit 增量流程](../../../../development/spec-kit.md#incremental-input)，以 specify、plan、tasks 对应技能与生效模板更新 009 的 US1／US3、FR-002／003／005／008 及受影响的文字、方案与试读步骤。核既有“点空白回概览”、图名入口及开栏后的路径，编码前以 analyze 核覆盖，再沿 implement 执行。

入口在 `src/web/DependencyCanvas.vue`（标题、组拖动、选中态、浮条）、`LoopReading.vue`（阅读顺序、真实出口、源码浮层）、`canvas.css` 与界面翻译。共用 `src/core/canvas-layout.ts` 的 `updateGroup` 已支持清理空组，布局保存独立于闭环内容。读到的闭环已有目标、连线和理由；此单沿用现有资料、接口与站内历史。更新[阅读器说明](../../../../usage/file-reader.md)；正式回归在 `tests/browser/`，运行输出归 `.local/D033/`。

## 验证与停点

1. **从图读懂失败路线。** 在[共用试读项目的隔离副本](../../../../../tests/README.md#页面改版共用试读)打开订单图，选「规则转换并检查边界」并收起右栏。底部应列出来自「服务先交出原始数量」，通向「规则返回后回到服务」和「无效数量让创建提前结束」。从底部走失败支，右栏保持收起；展开后读到集合没有改变的原因。此时实际来路是校验步，栏边「推荐上一步」却去「订单加入集合并返回」。两条都实点，再用「入口」回到首步。关联回归沿 [闭环主阅读](../../../../../tests/browser/loop-main-experience.mjs)。
2. **确认满幅和收展手感。** 同一桌面窗口平移、缩放，在一个长步骤固定源码并滚动讲解；收起再展开，以及收起后主动沿线换步。采集收展前、动画中、完成后的节点和小地图位置，核画布可操作区域、阅读滚动、源码和焦点。另走目录展开再关闭、点击图名回概览、选择库图例、390 CSS px 的点按和桌面键盘；长名称、多出口和减少动态按影响验证。复用 [D032 目录回归](../../../../../tests/browser/loop-catalog.mjs)与[站内回访](../../../../../tests/browser/reader-history.mjs)。
3. **解散经过拖动的组。** 在隔离副本框选成组、拖组并等保存完成，记下组员位置、连线、其他组和视野。先用「⋯」打开、Esc 取消，再用键盘或点按选「解散分组」。取消无布局写入，明确解散后仅这一组消失，保存并重开核成员仍在原位。补验证组名拖动、改名、成员调整、保存失败后的就地重试，沿[闭环分组](../../../../../tests/browser/loop-canvas-interactions.mjs)和[依赖图既有成组与解散](../../../../../tests/browser/dependency-canvas-selection.mjs)。作者截图中的「测试」组及其布局在共用 4341 原样保护。

自测后冻结候选、构建和输入，交独立审查子代理实操第 1、3 条及收展中的稳定性。每条给对应实图、量测或测试入口；修复后用原失败输入复验并补受影响路径。需要改闭环成品、历史规则或作者真实布局才可继续时，交回具体影响。
