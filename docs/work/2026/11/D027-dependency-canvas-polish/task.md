# D027 · 文件依赖图的连续圆角、曲线与点阵交互

## 目标与批准依据

类型为实现。在作者现有的 79% 订单依赖图上，读者从空白滑入 `service.mjs`，能认出文件、沿曲线找到上下游；也能顺手切工具、定位远处的节点、框选成组，并看出何时真正保存成功。

2026-11-20，作者指定「首先连线改成曲线，然后背景我喜欢点阵」「左下角加小地图和选择工具」「卡片的圆角要那种苹果这样的大厂用的 Squircle（超椭圆）」。主脑建议点工具固定、按住 Ctrl 临时反转，采用光标揭示、轻微鼓胀、一次回弹、组内同网格着色和新组保存成功时的单次涟漪。作者确认「可以，你在任务里说清楚，然后出任务吧。你说的单词涟漪也可以」。本单在真实依赖图上实现这组取舍，作者在 4341 判断手感与质感。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。需要实际改写或删除作者资料时，按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

## 范围与材料

仓库 `D:/project/SpecDev Harness/aftertaste-reader`，基线 `dev@5298a10`，任务分支 `codex/feat-dependency-canvas-polish`。派单消息提供批准提交。[D026 回执](../D026-dependency-canvas-selection/handoff.md)记录当前候选、共用控件、分组和恢复证据。本单的视觉、工具和反馈作用于**文件依赖图**。

| 读者在做什么 | 已定的视觉与操作 |
| --- | --- |
| 辨认节点 | 文件卡横向、近白底、细描边。直边到拐角的弯曲逐渐加深，执行选用能实际画出这种连续圆角的轮廓。卡面、描边、选中及键盘焦点轮廓沿同一形状；左右端口位于直边中点，焦点和框选可辨。文件名连扩展名是第一行主文字，次行是目录。已核对用轻量小勾并保留可访问文字；`support/audit.mjs` 明示「依赖待核对」。库节点用包图标、淡紫色及真实库类别。长路径、同名文件在详情与可访问名称中可分辨。 |
| 沿关系阅读 | 文件依赖用实线曲线，库使用关系用虚线曲线，箭头从被使用方指向使用方，落在目标卡边缘。选中节点时前景强调其直接相连的边，其他文件名仍可读。拖动节点时连线跟随端口，反向边、自环及关系原因仍可辨。从详情打开讲解再返回，保有之前的选中节点与视野。 |
| 在空白上移动和停留 | 浅绿灰底铺低对比细点。光标附近的点稍实、略大，外围轻微向外推；指针停稳后局部定住，移开后轻柔回弹一次并停稳。初次调校从约 **70 屏幕 CSS px** 作用半径、**2 屏幕 CSS px** 最大位移试起，可据实调，以作者缩放下的观感为准。空闲时画布安静。进入节点、拖图、拖节点或框选时让背景收住，光标层让出命中。 |
| 看分组、平移和缩放 | 点阵随主图视野平移缩放，缩远渐淡。组内外共用格点原点、间距和相位，组内仅略暖、略深。拖「订单处理」组时像移动一片有色玻璃，边界两侧格点保持对齐，只有显式成员跟着组走。 |
| 选择工具和找位置 | 左下角上层为小地图，显示全图与当前视野框。下层工具条放抓手、选择及原有缩放控件。点小地图定位，拖视野框平移；主图反向同步，小地图适配自身边界时保留主图视野。窄窗可收起小地图，保留工具和缩放。默认抓手，点按固定工具；按住 Ctrl 临时切到另一种，松开恢复。工具条与光标表达当前有效工具。两种工具只改变拖空白／组框背景的含义，单点读详情、拖节点及拖组名各沿原入口。一次拖动按鼠标落下时的工具执行到结束。 |

系统偏好减少动态效果时，使用静态点阵、组内色差、选中轮廓和可读保存反馈，停用鼓胀、回弹与涟漪。工具可键盘操作，组名输入框内沿用文本编辑行为。切页或窗口失焦时解除临时 Ctrl 状态，恢复固定工具。悬停、工具与框选草稿是页面即时状态。节点位置、分组以及读者实际改变的视野沿既有布局语义保存。读者已有的排布直接打开，保留原位；全图适配只用于小地图自身。

**实现依据。** 接续[现行规格 R16 和 A17—A18](../../../../../specs/001-first-release/08-current-spec-and-acceptance.md#graph-layout-acceptance)。按 [Spec Kit 增量入口](../../../../development/spec-kit.md#incremental-input)，在[现有 007](../../../../../specs/007-dependency-canvas/spec.md)使用 specify、plan、tasks 及生效模板维护本批要求，再以 analyze、implement 核对和执行。更新 FR-011 对默认手势的表述。本批尺寸、工具状态和验收定义集中在 007，快查与实施清单引用。图内工具使用已有中英文机制。

主要落点在 `src/web/`、`tests/browser/`、007 和[画布使用说明](../../../../usage/file-reader.md#dependency-canvas)。[DependencyEdge.vue](../../../../../src/web/DependencyEdge.vue) 已有 Bézier 与自环实现；[DependencyCanvas.vue](../../../../../src/web/DependencyCanvas.vue) 管理手势、视野及带修订的异步保存。实现先沿这些依据评估，必要时按职责分出画布部件。点阵使用本地可交付的绘制方案，停稳或隐藏后结束动态更新。若选新依赖或更改库用法，再针对引入理由和运行表现做专项研究。用 Ponytail 实现、Impeccable 局部呈现检查及 Ponytail Review 独审；点阵不另做独立演示页。

## 验证与停点

先取[4341 共用资料](../../../../../tests/README.md#页面改版共用试读)的隔离副本，保留作者现有的节点坐标、组和视野，固定这份对照输入。派单时原图为「订单处理」组、四个文件和标准库 `node:path`，视野显示 **79%**。若作者随后调过视野，在副本设置 79% 作对照。构建后首先从同一输入实走以下路径，再按影响补回归。写入、故障注入和重开保存检验均在副本完成。

1. **从空白滑入文件。** 在 79% 视图从空白缓慢移到 `service.mjs`，停住再点选。观察网点的推挤与归位、文件名及选中轮廓，沿 `rules.mjs` 和 `audit.mjs` 汇入的两条边、再沿通往 `api.mjs` 的边逐一追到端点。查看库虚线、组内外格点、长路径与键盘焦点。拖一个节点，核端点跟随；打开讲解再返回。
2. **用两种工具和小地图来回。** 分别固定抓手、选择，按住 Ctrl 反转，拖到一半先松 Ctrl 再松左键。核这次拖动自然完成，下次使用固定工具；再验失焦、组框背景内反向框选、边缘浮钮和 Ctrl+G 输入组名。点小地图及拖视野框，再缩放、收起小地图并重开图，核最终视野与原节点位置。窄窗实点工具与缩放，切闭环核步骤选择和独立视野。
3. **把保存与动效分开计时。** 在副本框选成组，暂扣这次布局保存响应，再释放成功响应，观察涟漪起点和次数。另做失败、重试成功、保存未回时切页和普通平移保存，核反馈对应正确组与修订。开启减少动态效果重走成功与失败，核两者可区分。重开核磁盘组名和成员。

保留同数据、同视野的改前／候选实图，以及可复核动效时序的一小段录屏或连续帧与实际保存结果。重点对照静止、划过空白、进入节点、成组成功。记录实测设备与浏览器、缩放和拖动是否跟手，按实际结果说明；桌面 Edge 主验，按影响串行补 Chrome、Firefox 的轮廓、手势和动效回归。证据放 `.local/D027/`，核心结论写回执。需要改变已定读图／保存语义或改写作者原资料时，交回具体影响。
