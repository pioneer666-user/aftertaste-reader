# D023 · 讲解中区阅读与复制块定位

## 目标与批准依据

实现任务。打开一篇讲解，读者能从标题直接开始阅读，读完几段仍能对照同一块源码。遇到疑问，可以留在原处复制块定位，粘贴到同项目的 AI 会话提问。

2026-11-19，作者在页面优化主脑会话认可「源码会移动的细节」，提出「用户点击项目名就出现一个窗口」和「鼠标旁边出一行功能框」，希望先复制讲解文档路径与块 ID。主脑用浅绿「书页批注」样张说明文件题头、源码随块停留、项目资料浮窗和现行复制格式后，作者确认「可以，出任务吧，别忘了我刚才说的设计原则」。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。需要实际改写或删除作者资料时，按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

## 范围与材料

**执行入口。** 仓库 `D:/project/SpecDev Harness/aftertaste-reader`。产品基线 `dev@6458be2`，派单分支 `codex/feat-reader-center` 从其后仅含派单原则与讨论记录的 `d470ca4` 接续。任务批准提交随转交消息提供。现版和换版说明见[共用试读](../../../../../tests/README.md#页面改版共用试读)。本机讨论样张可选看 `C:/Users/Lenovo/.codex/visualizations/2026/11/19/01a1f250-a3e6-7790-9353-2c75ae128ab9/reader-reference.html`。下面的操作和视觉取舍可独立用于实现。

- **找资料。** 侧栏以带展开提示的项目名为入口。点击或用键盘打开轻量浮窗，可查并选取完整项目路径、当前讲解文档的项目相对路径和该讲解引用的完整源码提交。正常校验结果放在这里。切文件时资料跟当前显示的讲解一致。源码缺失、讲解未完成或文档降级等影响阅读的状态仍在正文前可见，沿用已有诊断与修复入口。
- **读讲解。** 文件题头用一行呈现，如 `src/service.mjs`，目录色稍淡、文件名连扩展名突出，长路径可辨。题头与第一块之间用细线或等效留白分隔。右栏直接从原 Markdown 标题或首段起读，块 ID 收入定位操作。用中文实文调整行宽、行距和段距，区分正文内的代码示例与左侧固定源码。无标题块直接呈现原文，纯讲解块使用正文宽度。
- **对照源码。** 桌面左源码、右讲解。浅绿底板贴合代码高度，能放进可视区的短源码随本块长文停留，到块尾自然让位给下一块。长源码或矮窗按主阅读区滚动，最后一行可读。横向查看长行时行号留在左缘，缩进、空行和文本可见。窄屏上下排列。
- **带着疑问离开。** 同一讲解块内划选非空原文后，在松手端附近提供「复制块定位」。靠近窗口边缘时换侧避让，可用键盘抵达和执行。块标题旁也可直接复制整块定位，无标题块在块首提供等效入口。成功就近反馈，浏览器拒绝写剪贴板时提供相同的完整文本供手动复制。原生 Ctrl+C 仍复制所选文字。跨块、跨入固定源码、纯源码或取消选区时收起浮条，切文件后清掉旧目标。

复制文本按[既定格式 U73](../../../../../specs/001-first-release/05-reading-feedback.md#u73--复制文档块定位-v1作者授权-ai-定稿)生成，字段、路径基准、选文和转义以该节为准。缺少可靠的块身份或提交时走现有诊断。复制仅写入剪贴板，提问由读者自行粘贴。本批交付本地当前文件阅读页的入口。已有块尾「加入笔记」、书签与标注回访及五个顶栏入口沿 [D022](../D022-reader-navigation/handoff.md) 使用。浮条里的笔记操作、全局快捷键、五色切换、管理页、历史与导出页、AI 端答疑或写回另批处理。

正式设计在[现有 006 阅读规格](../../../../../specs/006-file-reader/spec.md)增量维护，接续 [08 的 R12 与 A11](../../../../../specs/001-first-release/08-current-spec-and-acceptance.md) 中本批页面侧的要求。执行按 [Spec Kit 增量入口](../../../../development/spec-kit.md#incremental-input) 使用 specify、plan、tasks 及其生效模板，再用 analyze、implement 核对和执行。具体尺寸、断点及其预期只在 006 的验收定义处写一次，快查与测试说明引用该处。页面按 [Impeccable 局部阅读与操作适配](../../../../development/skills.md#impeccable)实看。[ReaderDocument.vue](../../../../../src/web/ReaderDocument.vue) 已有单块选文判断和实际文档提交，[App.vue](../../../../../src/web/App.vue) 管理项目名与临时侧栏。预计改动在 `src/web/`、必要的定位格式化逻辑、`tests/browser/` 及受影响的 006 材料和阅读说明。运行证据放 `.local/D023/`。
