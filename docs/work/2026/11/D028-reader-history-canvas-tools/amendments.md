# D028 · 画布浮层样式调整

## 底部摘要

2026-11-20，作者在当前执行会话附上截图，用红色横线标出依赖图底部中央的位置，并明确要求「放成横的，占的空间小一些，框背景用那种半透明毛玻璃材质。」

原批准版本为 [D028 任务 @f00becb](task.md)。本条细化原任务「依赖图底部中央只在选中时浮出摘要」的呈现方式。桌面收起态用紧凑的横向单行布局，限宽并使用半透明毛玻璃背景。窄窗随可用空间调整，保留阅读讲解和查看关系入口。展开后仍可阅读完整路径和逐条原因。现行要求和验收见 [007 FR-020、SC-017—018](../../../../../specs/007-dependency-canvas/spec.md#functional-requirements)。

影响范围为依赖图摘要的外观、占用空间及对应的窗口和坐标复验。以包含此调整的下一次固定候选为生效版本，提交由本单回执记录。

## 左侧工具条

2026-11-20，作者附参考图并要求「左侧边栏做成这样的形式，这样好看，颜色还是咱们的主题色。」「位置放置左边正中间开始，居中对齐」「就是鼠标移到左边后才会出现文字介绍，默认只有图标按钮展示」。

在 [D028 原批准版本 @f00becb](task.md) 的依赖图左浮条范围内，沿画布左缘垂直居中，以回味主题色绘制窄胶囊。默认露出图标。鼠标进入浮条或键盘聚焦工具时，在各图标的右侧显示名称。短窗给小地图保留空间。现行要求见 [007 FR-019、SC-017—018](../../../../../specs/007-dependency-canvas/spec.md#functional-requirements)。本次调整在候选 `c0124ab` 的独审期间收到，生效候选由回执绑定。
