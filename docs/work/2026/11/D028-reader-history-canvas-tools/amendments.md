# D028 · 画布浮层样式调整

## 底部摘要

2026-11-20，作者在当前执行会话附上截图，用红色横线标出依赖图底部中央的位置，并明确要求「放成横的，占的空间小一些，框背景用那种半透明毛玻璃材质。」

原批准版本为 [D028 任务 @f00becb](task.md)。本条细化原任务「依赖图底部中央只在选中时浮出摘要」的呈现方式。桌面收起态用紧凑的横向单行布局，限宽并使用半透明毛玻璃背景。窄窗随可用空间调整，保留阅读讲解和查看关系入口。展开后仍可阅读完整路径和逐条原因。现行要求和验收见 [007 FR-020、SC-017—018](../../../../../specs/007-dependency-canvas/spec.md#functional-requirements)。

影响范围为依赖图摘要的外观、占用空间及对应的窗口和坐标复验。以包含此调整的下一次固定候选为生效版本，提交由本单回执记录。

## 左侧工具条

2026-11-20，作者附参考图并要求「左侧边栏做成这样的形式，这样好看，颜色还是咱们的主题色。」「位置放置左边正中间开始，居中对齐」「就是鼠标移到左边后才会出现文字介绍，默认只有图标按钮展示」。

在 [D028 原批准版本 @f00becb](task.md) 的依赖图左浮条范围内，沿画布左缘垂直居中，以回味主题色绘制窄胶囊。默认露出图标。鼠标进入浮条或键盘聚焦工具时，在各图标的右侧显示名称。短窗给小地图保留空间。现行要求见 [007 FR-019、SC-017—018](../../../../../specs/007-dependency-canvas/spec.md#functional-requirements)。本次调整在候选 `c0124ab` 的独审期间收到，生效候选由回执绑定。

## 试读后的细节打磨

2026-11-20，作者试读 `a33aabf` 后附三张图，要求「首先左侧边栏按钮颜色不要深色。然后收起侧边栏和展开应该有动画。」底部要「背景轻微模糊，带低透明度填充，边缘有细高光和半透明描边，整体像一层浮在内容上的磨砂玻璃」。作者另要求「右边的叉子关闭按钮做小一点，点击范围不小，按钮按我给你的第三个截图里面的样式，不要边框」，并补充「包括鼠标移到左边时出现的文字，要动画出现，而不是直接出现的」。

执行在 390 × 430 CSS px 复现「操作说明」名称挡住「阅读讲解」、指针移向名称时名称消失，以及指针停在原处按 Esc 无法关闭名称。审计实图见 `.local/D028/design-audit-a33aabf/`。作者确认整轮建议「行，先按你说的这些改，我们这轮专门设计这些细节上的东西。你把你提出的都改了」。

本次用浅色主题浮条替换试读版深色呈现，补齐显隐动效、标签的悬停与关闭、短窗避让和触控目标。收起摘要用磨砂玻璃，展开关系页保持实底便于阅读。底部操作采用参考图的无边框样式，缩小关闭图标并保留点击区域。相关控件统一字阶、间距、轮廓和交互反馈。范围限依赖图及其直接控件，现行要求和实现参数见 [007 规格](../../../../../specs/007-dependency-canvas/spec.md#functional-requirements)及[方案](../../../../../specs/007-dependency-canvas/plan.md#d028-试读细化)。生效版本为纳入此调整的下一固定候选，由本单回执绑定。

## 画布贴边与浮层轮廓

2026-11-20，作者根据试读候选 `2c7d349` 要求「左侧边栏的字字体粗细小一点，相当于字浅一些」「左侧边栏我说的居中是页面左边高度还要减去下面的哪个地图，然后再居中」「底部的那一栏两边做成圆头的，和左侧边栏一样」「就是边边角角，都用画布占满，不留空位」。作者用一张选中 `node:path` 的依赖图标出画布外缘、浮条和摘要两端，另一张图给出较浅的常规字重参考。

本条在 [D028 @f00becb](task.md) 的依赖图范围内，把画布铺到顶栏以下内容区的四边。浮条在画布顶边和左下工具区上边缘之间居中，名称采用较浅的常规字重。收起摘要两端沿浮条的圆头外形。现行要求、极短窗与形状参数见 [007 FR-010、019—020 和 SC-017—018](../../../../../specs/007-dependency-canvas/spec.md#functional-requirements)及[方案](../../../../../specs/007-dependency-canvas/plan.md#d028-画布贴边与浮层轮廓)。生效版本为纳入此调整的下一固定候选，由本单回执绑定。
