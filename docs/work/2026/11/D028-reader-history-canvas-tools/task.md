# D028 · 站内前进后退与画布浮动工具

## 目标与批准依据

类型为实现。读者在文件依赖图点选 `api.mjs`，能就近查看关系、打开讲解，读到中段后用后退回到原图，再用前进接着读。切页时顶栏入口位置稳定，查看关系时左下角小地图保持原位。

2026-11-20，作者在 D027 试读后提出「下面放一些比如，依赖之类的信息，然后放在中间不占满一行，这样左边的地图就可以不上移了」「加一个左右箭头按钮」「顶部侧边栏的按钮就每个页面都有」，并以浮在画布左缘的窄工具条为参照。主脑说明六页共用顶栏、站内访问位置和图内操作的分工后，作者确认「其他的你都理解的差不多」「右侧边栏主要是给闭环图里面的讲解去用的，如果依赖图里面用不上，我们也可以省」「然后你出任务吧，圆角统一范围太大我们可以后面再做」。本单采用依赖图底部摘要按需展开、闭环右侧阅读的安排。全站控件圆角另见[项目待办 B006](../../../../product/backlog.md)。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。需要实际改写或删除作者资料时，按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

## 范围与材料

仓库 `D:/project/SpecDev Harness/aftertaste-reader`。从 `dev@1be9d52` 建立任务分支 `codex/feat-reader-history-canvas-tools`，派单消息提供批准提交。[D027 回执](../D027-dependency-canvas-polish/handoff.md)提供当前试读版本、画布和保存证据。

- **六页共用顶栏。** 左侧依次为后退、前进、侧栏开关及六个固定页名。无可到达的历史项时，相应箭头留在原位并禁用。图中打开讲解后，页签仍叫「文件依赖图」。侧栏按钮也在六页同位，名称和展开状态对应当前页。讲解页控制原文件树与块目录，依赖图控制左浮条；其余页有可独立收起的现成辅区时接入，例如笔记列表。尚无适合辅区的页面同位显示禁用态，给出可读原因，避免开空面板或隐藏整页唯一内容。保留已有语言、刷新、键盘跳过导航及窄窗切页入口。
- **站内访问历史。** 本标签页内的成功切页、明确打开另一个文件或从记录跳到讲解块，构成可往返的访问步骤。重复打开同一个目的地或回访失败不增加空步骤。滚动、选图节点、变更筛选、开关详情、平移和缩放只更新当前停留位置；保存及编辑不是导航动作。后退后前往新目的地，旧的前进分支清除。第一版使用当前打开会话的历史，刷新后从当时实际进入的页面重新起步。
- **回到刚才读的地方。** 返回讲解恢复文档、所读块及块内阅读位置；返回依赖图恢复选中对象和视野；返回书签、标注或笔记恢复相应条目、筛选及列表位置，闭环恢复正在读的闭环和步骤。后退或前进取当前实际资料，保留笔记草稿、已改文字、节点坐标和组成员。目标失效时给出当前可用位置与原因。连续点击或读取较慢时，最终显示最后一次有效导航指定的页面，迟到的响应不能抢回焦点或改写历史。
- **依赖图左侧浮动工具。** 将「重新布局」、分组管理、刷新图与布局及简短操作说明移入靠画布左缘的窄竖条。悬停或键盘聚焦可见名称，点击和触屏有可达入口。顶栏开关可显隐工具条；空闲时图上方原有操作整行连同留白一起收掉。左下小地图、抓手、选择和缩放沿 D027 的位置及行为。分组仍可在鼠标旁或键盘操作，保存失败和重试就地可见。
- **依赖图底部中央只在选中时浮出摘要。** 例如 `api.mjs` 显示「依赖 service.mjs」「使用 node:path」，已有讲解可一步打开。摘要按内容收宽并设上限，空类别省略，有更多关系时给出可发现的展开入口。展开可核完整路径、核对状态与逐条关系原因，点相关文件仍能继续追图；选库可看类别、介绍和逐文件用法。无讲解、未核对等状态据实际资料呈现。详情和分组编辑可按需打开并关闭。依赖图省去专用右栏。摘要与展开面板悬在画布上，给左边小地图及工具条留位；窄窗可采用单一可关闭面板，底部工具仍可抵达。开关面板不改变画布尺寸、视野坐标或个人布局。
- **闭环阅读。** 桌面继续在右侧阅读所选步骤的解释、源码和分支理由。保持窄窗既有阅读能力。与依赖图共用组件时，两套页面各自的选择、工具和持久布局独立。本单沿用已有节点与页面外观，全站圆角及其他页面重设计后置。

正式需求与方案按 [Spec Kit 增量入口](../../../../development/spec-kit.md#incremental-input)使用 specify、plan、tasks 及生效模板，再以 analyze、implement 核对执行。[006 阅读规格](../../../../../specs/006-file-reader/spec.md)主定义共用导航、历史及回访位置，核 FR-011、SC-013 与原先后置的回访范围；[007 依赖图规格](../../../../../specs/007-dependency-canvas/spec.md)主定义浮动工具、摘要、完整关系及读图返回，调整原工具与详情呈现约定。沿[009 闭环阅读](../../../../../specs/009-loop-reader/spec.md)及[08 现行规格](../../../../../specs/001-first-release/08-current-spec-and-acceptance.md#graph-layout-acceptance)核右栏阅读和各图布局。视口尺寸与预期各在对应规格定义一次。

导航现状见 `src/web/App.vue`（六页入口、讲解页开关、来自依赖图的专用返回）；画布见 `src/web/DependencyCanvas.vue` 和 `src/web/canvas.css`。预计改动在 `src/web/`、直接受影响的 `tests/browser/`、规格及[阅读说明](../../../../usage/file-reader.md)。沿仓内 Ponytail、Impeccable 局部布局与交互适配；审查用 Ponytail Review。历史恢复为界面导航所需，本单不引入项目资料格式或要求另建路由系统。

## 验证与停点

必要构建后，先在[共用试读资料](../../../../../tests/README.md#页面改版共用试读)的固定副本走下列真实路径。派单前在 D027 的 1600 × 900 CSS px 中文窗口观察到：从讲解切到图，页签起点横移 38 px；点选 `api.mjs` 后，小地图工具区底边上移 136 px。用同一视口和输入比较候选的前后坐标及截图。运行证据放 `.local/D028/`。

1. 从讲解切进依赖图，打开和收起左浮条，依次选 `api.mjs` 和 `node:path`，展开、收起完整说明。核页签起点、画布边界、小地图底边及视野稳定；摘要居中收宽，逐条原因和库用法可读。实际通过浮条打开分组、找到刷新及重排。窄屏另验长说明、浮条与小地图可操作，并确认错误与重试能看见。
2. 从图打开讲解，滚到文档中段，再去书签。连续后退应先看见刚读的段落，再看见原节点和视野。前进应恢复对应讲解位置；回退后改去标注，核前进分支和箭头状态。另从「不理解」或跨文件笔记链接回访并返回，核原条目、筛选与滚动位置，以及失败链接和保存中草稿的行为。用六页、中英文和临界宽度核顶栏位置、固定页名、可用状态与焦点。
3. 打开订单闭环，从右栏读步骤再沿分支走一步，切依赖图又返回，核原步骤及两图各自的视野。D027 已审的连续圆角、曲线、点阵和 Ctrl／分组只补与新浮层、命中及焦点有关的回归。写入及故障场景使用副本。

执行自测后冻结候选和输入，按上述路径给独审对应证据。审查者亲手核一次完整的前进后退、一个文件和一个库的底部详情、闭环右栏，以及小地图开关详情前后的位置。修复后用原失败操作和受影响路径复验。若需要改变既有记录保存、资料去向或闭环教学语义，带实际影响交回主脑。
