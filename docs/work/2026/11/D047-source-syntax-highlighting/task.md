# D047 · 文件阅读页的固定源码语法高亮

## 目标与批准依据

实现任务。读者打开已有的 `config.py` 讲解，在固定源码栏能一眼分清 Python 关键字、普通名字、字符串和注释。打开原讲解即可看到效果，无须让讲解 AI 标注语言或重新生成资料。

2026-11-23，作者在自己的后端项目中读配置模块，指出“阅读代码的时候，我们没法像哪些编码工具一样看代码的关键字”。主脑核实页面已有真实源码路径，建议从截图圈出的固定源码栏开始，按 `.py` 识别 Python。作者确认“可以，你出一单解决吧”，并指定使用本地真实资料，日常服务占用 4317，候选另用端口。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。遇到已不支持的旧文档格式，识别脚本只负责报错或警告，让使用产品 Skill 的 AI 知道哪个文件受影响、原因是什么。AI 按当前 Skill 的正常生成、校验流程改好或重做相应讲解、闭环，无需维护逐版迁移脚本或另写兼容指南。实际改写或删除作者资料仍按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

1. **以作者正在读的文件为主验收。** 派单时从本机 [4317 原版首块](http://127.0.0.1:4317/#aftertaste-block/docs%2Faftertaste%2Fcurrent%2Fbackend%2Fapp%2Finfrastructure%2Fconfig.py.md/bonotpw8) 的只读文档接口核到 189 行、16 块；讲解引用 `619ad71f29c186fa7afbf5098978a5afd01ec978`。测试使用同机项目 `D:/project/Qiao-Ge-Doc/Qiao_Ge` 的这篇现有讲解。用本单候选构建在回环单独启动，优先 `4318`（开工复核，若占用则选其他空闲端口）。保留 4317 的进程、安装和端口。候选仅做阅读验证，不写真实项目的讲解或个人资料。私有源码和真实页面截图留在本机，回执记录定位、观察和候选直达链接。
2. **在原位置比对。** 浅绿主题打开首块 `bonotpw8`（1–11 行），让读者能直接辨出 `from`、`import` 与包名；在下一块 `xerjqw9d`（12–34 行）辨出 `class`、类名和字符串。对照同一固定提交检查各行源码、空行、缩进与行号。切换现有主题后颜色即时生效，各类文字满足现有正文对比度要求；在窄窗和长行上确认仍可读到行末、选取原文。
3. **补实篇未覆盖的边界。** 在隔离样例中检查跨讲解块的 Python 三引号字符串，字符串或注释中的关键字仍按其语境显示。未知扩展名以及源码中的尖括号、与号按原文可读。只在隔离样例构造这些输入。串行运行受影响的检查及真实浏览器验收，可再生成的本机证据放 `.local/D047/<run-id>/`。
4. 冻结候选后由执行调用独立审查子代理，按 Ponytail Review 复核真实项目读回、着色前后的源码一致性、失败回退和主题可读性。成果交回时给作者一个直达同一篇同一块的候选链接，方便与 4317 原版对照。
