## 数量进入订单前的约束

这个文件导出数量解析函数。调用者交入一个值，函数先使用 JavaScript 的数值转换，再要求结果是 1 到 9 之间的整数。满足条件就返回转换后的数字，后续创建订单可以直接保存它。

例如，合成输入中的字符串“4”会得到数字 4。小数 2.5、数字 10 和无法转换成数字的文本都会被拒绝。这里检查的是转换后的结果，因此布尔值 true 也能转成 1 并通过。空字符串和 null 会转成 0，落在允许范围之外。

普通校验失败会抛出异常。数值转换本身也可能抛出异常，例如传入 Symbol 时。此处没有捕获它们，调用链上层负责决定怎样呈现失败。接下来的订单创建讲解会展示这一步位于数组写入之前的位置。
