# D031 · 闭环画布、步骤直读与按需源码对照

## 目标与批准依据

类型为实现。读者从订单入口跟到数量校验，点选步骤就能在右栏读本步讲解，看清两条分支各自的理由。想核对实现时，从阅读栏左缘打开对应源码，读完能沿图继续。交付一版可在 4341 实际试读的页面，供作者反馈。

2026-11-20，作者提出「把依赖图里面的大部分都复用过来」「针对这个阅读的地方重点设计」「节点会轻微上浮」和「根据用户的决定来显示的源码对照」。主脑说明了右栏默认直读、指向源码入口预览、点击或 Enter 固定、切步骤随读、窄窗点按展开，以及卡面轻抬的操作。作者答复「可以，你先出一单，我看看效果，然后再提意见」。参照图中用步骤号、标题及入口标记区分节点，分支去向和原因一起呈现。截图中的订单文案、源码与页签均为参考，试读内容取自实际闭环。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。需要实际改写或删除作者资料时，按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

## 范围与材料

仓库 `D:/project/SpecDev Harness/aftertaste-reader`，基线 `dev@552a309`，任务分支 `codex/feat-loop-reading-canvas`，批准提交见派单消息。[D030 回执](../D030-reader-file-switch/handoff.md)记录 4341 的受审构建 `e5233cd` 与原项目。主脑已在该版本 1440 × 900 CSS px 的 Edge 窗口点开订单校验节点：本步讲解、原块讲解、固定源码均默认折叠；点失败分支后标题更换，两步的固定源码均为第 1–7 行。以这条路径对照首轮效果。

**画布与节点。** 沿用依赖图已审的连续圆角、低对比交互点阵、有方向的曲线、左侧浮动工具、左下小地图、抓手／框选及缩放。节点突出真实步骤标题，辅以推荐顺序中的步号及已有的入口标记；库图例仍可辨认。鼠标移入时仅卡面轻抬约 2 CSS px，离开时落回。热区、连线端口与个人布局坐标稳定，掠过相邻节点时右栏继续显示已选步骤。拖动时优先直接跟手，减少动态效果时静态反馈，键盘可见焦点。点节点或用键盘激活才切换步骤。

闭环打开后，共用顶栏的侧栏按钮控制该图左浮条；切换已保存闭环、刷新列表、打开概览和库图例仍有明确入口。图内刷新、重排、分组管理和操作说明归浮条，给右栏腾出阅读空间。沿 [007 画布操作](../../../../../specs/007-dependency-canvas/spec.md#functional-requirements)复用按住 Ctrl 临时反转、松开恢复、框选浮钮和 Ctrl+G 命名等行为；在闭环中按步骤或图例实例选取。快捷键只归当前活动画布。两类图各用自己的内容、布局、组和视野，依赖图底部文件关系摘要仍属于依赖页。

**右栏读步骤。** 选中后首先看到步骤标题、源码入口（有行范围时）和本步讲解。提示随本步就近呈现，较长的原块讲解按需展开。每条真实出口把目标步骤和闭环保存的理由放在同一可点击行，支持键盘沿分支前进。推荐顺序的上／下一步另有清楚名称；到达没有出口的步骤时点明当前路线结束。长文和多条理由都能读到底，换步后能从新步骤开头接读。库图例展示其已有的介绍、参与文件和用法。项目界面文案沿用中英文切换，讲解和源码保留原文。

**源码按需对照。** 默认收起。入口形如「对照源码 · src/rules.mjs · 1–7 行」。桌面在该入口稍停，面板贴右栏左缘浮在图面上，右栏讲解仍可并排读；移向面板时保持打开，能选字、复制及横向滚动。离开入口和面板后收起临时预览。点击入口或按 Enter 可固定，有明确的关闭入口，Esc 也可收起；从面板用键盘关闭时焦点回到触发处。固定时主动换步，按新步骤更新源码。相同引用保住代码位置、避免闪空，不同行范围显示正确起始行。读者能查到实际文件、行号及闭环所引提交。开关、选文和滚动源码时，图的平移、缩放、节点坐标和小地图位置稳定。

窄窗或并排空间不足时，点按同一入口在当前步骤内展开。触屏可完成开合、阅读和关闭。纯讲解步骤省去入口和代码占位；切到纯讲解或库图例时收起前一步的代码。固定源码读不到时在该步骤提示实际问题，保留本步讲解及沿分支继续阅读的能力。代码取自闭环保存的提交、文件和行范围，步骤按自身 ID 切换；单纯阅读、预览或固定不写项目资料，不向站内历史插入导航项。

**实施入口。** 产品依据为 [08 闭环与画布验收](../../../../../specs/001-first-release/08-current-spec-and-acceptance.md#graph-layout-acceptance)、[两图共用画布与独立布局](../../../../../specs/001-first-release/04-reading-modes.md#shared-graph-canvas)及 [009 闭环阅读](../../../../../specs/009-loop-reader/spec.md#functional-requirements)。在 009 沿 [Spec Kit 增量流程](../../../../development/spec-kit.md#incremental-input)采用 specify、plan、tasks 对应技能和生效模板，更新 US1、FR-003／008、SC-005 等受影响的主定义及试读步骤，写明桌面和窄窗入口，编码前以 analyze 核新增覆盖，再沿 implement 执行。007 提供画布手感参照，006 提供顶栏和回访依据。闭环教学资产和服务协议已有此批所需信息。

从 `src/web/DependencyCanvas.vue`、`LoopReading.vue`、`App.vue`、既有点阵／小地图／卡片与 `canvas.css` 接入。文件和闭环共用绘制与手势时，给每个图实例独立的目标和焦点，核多个已打开的闭环。复用 [闭环读取实现](../../../../../src/application/loops.ts) 的步骤取源与就地诊断。界面实施沿仓内 Ponytail 和 Impeccable 局部实图检查，使用说明更新 [阅读器说明](../../../../usage/file-reader.md) 的闭环部分。浏览器回归归 `tests/browser/`，运行输出归 `.local/D031/`。

## 验证与停点

必要构建后，先用 [4341 共用试读项目的固定副本](../../../../../tests/README.md#页面改版共用试读)走真实阅读路径。沿同一份订单资料、相同视野与窗口留基线和候选实图。作者可在试读版走第一条，异常、布局写入和故障注入在隔离副本完成。

1. **对照两条分支。** 读「规则转换并检查边界」，在「对照源码」停留并移入面板选取代码。固定后走「无效数量让创建提前结束」，左边仍是 `src/rules.mjs` 第 1–7 行，右边已经解释集合为何没有改变。重新从校验点走「规则返回后回到服务」及「订单加入集合并返回」，源码应依次换到 `src/service.mjs` 第 4–6、7–10 行。比较前后画布视野，临时预览、固定与关闭均实操；长行横滚需要时使用隔离输入。
2. **操作边界。** 鼠标掠过几张卡，核浮起与落回、端口及右栏稳定；再拖动同一卡、尝试抓手／选择、按住和松开 Ctrl、框选成组，实际验证只保存当前图的布局。返回依赖图再后退，闭环恢复原步骤和视野，两图各自读得回原布局。另走一次源码中选字及 Ctrl+C，核图快捷键与文本操作互不干扰。
3. **不同输入和资料。** 用键盘固定、读代码、关闭、沿分支继续；390 CSS px 窄窗用点按展开读到末行，再收起选另一步。检查减少动态效果、长步骤名及长分支理由。打开路径工具闭环，核纯讲解「日志路径」及 `node:path` 图例各展示自己的内容。沿 [闭环回归](../../../../../tests/browser/loop-reader.mjs) 的隔离缺源输入验诊断、个人布局保护及按影响选取的迟到／失败回归。[站内历史回归](../../../../../tests/browser/reader-history.mjs) 的闭环用例更新到新入口，保留下步、独立视野及窄窗可读的断言。

自测后冻结候选和输入，按场景给独审对应截图及操作证据。审查者亲手走桌面两条分支、窄窗或键盘对照、一次画布与源码交接，复核共享改动影响的依赖图路径。节点上浮与源码浮层开合交短录屏或连续帧，同时交一张正常阅读和一张固定源码全图。修复用原失败输入及受影响路径复验。若必须改闭环保存语义、作者资产或站内历史规则才可推进，带实际影响交回主脑。
