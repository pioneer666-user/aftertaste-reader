# D034 · 闭环满幅画布与步骤阅读顺序

## 目标与批准依据

类型为实现。读者先看全图，沿线选中一步，再按自己的意愿展开右栏。展开后能先读懂这一步发生了什么，再按真实分支的理由决定往哪里走。整个过程中，底部关系条留在原处。

2026-11-21，作者试读 D033 后要求「默认点开闭环图的时候，右侧边栏不展开」「右侧边栏和左边侧边栏一样，都是覆盖到画布上，不挤画布」，并指出底部毛玻璃关系条上跳、收展按钮独占宽列。作者提出靠近边缘显出收展箭头，推荐上／下一步改成小图标并解释用途，重点是右栏「怎么设计，才能让用户真的看懂」。主脑用现有订单成品演示「规则转换并检查边界」的两条分支，说明默认收栏、关系条按全画布定位、点击才收展、栏内顶部导航和下述阅读顺序。作者确认「先按你说的改一版，你出任务吧」。

## 每单沿用的产品原则

回味以当前版本为准，可以重做旧代码、变更数据格式，无需兼容旧代码或旧数据。格式变更时说清哪些资料受影响。需要实际改写或删除作者资料时，按本单授权处理。

回味在本机运行，页面可以充分尝试质感、动效和高级交互。读者大部分时间在看讲解，优先打磨文字、布局和操作。涉及界面时，用本地试读资料走通这次改变的场景，细看真实内容和窗口边界下的阅读与操作效果。

## 范围与材料

仓库 `D:/project/SpecDev Harness/aftertaste-reader`，基线 `dev@4841dcde8ca091af246188f5a375052d83b4a8d8`，分支 `codex/feat-loop-step-reading`，批准提交由派单消息提供。[D033 回执](../D033-loop-reading-panel/handoff.md)记录 4341 的受审构建 `c95193a` 及共用试读资料。此单替代 D033 的新图默认开栏、栏边竖排导航和右栏让宽布局。

**选图与收展。** 未选图时沿用 D032 的点阵、左侧目录及字标。从目录第一次打开某张闭环图，目录收起，右栏也收起。点节点更新画布选择和底部关系条；主动展开才读当前步，没有选择时读概览。点左上图名仍能直接打开本图概览。回访已经打开的图按当前会话恢复原步骤、视野及先前的显隐选择。收起和重开同一步能接着原位置读。

**右栏浮在满幅画布上。** 以顶栏下整张画布作为点阵、节点、小地图及关系条的定位依据。底部「来自／通向」毛玻璃条以全画布水平中心与底边为锚点。在同窗、同一步骤与同一小地图状态下，开栏、动画中、收栏的位置均相同。给长名称和多出口留可查全的入口；真正缩窗时可以紧凑排布。桌面抽屉只拦截自己覆盖的区域，图层边界处实点验证，不让操作穿透。目录、右栏、源码浮层与底部关系可按原用途接续，开合不改缩放、视野、节点、个人布局或站内历史。

**把手与导航。** 右侧边缘留一小段淡把手；开栏后沿面板靠画布的一边。指针靠近或键盘聚焦显出方向箭头，点击、Enter 或空格才收展。触屏可直接点按，移过边缘仍可正常拖图。将入口、推荐上一步和推荐下一步放进栏内顶部，用小图标与独立、容易命中的点击区，释放原 54 px 竖排控制列及正文为此预留的空白。悬停或聚焦有说明，如「推荐上一步 · 订单加入集合并返回」；控件有可访问名称，长文滚到底仍可导航，首尾能辨认不可用态。入口按 `entry`，前后步按 `reading_order`。

**右栏先读懂本步，再选去向。** 用真实步骤标题开头，紧接完整本步讲解；有 `hint` 才在讲解后就近显示。之后将对照源码收成轻量的一行，例如「对照源码 · src/rules.mjs · 1–7 行」，保留预览、固定、选字及缺源提示。再呈现真实出口：单出口用一行承接说明和去向；分岔时分别呈现每条 `edge.reason` 与可点击的完整目标标题；终点明确本路线到此结束。底部条供快速追线，右栏讲清缘由。最后才放默认折叠的「读这段代码的完整讲解」，展开读闭环保存的原块全文。界面控件随语言切换，讲解原文照常显示。纯讲解步、无行段和库图例沿各自已有数据呈现。

订单示意的两个输入来自成品概览内的假设例子。教学验收使用这份例子；界面直接呈现各闭环已有的讲解、提示、分支和理由。其他闭环按自身内容阅读，不推断成功／失败标签，不硬编码订单文案，也不要求新字段或重写成品。首次展开按步骤直读，主动换步从新讲解开头读；源码保持 D031 的同引用保位、换引用更新与窄窗内联行为。

**实施入口。** 以 [08 现行规格](../../../../../specs/001-first-release/08-current-spec-and-acceptance.md)和 [009 闭环阅读](../../../../../specs/009-loop-reader/spec.md)为依据。按 [Spec Kit 增量流程](../../../../development/spec-kit.md#incremental-input)使用 specify、plan、tasks 对应技能与生效模板，校准 009 US1、FR-002／003／008 和 SC-005 至 SC-007 中受影响的预期；编码前用 analyze 核覆盖，再沿 implement 执行。正式程序从 `src/web/DependencyCanvas.vue`、`LoopReading.vue`、`LoopRelations.vue`、`canvas.css` 及双语文案接入，更新[阅读器说明](../../../../usage/file-reader.md)。画布已有绝对定位右栏，但 `.graph-area` 仍为其留边距；容器变窄后触发底部条抬高避让小地图的规则。应核实际绘图区与用户看到的关系条，不能只量外壳。正式测试沿 `tests/browser/`，运行输出归 `.local/D034/`。

## 验证与停点

1. **用原输入复验上跳。** 主脑在 4341、1440 × 900 CSS px、订单校验步及原有小地图状态下实测：原版收栏时绘图区宽 1440、关系条中心 x 为 720、距底 12 px；开栏后分别约为 922、461、151 px。必要构建后优先在[共用试读项目的隔离副本](../../../../../tests/README.md#页面改版共用试读)重走首次选图 → 收栏选中校验步 → 展开 → 收起。采开合前、动画中、结束后的真实绘图区矩形、视野、同一节点、小地图、关系条中心和底边，逐帧比较同态内容；核页面没有新增布局写入。以满幅收栏态为参照，不以把手移动量代替画布读数。复查 [D033 收展测试](../../../../../tests/browser/loop-reading-panel.mjs)及[站内历史](../../../../../tests/browser/reader-history.mjs)中原来要求右栏在绘图区以外的断言，沿原操作更新预期，保留有效回访覆盖。
2. **读完两条路线。** 用 4341 的订单资料从「规则转换并检查边界」展开阅读。沿通过支读「规则返回后回到服务」，此时订单对象已建立，集合尚未增加；再到「订单加入集合并返回」，才读到追加。重走失败支「无效数量让创建提前结束」，应读到异常发生在创建和追加之前。实际从校验步通向失败步，失败步的推荐上一步却为成功路线末步，两种入口都实点。作者体验题为「输入文本 4，通过校验时集合已经改变了吗？哪一步才第一次改变？」交付真实讲解与分支实图，教学效果留给作者试读判断。另用入口步看可选提示、终点看收束、路径工具图看纯讲解或库图例。
3. **看清控件、接着阅读。** 指针经过边缘只显箭头，点按才收展；键盘可发现把手、操作推荐导航、看到目标全名。正文滚到底后能换步，展开末尾原块能读全文；固定源码、收展、换引用与收起后沿线追步均能继续。查中英文长标题、减少动态和 390 CSS px 点按，无悬停设备可开栏看内容。按影响复用[主阅读](../../../../../tests/browser/loop-main-experience.mjs)与[目录](../../../../../tests/browser/loop-catalog.mjs)用例，保留旧步骤中真实的阅读、源码和目录断言。

自测后冻结候选、构建和输入，由独立审查子代理实操第 1、2 条及键盘收展。证据按路径交付，几何问题给连续帧及读数，阅读问题给默认首屏、分支和长文导航的实图。若有修复，以原失败输入与受影响路径复验。需改变闭环成品格式或改写共用资料方可实现时，先交回具体影响。
