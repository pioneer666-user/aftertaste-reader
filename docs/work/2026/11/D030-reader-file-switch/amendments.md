# D030 · 试读调整

## 2026-11-20 · 占位铺满阅读视口

原批准为 [任务单](task.md) `eadf397`，前一候选为 `95fa7da`。作者附图指出源码和讲解骨架下的大块留白，并要求「占位占满，不要留这么多白，大部分的文档都是内容满的，如果留这么多白大部分情况下都是看的很别扭」。

替换任务单「快切直接，慢切有占位」中的占位覆盖范围。桌面两栏的骨架都铺到当前阅读视口底部。上下排列时，源码占用开头一段，讲解继续铺到视口底部。最终要求和验收见 [FR-018、SC-017](../../../../../specs/006-file-reader/spec.md#measurable-outcomes)。

## 2026-11-20 · 区分占位块高度

针对 `33cef23` 的实图，作者指出「这样太丑了，每个文档块都一样啊？ 做区分，不一样的高度。」继续沿用上一条的视口覆盖范围，源码板和讲解段落按长短交错排列，以不同行数形成不同块高。最终要求和验收归 [FR-018、SC-017](../../../../../specs/006-file-reader/spec.md#measurable-outcomes)。
