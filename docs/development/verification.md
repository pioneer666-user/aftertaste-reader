# 验证与验收

按本次影响选择，预期来自已确认规格；[08 的 A01—A25](../../specs/001-first-release/08-current-spec-and-acceptance.md) 是当前产品验收入口，均不能因为规范落地而勾成完成。

## 三种正确性

| 对象 | 必要证据 | 不能据此声称 |
| --- | --- | --- |
| 程序规则 | 类型／构建检查、受影响行为测试、真实命令或服务路径 | 讲解正确、用户已理解 |
| 产品 Skill | 实际场景的调用、产物、状态与范围；独立行为检查 | 仅文件格式通过就能稳定工作 |
| 阅读与教学 | 真实页面操作、失败恢复与实际试讲；作者体验 | 静态检查或审查代替作者验收 |

## 按影响选检查

- 规范／文档：链接、来源、现行与历史冲突、角色及交接场景；不为纯文档新增产品测试。
- 解析／定位：合法与畸形结构、代码围栏、重复 ID、空输入、边界行、Unicode。可表达独立性质时用 property-based-testing，不为覆盖率堆相似用例。
- 固定源码／更新／恢复：工作区与提交不同、Git 读取失败、重复准备、中断、首次备份不覆盖、恢复范围和用户资产保护；全部使用隔离样例，不破坏真实仓库。
- 命令／服务：相同用例在两个入口的语义一致、失败状态与诊断真实、路径越界和错误参数；不只测试内部函数。
- 数据保存：写入失败、重复调用与实际竞争情形，核原资料和未保存输入；按风险设计失败注入，不对真实个人笔记做破坏测试。
- 页面：长／空内容、键盘操作、状态转换、错误可见、重新打开后的持久结果；作者体验前由 AI 完成可做的功能检查。
- 导出：各选项的数据确实包含／排除、真实版本与更新状态、停服务并移走项目后打开、覆盖失败；隐藏 DOM 不等于移除未选资料。
- 安装／发布任务：在干净隔离目录验证真实打包产物和入口，区分首次安装、日常启动与离线阅读；不拿开发服务器成功替代产品包可用。

## Skill 行为验证

- 选受影响的真实请求及固定样例，检查实际行为和产物，不匹配固定措辞。
- 重点场景：首次范围未答、只提问与明确写回、Git 失败、更新中断与恢复、用户偏好冲突、旧闭环、更新中导出；按变更选取。
- 区分“开发审查子代理”和“模拟使用产品 Skill 的测试代理”；审查者未参与实现，行为试用遵守任务限定的资料和写入范围。
- 行为改进需要比较时固定输入，对比旧版／无 Skill 基线；记录实际模型、宿主与技能版本，不由单次成功推断所有模型可用。
- 讲解正确性核固定源码，教学是否有帮助由作者实际阅读判断；保留失败例子，下一次改进复用。
- Anthropic 评测流程目前只是候选参考，未接入或运行；不会因此产生额外产品运行依赖。

## 环境、资源与证据

- 首版按已定 Windows／Edge 主验；Chrome、Firefox 对受影响浏览器能力做适用兼容检查，记录实际 OS／浏览器版本。未测平台明确写未测。
- 浏览器检查优先已有测试工具或可复用证据；AI 不默认开展多浏览器并行或 CUA。确需 CUA 时先说明用途与范围，按当次授权使用；作者体验不替代技术检查。
- 相关测试一次一个文件串行执行，全套获准也串行。负载、批量服务、再次复现崩溃等先与作者确认；同版本成功检查不机械重复。
- 证据记录提交、命令、输入／样例、环境、结果和边界；关键摘要与独审落仓，大日志截图可放 `.local/<任务>/<轮次>/`，注明其不随克隆恢复。
- 已删除或不能重跑的本地产物不能单独支撑结论；保留足够的样例、命令与摘要。包含用户源码的日志或快照遵守产品限制。
- 同一问题两轮修复失败停止写入式修复，交回各轮证据与未知项；不得靠换代理重新计数。
