# 本地源码对照阅读

需要 Node.js 24 LTS 和 Git 2.45+，从已构建的回味开发树运行。页面及字体随构建提供，正常阅读可以断网使用。npm 安装发布另行交付。

## 准备与启动

在回味开发仓库的 PowerShell 中确认 `node --version` 显示 `v24.x`。按唯一锁文件执行 `npm ci`，再执行 `npm run typecheck` 与 `npm run build`。已有构建时，可直接在仓库根运行以下命令。把示例目录替换为要阅读的项目绝对路径。

```powershell
node dist/cli/main.js serve --project 'D:/projects/my-project'
```

运行终端需保留，页面访问启动输出中的 `url`。默认地址为 `http://127.0.0.1:4317`，可用 `--port 4318` 选择其他端口。

继续本机的共用试读时，直接[打开当前试读](http://127.0.0.1:4341/)。目标项目、换版和首次重建说明统一见[页面改版共用试读](../../tests/README.md#页面改版共用试读)。

命令可以从任意 cwd 调用工具入口绝对路径。一次启动对应一个项目，从该项目的 `docs/aftertaste/` 读取文件讲解、依赖图和已保存的闭环。

## 阅读已有讲解

阅读导航上半部按源码路径组织文件。展开文件夹后选择文件，同名文件可按所在目录或按钮提示中的完整源码路径区分。侧栏顶部显示项目名，点击「项目路径」查看完整路径。下半部「本篇目录」按正文顺序列出各块，点击一项跳到对应块。没有标题时会显示首句短摘，没有合适的文字时会显示源码行范围或块序号。

点击阅读页左上角的侧栏图标可收起或固定侧栏。桌面收起后，把鼠标移到阅读区左缘可临时展开，移出后会收回。再次打开可接着浏览原来的目录和块。窄屏用图标开关，选文件或跳块后回到正文。使用 Tab 选择按钮、Enter 激活、Escape 关闭侧栏。

上下拖动文件树和本篇目录之间的横线可调整两区高度。也可以用 Tab 聚焦分隔线，再按 ↑ 或 ↓ 调节。收栏再打开时，本页继续使用最近调整的比例。

点击侧栏里的项目名，可选择完整项目路径与实际源码提交，并查看校验状态。按 Esc 或点击窗外可关闭资料窗，继续从原处阅读。

打开讲解后，源码文件主标题下方的小字是当前讲解文档的项目相对路径，可以选取。往下进入正文。桌面左侧是固定源码，右侧是讲解。短源码会随本块正文停留，到下一块时自然让开。较长源码与正文一起滚动。横向查看长行时，行号留在左侧。窄屏上下排列，纯讲解块直接显示正文。

页面打开时执行结构、范围及固定源码检查。源码与复制定位都使用文档引用的提交。手改讲解后点击“刷新资料”或刷新浏览器，页面重新读取磁盘。源码与讲解仅在运行内存处理。

右上角可切换简体中文或 English。默认中文，有效的浏览器已保存选择优先。浏览器存储只保存界面语言，讲解、源码和用户内容保持原文。浏览器无法保存时仍在本页切换，并提示结果。

## 在已访问的页面之间往返

顶栏左侧依次是后退、前进和侧栏开关，后面是六个页签。浅色底标出当前页。窄窗点击当前页名可选其他页。侧栏开关控制当前页的辅助区，比如讲解目录、依赖图的闭环目录或笔记列表。该页没有可独立收起的区域时，可以查看开关的禁用原因。

切页、打开另一篇讲解或从个人记录跳到讲解块后，可以用前进和后退沿原路阅读。比如在依赖图打开 `api.mjs` 的讲解，读到中段后切书签，先退一步可接着读该段，再退一步回到原图节点和视野。重新前进可恢复同一段落。后退后去新位置会清除原前进路线。用浏览器重新加载页面会重新开始本次访问记录。

滚动、筛选和图内操作会更新当前停留位置。往返使用现有资料，保留正在编辑的笔记和已调整的布局。原目标已失效时，页面会显示可用位置和原因。

## 复制块定位提问

在同一讲解块内划选文字，松手后点旁边的「复制块定位」，也可以按 Tab 抵达操作再按 Enter。块开头的复制图标可直接复制整块定位。复制后，把定位贴到能访问该项目的 AI 会话里，再写下你的问题。浏览器拒绝自动复制时，按提示手动复制已选中的定位文本。平常的 Ctrl+C 仍复制所选原文。

## 收藏讲解块与回访

移到讲解块上或用 Tab 聚焦右侧页边，即可找到「书签」和「理解标注」。触屏上两项始终可点。点空块的书签图标便能填写收藏理由。可以直接收藏，也可以填自己的备注。已有书签时先显示理由，点标题旁的「＋」可继续收藏。点某条理由旁的铅笔，直接在原行修改；右下的「保存」或「取消」只作用于这一条。切到另一条、点「＋」或收起后，回到对应位置还可接着写。改回原话时「未保存」消失。点该条的「更多」，在旁边浮出的「移除书签」上确认；若有改动，先保存或取消。看到「书签已保存」后，即可关闭页面和服务。

重新打开同一项目，在顶栏选「书签」。左栏显示条数、理由和简短来源。点一条，靠近左栏的详情先显示完整收藏理由，再显示当前讲解的标题、摘录和来源。空理由用块的标题或首句提示是哪一块。点该行末尾的箭头或详情里的「回原文」，阅读器会展开原块的书签并聚焦这一条。用顶栏后退可回到刚才的条目和阅读位置。

展开「完整定位」可选取文档路径和块 ID。讲解暂不可定位时，详情会保留原话和完整定位，并给出具体原因。恢复讲解后点「重试读取」。

书签保存在所选项目的 `docs/aftertaste/bookmarks.json`，随项目保留。写入失败时，页面会保留你正在输入的备注。使用阅读器的“刷新资料”或切换讲解后，仍可回到原块继续编辑。解除文件占用或修复权限后，可以重新保存。若另一页面改过同一条，先核对显示的已保存备注，再决定是否重试。保存或重试时，同一项目使用一个阅读服务。

## 记录项目笔记

在顶栏打开「笔记」会先看到第一篇正文。展开左栏时，笔记从书签和标注同样的位置开始。点左栏「全部笔记 ▾」可看所有标签。输入「回」缩小标签范围，点「回访」便只列出带这个标签的笔记。再开同一入口选「全部笔记」即可恢复。选择一篇即可读正文和标签。点引用后用顶栏后退回到原句，按 Tab 可接着读下一处链接。三页都可用顶栏开关收起列表；窄窗打开列表选一条，就会回到整宽详情。

在任一页面点语言左侧的「笔记列表」。输入名称的一部分可筛选，点一篇直接编辑，点列表底部的「新建笔记」打开空白编辑器。标题在顶行，留空时列表使用正文首行。正文下方可以选已有标签、输入新标签或移除标签。点返回箭头换篇，点眼睛预览，再点铅笔接着写。仅打开列表或空白编辑器不会写入；输入、添加标签或主动加入引文后自动保存。关闭后保存继续，失败草稿可从列表找回并重试。

从面板左下角拖动手柄，向左拉宽、向下拉高。键盘聚焦手柄后用方向键微调，Home 恢复初始尺寸。列表、编辑和预览沿用这次调好的大小，刷新页面后恢复默认。

在讲解中划选文字，「复制块定位」可复制原句和块的位置。点「加入笔记」会在原页右上角打开带引文的笔记。如果浮层已打开一篇（包括眼睛预览时），原句会加到这一篇，光标停在引文下方。要加到指定已有篇，先从右上角列表打开它，再选中讲解文字。引用显示原句与文件、块 ID。编辑时点引用可整块选中，复制或剪切会带上完整块链接；粘贴到另一篇会重新显示引用。用退格或 Delete 可整块删除，撤销即可恢复。在预览中点击链接回到原文。文档或块暂时失效时保留原引用，显示具体原因。

在「笔记」工作台，独立的纯文字首行可直接用作篇名。点「编辑」即可改这行原文，或点「另设标题」单独取名。清空自定标题后，列表重新取正文首个非空行。篇首的「＋ 标签」可添加标签，点已有标签的 × 可移除。要删除整篇，点「更多」里的「删除笔记」并确认。桌面可左右对照预览，窄窗用「编辑／预览」切换。工作台与浮层共用同一篇的草稿和保存状态。

标题、正文和标签自动保存到所选项目的 `docs/aftertaste/notes.json`。看到「已保存」后可关闭页面和服务。编辑正文时，Ctrl+Z 可撤销已经自动保存的输入，撤销结果也会自动保存。写失败时草稿留在当前页面，恢复后可点「重试保存」。同一服务的两个页面可以编辑不同笔记。若同一篇的已保存版本发生变化，先保留自己的草稿，再按需读取已保存版本。

## 标注理解状态

点页边「理解标注」并选灰色 ○ 未标记、红色 ? 不理解或绿色 ✓ 已理解，状态会立即保存。只有批注时，页边常显中性的批注图标。打开即可读原话，再点「编辑批注」写下卡住的原因或自己的理解。点输入区右下的「保存」提交，清空后保存即可移除批注。改标会保留已存批注和正在写的草稿。「取消」放弃这次批注编辑。按 Esc 或关闭回到原入口，点击正文可继续阅读。窄窗浮层贴底。切换入口、收起或切篇后，回到原块再打开即可续写本页草稿。

重开项目后，从顶栏的「标注」查看已标状态和仍留有批注的块。「全部」和「不理解」直接切换左栏范围，标题旁显示当前条数。选择一条，详情会先显示状态和完整批注，再显示当前讲解。点行尾箭头或详情里的「回原文」会展开原块的理解状态和批注。后退会恢复所选条目、筛选和原阅读位置。原文暂不可定位时，仍可读批注、展开完整定位或重试。

标注保存在所选项目的 `docs/aftertaste/understanding-marks.json`。看到「标注已保存」或「批注已保存」后可关页。保存失败时，本页保留输入，恢复后可重试。同一服务的另一页改过同一状态或批注时，页面显示已存值，可取消当前草稿，或核对后提交自己的版本。

## 文件依赖图与布局

打开顶栏的「文件依赖图」。文件卡首行是文件名，下一行是目录。小勾表示依赖已核对，待核对的文件有文字提示。点选文件后沿实线看直接依赖，沿虚线看库的使用关系。底部的横向摘要列出主要关系，点一条线或用 Tab 聚焦后按 Enter，可读这条关系的完整两端与原因。点库图例可直接读介绍和每个文件的用法。已有讲解可从摘要直接点「阅读讲解」，再用顶栏「后退」回到刚才选中的文件和视野。

用顶栏左侧开关打开闭环目录，按标题或路线缩影选一条。金色菱形标出所有参与文件。图上方可「阅读此闭环」，后退一次回到原图；点「清除高亮」结束选取。版本不同或路径缺失时，上方会说明原因，可继续读保存的闭环。

画布左侧常驻浅色工具条。它默认只显示图标。鼠标移入工具条或用 Tab 聚焦时可查看名称，按 Esc 收起名称。触屏可点「操作说明」查看图标顺序。点叉号可清除选择。小地图和下方工具仍在左下角。

- 选中标有“标准库”或“第三方库”的图例，可读库的介绍和每个文件使用它的理由。切换界面语言时，介绍和理由保持原文。
- 左下角默认使用抓手，可以拖动空白处或组框背景平移。点选择工具可固定为框选。按住 Ctrl 临时用另一种工具，松开恢复。一次拖动按鼠标落下时的工具完成。两种工具下都可点文件读详情或直接拖文件、库图例。
- 小地图显示全图和当前视野。点击小地图可跳到该处，拖动视野框可平移。用滚轮或下方按钮缩放主图，窄窗里可收起小地图继续用工具和缩放。
- 用选择工具拖框，完全围住要分组的文件和库。松手后点鼠标旁的「分组」，或按 Ctrl+G。填组名后按 Enter 确认，按 Esc 取消。有成员已在别组时，命名处会列出将移组的成员。
- 点组名旁的「⋯」可改名、调整成员或解散分组。点「解散分组」后组框消失，文件和库图例都留在原位。拖组名只移动组成员。也可从左浮条打开「编辑分组」，勾选成员来新建或修改组。
- “重新布局”放回默认视野并按组排列对象，保留组名与成员。
- 调整会自动保存。新组实际保存成功时，组边缘的点向外亮一圈。系统开启减少动态效果后可直接看保存提示。待保存提示消失后可关页面和服务。再次启动同一项目将读取 `docs/aftertaste/dependency-layout.json`。每个项目单独保存布局。一个项目用同一个服务供多个标签页访问。

文件占用或权限问题会显示保存失败，页面仍保留这次摆放。解除占用或修复权限后点“重试保存”。如果另一个标签页已保存，可显式放弃本页草稿并读取已保存布局。布局文件损坏时请保留原件，按诊断修复后刷新。

文件关系、库介绍和使用理由由讲解 AI 通过图工具维护，网页只保存读者的排布。图内容更新后，在左浮条点「刷新图和布局」。存续的文件和图例保留位置与分组，新对象优先放在旧排布外侧。资料损坏、暂时缺失或移除尚未确认时，服务保留磁盘布局并提示原因。[页面改版共用试读](../../tests/README.md#页面改版共用试读)提供带分组与库图例的订单依赖图。

## 阅读已保存的闭环

在顶部打开“闭环阅读”，左侧目录列出每条路线的缩影、标题、目标、步数和文件数。第一次选图时两栏收起，先看全图。点节点后可从底部「来自／通向」沿真实连线换步，点「展开讲解」直接读当前步，在右栏可查所有来路、出口的全名和理由。点「收起讲解」回到全图。靠近右边缘或用 Tab 聚焦把手会显出箭头，点击、Enter 或空格展开阅读栏，触屏可直接点按。阅读栏覆盖在画布上，收起后再打开同一步能接着读。回访一张图会恢复先前的步骤、视野与显隐选择。

先读标题、本步讲解与可选提示，再按需对照源码。每条出口写出走向目标步骤的理由，末尾可展开原块全文。栏内顶部的旗标回入口，左右箭头按推荐顺序走，悬停或键盘聚焦可见目标全名。点空白清空选择，点左上图名打开概览。顶栏按钮可展开目录，再点一次或按 Esc 收回。

拖动组名移动整组。点组名旁的「⋯」可以改名、调整成员或解散分组。「解散分组」会立即保存到本图个人布局，节点保留在原位。

有源码范围的步骤显示“对照源码 · 文件 · 起止行”。桌面稍停或键盘聚焦可预览，点击或按 Enter 固定；固定后换步会跟随新步骤更新，同一引用保留代码位置。面板贴着右栏左缘浮在图面上，可选择、复制、纵横滚动，点“关闭源码”或按 Esc 收起。窄窗或空间不足时，点按入口在本步内展开。预览和固定不写布局，也不新增站内历史。纯讲解步骤没有源码入口；源码不可用时保留本步讲解和实际诊断。切页后用站内历史回来，可继续读原闭环步骤和视野。

库图例展示闭环保存的介绍和参与文件各自的用法。两类图共用左浮条、点阵、小地图、抓手／选择、缩放和分组手势；两图工具常驻，顶栏开关控制各自的闭环目录。鼠标经过节点时卡面轻抬约 2 像素，离开或拖动时落回；系统开启减少动态效果后保持静止。即使两个教学步骤引用同一原块，也可分别摆放。每条闭环的个人排布独立存于 `docs/aftertaste/loops/<id>/layout.json`。遇到写入失败可回原图重试，遇到修订冲突可显式读取已保存的布局。订单和路径工具两条闭环可在[页面改版共用试读](../../tests/README.md#页面改版共用试读)中阅读。

## 错误与修复

- 空资料显示“还没有文件讲解”。先为当前项目生成资料，再刷新。
- 结构或范围不合法时，页面按普通 Markdown 显示可读原文，检查结果提供问题码、文档行、块及建议。复制“修复信息”交给有项目访问权限的 AI，复制失败可选择文本手动复制。
- Git、提交或对象不可用时，已有讲解仍能打开，源码标为不可用。按具体问题核对原项目和引用，修复后刷新。讲解和源码由阅读服务只读访问。
- 文档无法读取为 UTF-8 时显示读取错误。核文件、编码和权限后刷新。
- 超大块显示警告并完整阅读。空正文显示未完成。
- 端口被占用时选择其他端口，或在原终端关闭属于自己的服务。预构建页面缺失时重新构建。

修复信息不含源码正文。Markdown 中的原生 HTML 按文本处理，图片呈现替代文本，链接限于安全协议，页面不会自动加载外部资源。任意磁盘文件读取、资料生成及编辑由本批之外的能力承担。

## 停止与重启

在启动服务的 PowerShell 终端按 Ctrl+C，收到 `status=stopped` 后服务关闭。重新执行同一启动命令可继续阅读。停止服务保留项目资料。共用服务的目标目录与启动命令见[页面改版共用试读](../../tests/README.md#页面改版共用试读)。
