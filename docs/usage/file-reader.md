# 本地源码对照阅读

需要 Node.js 24 LTS 和 Git 2.45+，从已构建的回味开发树运行。页面及字体随构建提供，正常阅读可以断网使用。npm 安装发布另行交付。

## 准备与启动

在回味开发仓库的 PowerShell 中按唯一锁文件执行 `npm ci`，再执行 `npm run typecheck` 与 `npm run build`。成功后使用 `dist/cli/main.js serve --project` 并传目标项目的绝对目录。运行终端需保留，页面访问启动输出中的 `url`。默认地址为 `http://127.0.0.1:4317`，可用 `--port 4318` 选择其他端口。

命令可以从任意 cwd 调用工具入口绝对路径。一次启动对应一个项目，从该项目的 `docs/aftertaste/` 读取文件讲解、依赖图和已保存的闭环。

## 阅读已有讲解

左侧按源码完整镜像路径选择文件，源码扩展名保留。页面显示文档路径和实际完整源码提交。对照块为源码与讲解双栏，窄屏上下排列；纯讲解块单独显示。源码区可以横向滚动查看长行，正文中的示例代码使用独立样式。

页面打开时执行结构、范围及固定源码检查。源码来自文档头提交，修改工作区或 HEAD 后仍显示该提交。手改讲解后点击“刷新资料”或刷新浏览器，页面重新读取磁盘。源码与讲解仅在运行内存处理。

右上角可切换简体中文或 English。默认中文，有效的浏览器已保存选择优先。浏览器存储只保存界面语言，讲解、源码和用户内容保持原文。浏览器无法保存时仍在本页切换，并提示结果。

## 收藏讲解块与回访

在块标题旁选“加书签”。可以直接收藏，也可以填自己的备注。同一块能加多条，可在原块逐条编辑备注或移除。看到“书签已保存”后，即可关闭页面和服务。

重新打开同一项目，在顶栏选“书签”，再选择要回看的记录。阅读器会打开该文件，滚到原块并聚焦所选书签。当前讲解暂不可用时，列表仍显示原路径、块 ID 和备注。恢复讲解后可再次选中该记录。

书签保存在所选项目的 `docs/aftertaste/bookmarks.json`，随项目保留。写入失败时，页面会保留你正在输入的备注。使用阅读器的“刷新资料”或切换讲解后，仍可回到原块继续编辑。解除文件占用或修复权限后，可以重新保存。若另一页面改过同一条，先核对显示的已保存备注，再决定是否重试。保存或重试时，同一项目使用一个阅读服务。

## 文件依赖图与布局

打开页面顶部的“文件依赖图”。箭头指向使用依赖的文件，库图例的使用箭头为虚线。单击文件可查看直接关系、原因和依赖核对状态。已有讲解的文件显示“阅读讲解”，读完用“返回依赖图”回到刚才的画布视野。

- 选中标有“标准库”或“第三方库”的图例，可读库的介绍和每个文件使用它的理由。切换界面语言时，介绍和理由保持原文。
- 拖动文件或图例调整位置，拖动空白处平移，滚轮或缩放按钮调整视野。
- 在“分组”选择新建或已有组，填写组名并勾选文件和图例，点“应用分组”。勾选另一组成员会转移归属，取消一组的最后一个成员会移除该组。拖组名只移动组成员。
- “重新布局”放回默认视野并按组排列对象，保留组名与成员。
- 看到“布局已保存”后可关页面和服务。再次启动同一项目将读取 `docs/aftertaste/dependency-layout.json`。每个项目单独保存布局。一个项目用同一个服务供多个标签页访问。

文件占用或权限问题会显示保存失败，页面仍保留这次摆放。解除占用或修复权限后点“重试保存”。如果另一个标签页已保存，可显式放弃本页草稿并读取已保存布局。布局文件损坏时请保留原件，按诊断修复后刷新。

文件关系、库介绍和使用理由由讲解 AI 通过图工具维护，网页只保存读者的排布。图内容更新后点“刷新图和布局”。存续的文件和图例保留位置与分组，新对象优先放在旧排布外侧。资料损坏、暂时缺失或移除尚未确认时，服务保留磁盘布局并提示原因。图例试读入口见 [D014 回执](../work/2026/11/D014-dependency-legends/handoff.md)。

## 阅读已保存的闭环

在顶部打开“闭环阅读”，按标题选择。页面从入口步骤开始，可展开“串讲”和“推荐阅读顺序”。按“推荐下一步”顺序读，也可以从“从这里可以读到”按实际连线查看两条分支和连接理由。选中画布中的步骤后，可展开本步讲解、提示、保存的原块讲解及固定源码行。旧闭环始终从自己的成品读取讲解。源码不可用时，该步显示诊断，其他内容仍可阅读。

库图例展示闭环保存的介绍和参与文件各自的用法。画布可拖动步骤和图例、分组、平移缩放，并保组重排。即使两个教学步骤引用同一原块，也可分别摆放。每条闭环的个人排布独立存于 `docs/aftertaste/loops/<id>/layout.json`。遇到写入失败可回原图重试，遇到修订冲突可显式读取已保存的布局。订单及库图例试读见 [D016 回执](../work/2026/11/D016-loop-reader/handoff.md)。

## 错误与修复

- 空资料显示“还没有文件讲解”。先为当前项目生成资料，再刷新。
- 结构或范围不合法时，页面按普通 Markdown 显示可读原文，检查结果提供问题码、文档行、块及建议。复制“修复信息”交给有项目访问权限的 AI，复制失败可选择文本手动复制。
- Git、提交或对象不可用时，已有讲解仍能打开，源码标为不可用。按具体问题核对原项目和引用，修复后刷新。讲解和源码由阅读服务只读访问。
- 文档无法读取为 UTF-8 时显示读取错误。核文件、编码和权限后刷新。
- 超大块显示警告并完整阅读。空正文显示未完成。
- 端口被占用时选择其他端口，或在原终端关闭属于自己的服务。预构建页面缺失时重新构建。

修复信息不含源码正文。Markdown 中的原生 HTML 按文本处理，图片呈现替代文本，链接限于安全协议，页面不会自动加载外部资源。任意磁盘文件读取、资料生成及编辑由本批之外的能力承担。

## 停止与重启

在启动服务的 PowerShell 终端按 Ctrl+C，收到 `status=stopped` 后服务关闭。重新执行同一启动命令可继续阅读。停止服务保留项目资料。作者待验服务的具体启动命令、资源位置与关闭方式见 [D011 回执](../work/2026/11/D011-file-reader/handoff.md)。
