# 生成文件讲解与闭环

先按[首次安装](../../README.md#首次安装)取得 Skill 和本地 Git 项目的绝对路径。开发者也可以从已构建仓库中显式读取同名 Skill。[D010 开发树用例](../work/2026/11/D010-generation-skill/evidence.md)

## 给讲解 AI 的请求

把安装时取得的 Skill 路径和目标项目路径发给 AI，要求显式读取 Skill。告诉它想读的范围，以及先逐批阅读还是让它连续生成。也可以说明自己能读懂哪些代码，最想问什么。若要读指定的本地 Git 提交，请一并给出。范围或节奏缺失时，AI 会补问并等待。

首次为项目生成文件讲解或闭环时，如果还没选项目讲法，AI 会问「这个项目，你希望我怎么讲？」你可以选从基础讲起、从已有基础弄懂设计，或集中看依赖和架构。说「按默认讲」会选择第二项。也可以在第一条请求里直接说明。AI 会等你回答后才写入资料。

选择存到目标项目的 `docs/aftertaste/preferences.md`。以后换对话，或在文件讲解和闭环之间切换，AI 会读回这份选择。给另一段讲解说「这一段讲短一点」只影响当次。要换项目讲法，可以直接说「以后这个项目按第三种讲」。

AI 会从 Skill 的位置找到同一安装包里的工具，读取固定提交，选取相关小批次，生成并校验讲解，补齐依赖与阅读方向。

## 读产物

讲解在目标项目 `docs/aftertaste/current/` 镜像源码路径，保留源码扩展名再加 `.md`。依赖在 `dependency-graph.json`，偏好在 `preferences.md`，方向在 `reading-direction.md`。使用[本地阅读服务](file-reader.md)打开已有讲解，按块对照文档头提交的真实源码，支持简体中文和英文界面。源码由工具运行时读取。

逐批阅读在交付后等待“继续”。可以复制文档路径与块 ID 提问，AI 在聊天回答，真实反馈按需帮助后续讲法。

## 从已有讲解串起一个业务过程

给 AI 同一个 Skill 入口、目标项目和问题，例如“帮我从已有讲解里找一条路线，解释订单数量校验怎么影响集合”。AI 会查找有完整讲解依据的路线，说明起点和结果。路线和项目讲法都明确后再保存。以后给 AI 项目路径与这条闭环 ID，即可直接读回当时的串讲、连线和源码定位。已保存的讲解和图例随这条闭环保留，源码仍从原 Git 提交读取。

在[本地阅读服务](file-reader.md#阅读已保存的闭环)打开「闭环阅读」，可以沿着图上的分支读取各步和源码。

## 边读边问

在文件块或闭环步骤中划一句，点复制定位，连同目标项目发给有访问权的讲解 AI。问「建立对象时集合已经变了吗？」会在聊天得到解释。说「把这个例子补进刚才那一步」时，AI 会修订所指 current 并读回；重新打开该块或步骤即可看见。想把讲法沿用到以后，可明确告诉 AI。
