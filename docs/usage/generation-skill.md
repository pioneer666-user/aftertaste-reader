# 使用开发树生成普通文件讲解

当前从已构建的回味开发树显式加载 Skill。需要 Node.js 24 LTS、Git 2.45+ 及可读取的本地普通 Git 目标项目。当前宿主自动发现、全局安装与 npm 发布尚待验证。

## 准备工具

在回味开发仓库的 PowerShell 中，使用 Node 24 按锁文件准备依赖并运行 `npm run build`。成功后 `dist/cli/main.js` 是工具入口，之后可以从任意 cwd 调用它的绝对路径。本次验证环境与真实命令见 [D010 证据](../work/2026/11/D010-generation-skill/evidence.md)。

## 给讲解 AI 的请求

将实际产品 `skills/aftertaste-reader/SKILL.md` 绝对路径交给 AI，要求显式读取，再给目标项目绝对路径、想读的范围、逐批阅读或连续生成，以及可选本地提交。普通请求例如“请读取我给出的 Skill 入口。讲解目标项目的 src/，采用逐批阅读。默认固定开始时的 HEAD，我会写简单接口，希望理解职责和取舍。”

AI 解析已读取入口的位置，按包内 tools.md 找到工具。它会读取固定提交，选取相关小批次、生成骨架、填写讲解、校验文档、补齐依赖和阅读方向。范围或节奏未给全时，AI 补问并等待。已有有效选择可直接复用。

## 读产物

讲解在目标项目 `docs/aftertaste/current/` 镜像源码路径，保留源码扩展名再加 `.md`。依赖在 `dependency-graph.json`，偏好在 `preferences.md`，方向在 `reading-direction.md`。目前用编辑器或 Markdown 预览阅读讲解，依据文档头提交及块范围向 AI 取固定源码作对照。源码由工具运行时读取。

逐批阅读在交付后等待“继续”。可以复制文档路径与块 ID 提问，AI 在聊天回答，真实反馈按需帮助后续讲法。跨提交更新、讲解写回、闭环、网页和导出尚待接入。
