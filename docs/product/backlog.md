- 状态：D011 已在首批本地逐文件阅读页落实，规则见 [006 规格](../../specs/006-file-reader/spec.md)，覆盖与待验状态见 [D011 回执](../work/2026/11/D011-file-reader/handoff.md)。导出语言行为由对应任务落实。

- 时机：下一次正式规格／方案衔接时纳入，在第一批正式页面写入大量文案前建立语言资源与组件分离。不能等产品完成后再全量抽取文字；也不回头改造 D004 实验。
- 范围：界面按钮、导航、提示、状态、可预期错误和无障碍标签使用两套语言资源，用户可切换；讲解正文、用户笔记、用户自定义组名和源码保持原内容，不随界面切换自动翻译。不增加机器翻译服务或额外语言。
- 主脑技术判断：基本切换复杂度可控，主要成本在文案齐全、错误信息映射和英文较长时的布局。优先使用与现有 Vue 技术相容的成熟方式，不为可预期能力单列实验；具体依赖在正式方案中确定。[Vue I18n 入门](https://vue-i18n.intlify.dev/guide/essentials/started)及[全局语言切换](https://vue-i18n.intlify.dev/guide/essentials/scope)提供现成机制，2026-11-16 核阅。
- 正式设计要落实：中文采用的字形、初始语言／回退、用户选择的保存范围、本地阅读页与导出只读页的语言行为、程序诊断与界面文案的分工。字段与常规技术细节由 AI 设计；新增产品取舍才回作者讨论。使用对应 Spec Kit 技能／模板，保留本条需求来源。
- 完成标志：同一套页面逻辑可切换两种界面语言，不丢阅读或编辑状态；语言资源完整，英文较长文案下核心布局可用；新增语言沿资源扩展，无需复制页面或业务逻辑。
