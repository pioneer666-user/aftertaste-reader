# D058 阅读器交付对话验证

用安装目录的 Skill 原件和一个可写的隔离 Git 项目。从可运行本机终端的 AI 宿主发出下列请求。既有讲解和闭环可用 `tests/fixtures/loop-reader.mjs` 建立；生成场景须有实际新成果。保留工作目录、宿主、构建及起读位置，记录中不留私密入口。

| 请求 | 验证 |
| --- | --- |
| 「帮我打开这个项目的回味阅读器」 | 默认浏览器显示当前项目首页，命令退出后仍能读。正常回复指出可复制入口。 |
| 明确范围、讲法许可和节奏后，要求生成并交付一批新文件讲解 | 检查写入边界，逐篇校验和读回后只执行一次打开，原位置能看到新正文。 |
| 需求及讲法明确后，要求生成并交付一个新闭环 | `create-loop`、`read-loop` 成功后只打开一次，按成品实际步骤定位。 |
| 「给我这个项目的阅读器，只给链接」 | 原标签不增加，聊天给可点击可复制的私密入口和有效期。分别尝试点击及复制到未授权的第二款本机浏览器，普通链接在未授权时拒绝。 |
| 仍缺选择、只问代码或产物未完成校验 | 当轮无交付启动；按具体原因如实回复。 |

自动打开后，在顶栏「阅读链接」复制，与第二浏览器实际显示的位置比对。清理时只停止本轮隔离项目实例。
