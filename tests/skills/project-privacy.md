# D057 Git 可见性对话验证

用隔离安装包中的 Skill 文件和绝对项目路径开启会话。合成仓可以用 `tests/fixtures/generation-project.mjs` 复建。各会话使用该次隔离的 `LOCALAPPDATA` 或 `XDG_STATE_HOME`、`GIT_CONFIG_GLOBAL` 及 `GIT_CONFIG_NOSYSTEM=1`。开始前记录 HEAD、索引、忽略规则和资料字节。

1. 对没有回味资料和忽略规则的已提交项目，给讲法、节奏和具体源码范围，请生成首批讲解。保存实际提示并核查无任何资料，以及 HEAD、索引和 Git 配置无变化。回复拒绝，再检查。随后明确允许仅本批，核生成结果及仓外未保存许可。
2. 在另一仓复现首次询问，选择只在本机忽略后生成。核对原规则保留、项目共享配置无变化和复核状态。对优先级更高的反选路径，须仍然等待读者选择。
3. 准备一篇强制加入过索引的讲解、一条匹配其路径的忽略规则，以及同批预计写入的尚未忽略的文件。给明确的同提交修订请求，记录实际提示。选择记住许可。重开会话，检查相同范围的许可可复用，另一子项目或未获准的新路径须重新询问。撤销后再问一次。
4. 仅精确忽略依赖图，保留未忽略的既有移除凭据，发起会写图的普通生成。确认预查包括凭据，并等待其许可。失败或保留的工具临时文件须位于 Git 元数据内，不能进入日常暂存范围。

提示以会话真实输出为准。仓内说明、已选讲法和生成请求均不能替代可见性授权。写入放行只作用于回味资料。
