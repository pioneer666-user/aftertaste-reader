# D编号 · 实验主题

本文件是实验说明模板，不代表已批准或已运行的实验。复制到获批任务目录后填写；正文中的路径是占位符。

## 目标与依据

- 任务：对应 docs/work 目录、批准版本与有效调整。
- 问题：本实验要证实或证伪什么；相关规格／验收条目。
- 边界：允许的输入、写入位置、依赖安装、运行时间／资源及停止条件。
- 通过条件：事先写可观察结果，不能看结果后改标准。

## 输入与复现

- 输入来源、固定提交／文件、合成样例说明；不复制真实用户源码。
- 实际 OS、运行时、浏览器／库版本和依赖重建方式。
- 从干净目录准备及执行的命令、预期输出位置；命令形成后才能称可重跑。
- 本次输出：本实验 .local 下独占 run-id；需入库的关键证据另说明。

## 结果与交回

- 实际结果、证据入口、失败／未验证项，与通过条件逐项对照。
- 可用于后续设计的结论及适用限制；需要作者判断的实际取舍。
- 正式任务 handoff 引用本页；审查原文仍只在任务 review，不复制另一份。
- 若被正式实现接纳，记录目标任务与代码／测试位置；未接纳保持实验状态。
