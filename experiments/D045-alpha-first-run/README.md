# D045 · 从本地安装包开始读真实后端

## 目标与依据

本实验回答两个问题：第一次拿到回味的人能否只凭安装包和读者说明生成第一篇讲解？读者能否沿生成的闭环讲清一次收藏请求怎样变成数据库中的记录、计数和前端响应？通过条件和独审要求见[任务书](../../docs/work/2026/11/D045-alpha-first-run/task.md)。

## 输入与复现

试读项目为 [Apache Answer v1.5.0](https://github.com/apache/answer/tree/3f1ed50f6776452c11b6ffdbdc767cd1887d629b)，提交为 `3f1ed50f6776452c11b6ffdbdc767cd1887d629b`。执行者在隔离目录安装候选包，准备尚无回味资料的固定源码副本，并记录实际环境、命令、包的 SHA-256 及所用路径。可重建的本机产物归本目录下的 `.local/<run-id>/`。
