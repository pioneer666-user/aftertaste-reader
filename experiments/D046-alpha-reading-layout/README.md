# D046 · 收藏请求真实试读

使用 [D045 的固定项目、读者问题和空偏好](../D045-alpha-first-run/README.md)。在仓库外独立克隆该提交，复制已校验的 14 篇文件讲解、文件图和教学资料。新版代表性文件与整条闭环由使用候选包的讲解会话产出。读者入口与固定证据见[本批回执](../../docs/work/2026/11/D046-alpha-reading-layout/handoff.md)。

## 复核一次阅读

[检查脚本](check-reading.mjs)使用项目原有的 Playwright 和 Edge。依次运行，每次只开一个浏览器。以下命令从本仓根目录执行，4357 为原版，4359 为新版作者入口。

```powershell
node experiments/D046-alpha-reading-layout/check-reading.mjs http://127.0.0.1:4357 baseline .local/D046/recheck
node experiments/D046-alpha-reading-layout/check-reading.mjs http://127.0.0.1:4359 author .local/D046/recheck
```

两次使用同一 1440 × 900 桌面窗口、14 篇同路径文档，以及 390 × 844 的窄窗。脚本展开全部目录，键盘切篇，测可见行数、列宽、长名和触屏行高。新版另查从文件块直达、双图首屏、节点悬停、键盘聚焦、恢复淡线、闭环高亮和跳转，输出截图与 JSON 摘要。可在新项目直接验证 `touch` 模式，使用 Edge 的触屏模拟。

## 验证保存与增点

`layout` 和 `legacy` 需要另建测试副本，目录名为 `legacy-check`。先核服务返回的绝对项目路径。两种模式会向这个副本写入测试分组、图数据与布局。作者入口仅用于试读。

- `layout` 使用新版文件图与新闭环，两图起初均无个人布局。脚本依次拖动、命名分组和缩放，关页重开后对比坐标，增加关联节点，再由页面刷新、重排并重开。另在闭环平移到分岔点，分别走两条出口，点库返回具体用法所在的步骤。
- `legacy` 使用 D045 原闭环及其完整个人布局。在已有库位置上构造混合组和纯库组，打开概览查文件用法，重排后从磁盘读回隐藏坐标与成员。随后打开另一条无库图例的测试路线。
- 这两个模式的第四个参数是对应副本的绝对路径。运行日志、截图和坐标保存在第三个参数指定的目录。还原输入时从固定样本给测试副本重新填充，不向原版或新版作者项目写测试数据。
