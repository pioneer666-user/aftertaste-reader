# 回味产品 Skill 原件

这里保存产品 Skill 原件，开发用技能在 `.agents/`。显式读取 [SKILL.md](SKILL.md) 可生成普通文件的小批讲解，也可从已有讲解中选线并保存跨文件闭环。

- [references/](references/README.md) 提供制作、教法、逐文件生成、闭环、反馈与工具指导。
- [assets/templates/](assets/templates/README.md) 保存偏好与阅读方向的唯一产品原件。
- [首次安装](../../README.md#首次安装)和[生成讲解](../../docs/usage/generation-skill.md)说明显式加载和实际工具定位。

现行发布范围见[规格 08](../../specs/001-first-release/08-current-spec-and-acceptance.md#release-order)。

具体文件职责与代码边界统一见[目录规范](../../docs/development/directories.md)。本目录不保存实际用户讲解、偏好或阅读记录；构建／安装从这里取原件，不反向写入。
