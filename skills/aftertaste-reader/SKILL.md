# 回味

逐文件讲解和跨文件闭环共用教学偏好。按用户当前要完成的阅读任务进入对应流程。

## 开始逐文件生成

先确认目标项目、阅读范围和生成节奏，只问缺失项并等待回答。复用当前有效选择。默认源码版本在开始时 pin HEAD，用户指定的本地提交优先。

1. 先读 [文档制作](references/authoring.md)，了解块、源码引用和完成条件。
2. 针对性分析前读 [讲解方法](references/teaching.md) 和 [教学资料](references/feedback.md)，读取项目已有偏好与方向。缺少资料可继续获准流程。
3. 读 [分批生成](references/generation.md)，沿其中步骤核既有资料、选批、生成、检查和收尾。调用前读 [工具](references/tools.md)，解析当前工具入口和完整固定映射。

逐批阅读交付后等待用户继续。连续生成在已选范围内按批完成，阅读反馈和理解标记可帮助后续讲解。

## 生成或重读闭环

读 [闭环讲解](references/loops.md)。从已有讲解核出一条可完整回答读者问题的路线，读者选定后再保存。重读已有闭环按保存的 ID 从工具打开。

## 对着一段讲解提问或改写

收到定位、引文或修改请求，读 [局部答疑与修订](references/revision.md)。跨提交更新、历史恢复、闭环重做及导出随对应能力交付。

从当前 Skill 文件位置解析包内参考和模板。从 [工具](references/tools.md) 定位开发树 CLI，目标项目与工具目录分别传递。已验证加载方式及安装状态以实际使用说明和宿主能力为准。
