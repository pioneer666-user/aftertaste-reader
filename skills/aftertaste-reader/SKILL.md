# 回味

逐文件讲解和跨文件闭环共用教学偏好。按用户当前要完成的阅读任务进入对应流程。

生成、修订讲解，以及保存偏好或阅读方向前，按[写入前检查 Git 可见性](references/tools.md#project-privacy)核本批文件，取得覆盖本批的许可后再写。更改或撤销本机许可也走该入口。只读答疑、核查和重读照常进行。

## 打开阅读器

用户请你打开或启动阅读器时，确认当前目标项目，按[启动与交付](references/tools.md#reader-launch)打开首页。用户只要链接时用同一入口的仅链接方式。确认项目后即可执行，无需先生成讲解或选择项目讲法。

## 开始逐文件生成

先确认目标项目，按[项目讲法](references/teaching.md#项目讲法)查当前选择，并核阅读范围和生成节奏。范围已给足时，先凭请求与目标项目的偏好核讲法。缺项就问并结束本轮，等答复后再读取源码和已有成果。

1. 范围、节奏和讲法都已明确后，先读[文档制作](references/authoring.md)，了解块、源码引用和完成条件。
2. 结合[讲解方法](references/teaching.md)和[教学资料](references/feedback.md)的阅读方向及反馈组织内容。默认 pin HEAD，用户指定的本地提交优先。
3. 读 [分批生成](references/generation.md)，沿其中步骤核既有资料、选批、生成、检查和收尾。调用前读 [工具](references/tools.md)，解析当前工具入口和完整固定映射。

逐批阅读交付后等待用户继续。连续生成在已选范围内按批完成，阅读反馈和理解标记可帮助后续讲解。

## 生成或重读闭环

新闭环先按[项目讲法](references/teaching.md#项目讲法)查当前选择。路线已经明确而讲法待选时，凭请求与目标项目偏好给选项并结束本轮，等答复后再核源码和已有成果。仍需选线或已取得两项选择时，按[闭环讲解](references/loops.md)继续。重读已有闭环按保存的 ID 从工具打开。

## 对着一段讲解提问或改写

收到定位、引文或修改请求，读 [局部答疑与修订](references/revision.md)。跨提交更新、历史恢复、闭环重做及导出随对应能力交付。

从当前 Skill 文件位置读取同包参考和模板，按 [工具](references/tools.md) 定位同包 CLI。将用户的目标项目路径单独传给工具。
