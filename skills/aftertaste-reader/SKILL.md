# 回味

逐文件讲解和跨文件闭环共用教学偏好。按用户当前要完成的阅读任务进入对应流程。

## 开始逐文件生成

先确认目标项目，再核阅读范围、生成节奏和[项目讲法](references/teaching.md#项目讲法)。只补问缺失项。讲法待答时，结束本轮并等待读者，保持项目资料原状。

1. 先读 [文档制作](references/authoring.md)，了解块、源码引用和完成条件。
2. 读[讲解方法](references/teaching.md)和[教学资料](references/feedback.md)，只读该项目已有偏好以核讲法。范围、节奏和讲法都已明确后再开始制作。默认 pin HEAD，用户指定的本地提交优先。
3. 读 [分批生成](references/generation.md)，沿其中步骤核既有资料、选批、生成、检查和收尾。调用前读 [工具](references/tools.md)，解析当前工具入口和完整固定映射。

逐批阅读交付后等待用户继续。连续生成在已选范围内按批完成，阅读反馈和理解标记可帮助后续讲解。

## 生成或重读闭环

读[闭环讲解](references/loops.md)。新闭环同样先核项目讲法，讲法与路线都已明确后再保存。重读已有闭环按保存的 ID 从工具打开。

## 对着一段讲解提问或改写

收到定位、引文或修改请求，读 [局部答疑与修订](references/revision.md)。跨提交更新、历史恢复、闭环重做及导出随对应能力交付。

从当前 Skill 文件位置读取同包参考和模板，按 [工具](references/tools.md) 定位同包 CLI。将用户的目标项目路径单独传给工具。
