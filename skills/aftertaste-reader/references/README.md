# 讲解 AI 的参考指南

由 [SKILL.md](../SKILL.md) 引导按任务选读。普通生成用 authoring 和 generation，跨文件闭环用 [loops](loops.md)，两者共用 teaching、feedback 和 tools。

文件职责以[目录规范](../../../docs/development/directories.md)为准，产品依据见[现行规格](../../../specs/001-first-release/08-current-spec-and-acceptance.md)与 [005](../../../specs/005-generation-skill/spec.md)。后续分支只在相应能力实现时增加指南。

用户偏好、阅读方向等实际资料从目标项目读取；模板在同包 assets/templates，不在本目录维护另一份。后续示例只使用合成内容或固定源码引用。
