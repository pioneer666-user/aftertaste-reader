# Aftertaste Reader · 回甘

帮助项目作者对照源码与讲解，逐步读懂自己的项目。当前处于首版需求讨论阶段，尚无可安装产品。

## 当前入口（2026-11-16，U98）

**U101 源码原则**：文件文档、闭环及历史只保存固定源码引用，程序运行时从 Git 读取；读取失败给出错误，不另存源码兜底。只有用户明确勾选携带源码的导出 HTML 例外。此前闭环保存源码文本的设计已撤销；当前仍无产品实现，不存在已实现保存机制的迁移。

先读[首版现行规格与验收清单](specs/001-first-release/08-current-spec-and-acceptance.md)：汇总现行规则、25 个验收场景，以及需作者裁决、AI 落实和实验验证的缺口。**首版采用本地服务，并加入导出功能**；U99 确认只导出 current 文件文档与闭环为单个 HTML，弹框选择是否携带源码、笔记、书签和批注。U100 确认导出页只读，个人记录的编辑回本地服务。D-001 已由 U94 解决，U97 已确认闭环更新主流程。

目前只整理设计文档，尚未编写产品或实际 Skill、未运行实验。以下是保留的阶段记录，其中“未定”或“尚未确认”仅表示当时状态，不能覆盖后续确认。旧 6/16 检查不代表当前设计完成比例。
